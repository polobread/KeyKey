琦琦輸入法 Windows 11 安裝說明
================================

1. 先把整個 ZIP 解壓縮，不要直接在 ZIP 裡執行檔案。
2. 雙擊 Install.cmd，並允許 Windows 的系統管理員權限提示。
3. 安裝程式會自動將「琦琦輸入法」加入 Win+Space 清單。
4. 若沒有立即出現，請登出再登入。

解除安裝：

- 到「設定 > 應用程式 > 已安裝的應用程式」移除「琦琦輸入法」；或
- 執行解壓縮資料夾裡的 Uninstall.cmd。

這是未簽署的家用測試版本。若檔案是從網路下載，Windows 可能顯示安全警告；
請只安裝由你信任的人提供的檔案。x64 套件只適用於 x64 Windows 11，ARM64
電腦必須使用 ARM64 套件。

chichi77 KeyKey for Windows 11
==============================

1. Extract the entire ZIP. Do not run the installer from inside the ZIP.
2. Double-click Install.cmd and approve the administrator prompt.
3. The installer automatically adds chichi77 KeyKey to the Win+Space list.
4. Sign out and back in if it does not appear immediately.

Uninstall it from Settings > Apps > Installed apps, or run Uninstall.cmd from
the extracted package. This is an unsigned home-testing build. Install it only
when it came from someone you trust. The x64 package requires x64 Windows 11;
use a separate ARM64 package on ARM64 Windows.
