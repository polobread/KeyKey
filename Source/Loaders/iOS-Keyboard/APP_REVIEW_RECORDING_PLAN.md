# App Review 實機錄影流程

適用版本：琦琦注音 `1.2.7 (13)`；裝置：iPhone 16 Plus；方向：直式。建議成片控制在
90–120 秒，使用 iOS 內建螢幕錄影，檔名為
`KeyKey-1.2.7-build13-iPhone16Plus-AppReview.mp4`。

## 錄影前準備

- 安裝 Release build 13，確認首頁沒有 Debug 專用的「開啟輸入欄位測試」。
- 開啟勿擾模式並清除通知，避免錄到個資；準備一則空白的「備忘錄」。
- 在「設定 → 一般 → 鍵盤 → 鍵盤 → 新增鍵盤」加入「琦琦注音」，保持「允許完整取用」
  關閉。
- 接上 USB 或藍牙實體鍵盤，確認 App 內「實體鍵盤編輯器」顯示綠色已連線狀態。

## 錄影順序

1. 從主畫面開始錄影並開啟琦琦注音，帶到安裝說明與「實體鍵盤編輯器」入口；向下捲動，
   讓畫面證明正式版沒有測試輸入按鈕。
2. 點「開啟鍵盤設定」，快速帶過已加入的琦琦注音與關閉中的「允許完整取用」。
3. 開啟備忘錄的新筆記，按地球鍵切到琦琦注音；用觸控鍵盤輸入
   `ㄅ半注音的第一選擇 琦琦注音輸入法`，展示 inline 組字、固定直排 `1–9` 候選與選字。
4. 點鍵盤上的「設」，短暫展示 30 組本機關聯詞庫與候選色設定，再回到備忘錄。
5. 回到琦琦 App，開啟「實體鍵盤編輯器」。讓已連線狀態入鏡後，以實體鍵盤輸入同一句
   文字，並展示數字鍵選字、方向鍵移動與 Space／Page Up／Page Down 翻頁。
6. 點「複製」，回備忘錄貼上結果；再回編輯器點「分享」，讓系統分享面板入鏡後取消，
   不傳送給任何人。
7. 回首頁捲到支持方案與「恢復購買」，說明未購買不會鎖住任何輸入功能；不要實際購買。
8. 回到主畫面並停止錄影。

## 交付前檢查

- 影片全程為直式、畫面清楚，沒有通知、帳號或其他個資。
- 版本為 `1.2.7 (13)`，且未出現「開啟輸入欄位測試」或其他 Debug UI。
- 清楚呈現觸控鍵盤可在其他 App 輸入，以及實體鍵盤只在琦琦 App 前景的編輯器內使用；
  不宣稱能在備忘錄、LINE 或 Safari 接管實體鍵盤。
- 有展示完整取用不必開啟、複製與分享由使用者主動觸發，以及支持方案不會鎖功能。
