# 琦琦注音 Android IME

Android 原生繁體中文注音輸入法，使用 KeyKey 共用的
`Source/DataTables/bpmf-ext.cin` 字表。建置時會自動把字表加入 APK，不需要手動複製。

## 畫面模式

- 直式：六排，最上方為上一頁 ▲、9 個候選字與下一頁 ▼，下面依序為數字、QWERTY、ASD、ZXC、
  中英切換／符號／空白／Emoji 列。中間 ASD 列保留 Enter，最右下角為 Emoji 鍵。
- 橫式：五排精簡鍵盤；內容高度為 155dp，每列約 31dp，比 115dp 的半高版增加約
  35%。英數鍵與注音符號左右並排，例如 `1 ㄅ`，不再上下堆疊。中央的上一頁 ▲
  與下一頁 ▼ 之間保留兩個候選字欄位，
  左欄由上到下為 1–5，右欄由上到下為 6–9。
- USB／藍牙鍵盤：只顯示上一頁 ▲、9 個候選字與下一頁 ▼。數字鍵 `1–9` 選字，
  `Page Up`／`Page Down` 換頁。

候選列可按 ▲／▼ 或左右滑動換頁；候選開啟時按空白也會前往下一頁。翻過最後一頁
會回到第一頁，從第一頁往前則會回到最後一頁。中文模式使用台灣標準注音鍵位；
`Alt/英` 鍵切換英文，聲調鍵會立即查詢候選，未輸入聲調時可按空白查詢。
候選字顯示時，畫面數字列及實體鍵盤的 `1–9` 會優先選取對應候選；沒有候選時，
數字列才作為 `ㄅ、ㄉ…` 等標準注音鍵使用。Android 版目前沒有關聯詞候選。
右下角 Emoji 鍵會在候選區開啟 45 個常用表情符號，每頁 9 個、共 5 頁；翻頁與
`1–9` 選取方式和中文字候選相同。
軟體鍵盤底部保留系統區域，避免中英切換、空白及 Enter 等底列按鍵與 Android 的
多國語系地球鍵或手勢導覽列重疊。直式保留 46dp，讓底列比一個完整按鍵安全區的版本
下移 10dp；橫式保留 35dp，讓底列比半高版下移約半個按鍵高度。

## 建置

需求：Android Studio、JDK 17 以上、Android SDK 36。

```powershell
cd Source\Loaders\Android-IME
.\gradlew.bat test assembleDebug
```

APK 位於 `app/build/outputs/apk/debug/app-debug.apk`。

## 在手機啟用

1. 安裝 APK 並開啟「琦琦注音」。
2. 點「啟用輸入法」，在 Android 設定中開啟「琦琦注音輸入法」。
3. 回到程式點「選擇琦琦注音」。

輸入法沒有宣告網路權限；查字與選字都在裝置本機進行。
