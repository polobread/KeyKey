# Linux runtime data

`tc2sc.cin` is generated by `tools/generate-tc2sc-cin.rb` from the repository's
read-only `Source/ModulePackages/OVOFHanConvert/VXHCTC2SCTable.c`. It contains
the 3,058 explicit one-code-point Traditional-to-Simplified mappings used by
the existing OpenVanilla output filter. Do not edit the generated table by
hand.

The generated mapping retains the source table's BSD 3-Clause terms and
attribution to the OpenVanilla Project. The source table records that its data
was derived from Encode::HanConvert 0.31 by Autrijus Tang.

Built-in associated phrases are read from the repository's existing
`DataSource/McBopomofo` and `DataSource/chichi77Collection` sources. CMake
installs them under `data/associated-phrases`; the Linux-only parser applies
the established frequency threshold, people-name exclusions, source ordering,
and cross-collection deduplication contract.
