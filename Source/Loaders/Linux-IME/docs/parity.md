This ledger records evidence; it is not a product-support claim. Behavior
investigations inspect the macOS OSX-IMK/PlainVanilla/module flow first, then
compare Windows TSF; phase-one scope remains bounded by the Windows runtime.
Linux desktop acceptance remains pending unless an entry links to concrete
evidence. Test IDs refer to `LINUX_TEST_PLAN.md`.

Phase one uses the Windows TSF runtime as its parity baseline. Bopomofo
learning/dynamic frequency, auto-correction, and F12–F15 are not Windows-parity
items. F03/F04 and the existing Traditional-to-Simplified path remain as
extension features and are not removed. L1 flows call the Linux engine directly and must not be
cited as desktop evidence. The separately named local X11 cases do reach an
installed Fcitx addon and real GTK 3 entry, but cover only the narrow flows
listed above and are not complete T01–T06 or GNOME/Wayland acceptance.
