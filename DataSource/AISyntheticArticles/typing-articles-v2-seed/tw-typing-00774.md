# 二手商品交易之後的回覆

【通訊軟體私訊】

買家：您好，看到您出售一台 iPad。想請問還在嗎？我在不同二手通路看到的價格差很多，有些含鍵盤，有些只有平板，所以想先確認您貼的價格包括哪些東西。

賣家：還在。價格包含 iPad、充電線和保護殼，不含鍵盤。盒子也在，但邊角有壓痕。機器正常使用，外觀右側有一道細刮痕，我在照片第三張有拍。

買家：謝謝。第三張反光，我看不出刮痕深度。可以補一張關掉螢幕、從側面照的照片嗎？另外，您寫「電池堪用」，是體感描述還是有檢測紀錄？

賣家：是我自己的使用感受，沒有正式檢測，所以不會保證還剩多少比例。我今晚補照片。先說明，這台已過原購買保固，我不想用不確定的數字吸引人。

買家：了解。我手上也有 Pixel 手機，主要想用 iPad 看文件、做筆記，不追求全新外觀。只是同城另一個賣場的價格比您低一些，若現場檢查沒有其他問題，能否小議？

賣家：可以談，但請把比較條件一起說。那個價格是否同容量、同樣含保護殼？若只是看到最低價就要我跟，我沒辦法。

買家：同容量，不含保護殼，照片看起來刮痕較少，但賣家不接受面交測試。您的優點是能當面驗貨。我不是要求跟最低價一樣，想問能否少一點，現場確認後直接交易。

賣家：這樣說我能理解。我可以調低一些，但不再另外送配件。面交時你可測觸控、按鍵、相機、喇叭和充電，登入自己的網路測試也行。請不要帶回家用幾天後才決定，二手物品很難釐清這段期間的狀況。

買家：同意現場決定。還想確認帳號會完全登出並清除資料嗎？若啟用鎖定沒解除，我不會付款。

賣家：會。我們見面時一起確認已重置、沒有綁定我的帳號，再由你進到初始設定畫面。機身序號可現場核對盒子，不在私訊公開完整照片。

過了二十分鐘，賣家補上刮痕近照。

買家：看到了，刮痕比我想像明顯，但不像裂痕。能否再確認螢幕顯示時那個位置不會出現亮點？

賣家：我肉眼沒有看到異常，但不同底色可能較容易察覺。現場可以開白、黑、紅、綠、藍畫面讓你看。我不會把「我沒看到」寫成「絕對沒有」。

買家：好。那我接受您剛才提出的價格，條件是面交完成驗貨。若發現觸控失靈、帳號未解除或實物有照片未呈現的裂痕，我可以不買；單純對細刮痕反悔則是我的問題。

賣家：可以。約在公開場所，時間不要太晚。我會帶充電器供測試，但交易內容仍只有剛才列出的物品。你用 Pixel 手機分享網路時，記得測完登出，不要把自己的帳號留在平板上。

【面交後續】

買家：已到，坐在入口旁長桌，穿深色外套。您不用公開傳車牌或住址。

賣家：我也到了，手上拿灰色提袋。先核對商品，不急著付款。

兩人依序查看外觀。買家試了螢幕各區觸控、音量鍵、相機與充電，並用 Pixel 手機分享網路。賣家在買家面前完成清除，再重新開機到設定頁。盒上序號與機身相符，右側刮痕和照片一致。

買家：功能都正常，我接受現況。剛才談好的金額現在轉給您，請看是否收到。

賣家：已收到，金額正確。我把 iPad、充電線、保護殼和盒子交給你。請再點一次，別把我的測試充電器也帶走。

買家：四樣都在。放心，您的充電器還在桌上。這次價格雖不是各通路最低，但能驗貨、能確認帳號解除，對我比較重要。

賣家：謝謝你先說明議價依據，也沒有把不同配件與交易方式混在一起比。回去後若只是改變心意，我不接受退貨；若發現今天檢查時已存在、而我未揭露的重大問題，請把狀況和照片傳來，我們再核對。交易紀錄我會保留，不公開彼此個人資料。
