# 溫和安慰地談家人報平安

美玲：不好意思下班後打擾。有人知道志偉到家了嗎？他說陪家人回南部，原本約好晚上八點在工作群組報平安，但現在還沒看到。

雅芳：先別急。我記得他說九點，不是八點。可能我們聽到的時間不同。

建國：我也記成八點半。下午會議快結束時大家同時說話，真的不好判斷。

美玲：我不是要催工作，只是他家人第一次開長途夜車。他說「到了會講」，我怕路上有狀況。

雅芳：理解。先傳一則簡短訊息就好，不要連續打電話讓駕駛分心。可以寫：「方便時回一個平安，不急著說明。」

美玲：已傳，還沒讀。

建國：那我們先核對時間。行事曆備註是「約九點抵達」，但群組上午那則寫「八點左右出發」，可能有人把出發和抵達記反了。

美玲：啊，那很可能是我記錯。我把八點當成到家時間了。

雅芳：沒關係。擔心是正常的，但現在沒有消息不代表出事。若他們八點才出發，途中也可能休息。

美玲：我知道，只是想確認。志偉？看到時回個貼圖也可以。

建國：這是第二次詢問了，先等等。我們約九點半仍沒消息，再由一個人打電話。大家一起聯絡，反而會讓家人緊張。

雅芳：同意。我負責打，因為我有他先前留下的聯絡方式。其他人先別找他的家人。

美玲：好，謝謝。我會停止重傳。

志偉：剛到休息站，大家平安。是我說得不清楚，八點出發，預計十點多才到家。我一直在副駕幫忙看路，手機調成靜音。

美玲：收到平安就好。抱歉，我把時間記反，還在群組連問。

志偉：不用道歉，你是關心。我也應該在出發前寫完整，不只說「八點」。家人正在休息，等抵達後我再報一次。

建國：已確認人在休息站，不必現在講細節。慢慢走，安全第一。

雅芳：你不用一路回訊息。抵達、停好車後再傳。我們知道大概十點多即可。

志偉：收到。司機不是我，我也會提醒開車的人不要看手機。

美玲：我先把群組標題改回一般聊天，剛才一緊張差點寫成「緊急」。幸好先核對到是時間記錯。

建國：這次也提醒我們，報平安要寫事件和時間，例如「八點出發、十點後抵達」，不能只丟一個數字。

雅芳：再加地點不用太詳細。說在休息站或已到家就夠，不必公開即時路線。

【十點四十分】

志偉：已到家，車停好，家人都平安。路上因為休息比預期晚一點，沒有事故。謝謝大家關心。

美玲：收到。真的放心了。今晚不用回工作訊息，陪家人休息吧。

雅芳：平安到家就好。明天有空再說旅途情況，不必現在交報告。

建國：我把先前寫的「九點前到」更正為「十點後抵達」。不是誰失約，是我們把出發和到達混在一起。

志偉：對。下次我會直接寫兩行：何時出發、預計何時報平安。如果時間改變，也先通知，不讓你們猜。

美玲：那我也改：超過預定時間先問一次，沒回先核對原訊息，不自己把沉默想成壞消息。

雅芳：很好。今晚結論就是人都平安、時間已釐清。大家晚安。

【隔日上午】

志偉：再補一則，家人昨晚休息後狀況都好。昨天讓大家等消息，主要是我只寫「八點」，沒有說那是出發時間。以後長途移動會在出發前寫清楚預計抵達區間，中途若停留，也只在安全停車時回報。

美玲：謝謝補充。我回頭看訊息，確實是自己把八點接成到家。下次我會先引用原句確認：「你說的是八點出發嗎？」不直接把記憶當成約定。

志偉：同意。這次是時間表達不完整，沒有緊急事故。謝謝大家先安慰、再查訊息，沒有把猜測越傳越大。

美玲：收到。那這件事正式收尾，人平安，約定也改清楚了。
