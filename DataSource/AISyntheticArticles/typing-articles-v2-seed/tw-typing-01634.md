# 溫和安慰地談分享旅後心得

寄件者：媽媽
主旨：回家後才想起的旅行片段

孩子們：

行李都收好了嗎？我今天整理照片，才發現大家在華盛頓紀念碑前那張合照，有人閉眼、有人低頭找帽子，沒有一張完全整齊。以前我會覺得可惜，現在反而喜歡。那天風很大，我們走了不少路，還為了集合點講了半天，照片把那些狼狽都留下來。

你們一路照顧我，讓我累時可以坐下，不催我追景點，謝謝。若要選最難忘的地方，我想到的未必是最壯觀的景色，而是大家在草地旁分著吃點心，又一起確認回程方向。回家後不要只挑漂亮照片，也把各自記得的事寫一點給我。

媽媽

寄件者：大女兒
主旨：回覆：回家後才想起的旅行片段

媽：

我也喜歡那張閉眼照。華盛頓紀念碑當然醒目，但我記得更清楚的是你走到一半說不必為了拍近景硬撐，我們便改在遠處慢慢看。當時我怕行程不完整，還一直問要不要再走過去。現在想想，完整不等於每個角度都拍到。

至於胡佛水壩那天，我起初很失望。天氣熱，參觀動線又和我查到的舊資料不同，我一直覺得準備白做了。後來弟弟提醒我，網路文章有年份，現場應以當日指示為準。我才把紙本收起來，跟著大家走。這件事也值得寫進心得，免得親友把我們的舊經驗當成現在保證。

大女兒

寄件者：小兒子
主旨：我記得的不是同一件事

我對華盛頓紀念碑的印象是我們約錯方向。媽媽站在遠處以為看得到我們，其實人群一擋就完全找不到。後來大家約定只說正式名稱不夠，還要講哪一側、身邊有什麼固定標示。那次沒有真的走散，但把我嚇到了。

胡佛水壩則是姐姐一直查資料，我一直叫她放鬆，後來才知道她不是想控制大家，是擔心長距離移動出了差錯。我那句「都到了再說」有點不負責任。若重來，我會一起查官方資訊，不把所有準備都丟給她。

寄件者：爸爸
主旨：旅後心得不要變成檢討會

大家寫得很仔細，不過也別只寫做錯什麼。旅行中臨時改動本來就會發生，我們能彼此提醒、沒有人逞強，已經很好。姐姐的準備讓路線有底，弟弟臨場問工作人員也有幫助，兩種方式不是互相排斥。

寄件者：媽媽
主旨：回覆：旅後心得不要變成檢討會

爸爸說得對。我請大家寫心得，不是要找誰安排失誤。姐姐若還在介意資料過時，請放下吧；妳已經當場更正，也提醒我們不要轉傳。弟弟也不用一直為那句話道歉，後來你主動去問清楚，就是改變。

我希望留下的是台灣家人真的會用的繁體名稱，所以相簿標題請寫「華盛頓紀念碑」和「胡佛水壩」，不要從不同網站各抄一種譯名。說明文字可以寫我們自己的感受，開放時間、交通規則等會改變的資訊就不要當成永久指南。

寄件者：大女兒
主旨：照片說明初稿

我整理成兩組。第一組是華盛頓紀念碑的遠景、合照和休息照片；第二組是胡佛水壩的途中景色、參觀區域與回程。沒有加上不確定的設施名稱。

有一張媽媽看起來很累，我原本想刪。媽媽若不介意，我想留著，註明「知道累了就停下，行程因此變得更適合全家」。

寄件者：媽媽
主旨：回覆：照片說明初稿

那張可以留。我確實累，也確實說出口了。年紀大的人旅行常怕拖累大家，反而不敢休息；若親友看到這段，也許會知道調整不是掃興。

寄件者：小兒子
主旨：補一段給相簿

我想寫：「我們沒有收集最多景點，卻學會在地圖、現場和彼此之間反覆確認。有人做功課，有人問路，有人提醒休息。遇到不同資訊時，先承認不知道，再找可信的現場說明。」

這樣會不會太像報告？

寄件者：爸爸
主旨：回覆：補一段給相簿

稍微像，但內容是真的。最後加一句輕鬆的：「以及拍合照時，請先確定大家都睜開眼睛。」就很像我們家了。

寄件者：媽媽
主旨：相簿完成

我已看完照片和文字。兩個地標名稱都正確，感受也保留了各自聲音。這封郵件串就一起收著吧。往後記憶若有不同，不必爭誰才對；有人記得景色，有人記得找路，有人記得那包在草地上分完的點心，合起來才是我們的旅行。
