# 商品照片與那次餐點漏送

顧客文章：昨晚向附近餐館訂了幾份晚餐，送到後少了一份主菜。外袋沒有破，收據上卻有列出那份餐點。我用數位相機拍了袋內與收據，照片時間也保留著。打電話時店家說可以補送，但當下大家已等很久，我想確認後續怎麼處理，不希望只得到一句「下次再說」。

店家留言：您好，昨晚尖峰時段確實接到您的電話。我們核對出餐單後，判斷可能在裝袋時遺漏，因此提出補送。您當時表示不方便再等，我們才先記下聯絡方式。很抱歉造成困擾，請勿在公開留言留下地址，細節可用電子郵件確認。

顧客回覆：謝謝回應。我不是拒絕所有補送，而是餐點若一小時後才來，聚餐早已結束。電話中我詢問能否退漏送那一份的費用，店員只說店裡規定只能補送。我想再次要求：若今晚能在約定時間送到，我接受補送；若無法安排，請處理漏送品項的退款。

店家：我們理解您的考量，但當年的電話訂餐與帳務是分開記錄，值班人員不能當場決定退費。經負責人確認，我們仍可優先安排補送，並在出發前先以電話告知。若您今晚沒有用餐需求，我們會另外聯絡協商，不會把餐點突然送到門口。

顧客：今晚家人都在，可以補送，但請先確認是原本漏掉的主菜，不要改成折價券或其他餐點。還有，商品照片只是用來證明袋內內容，請不要把照片刊在店家部落格，也不用公開我的姓名。

店家：收到。補送內容依原訂單，不另作替換；照片僅供此次核對，不會公開。為避免再次遺漏，我們會讓廚房完成後在出餐單畫記，裝袋人員再逐項核對，外送人員離店前確認袋數。這是本次後續處理，不會要求您再證明一次。

顧客：那大約何時能確認？我不是要催車在路上飛，只是不想全家又等到很晚。如果今天人手不足，請早點說，我們可以改談退款。

店家：目前只能確認晚餐時段可送，精確時間仍受當日訂單影響。我們會在預備出餐前致電；若到您指定的最晚時間仍無法安排，便停止製作並由負責人處理該品項費用。這項條件已寫進交班本，晚班會看到。

顧客：這樣可以。我也補充，昨天外送人員態度正常，問題應在裝袋，不希望因留言讓他一個人承擔。我的要求是把漏送補齊或退還漏送部分，不是要求整張訂單免費。

店家：謝謝您把範圍說清楚。我們已聯絡上晚班，對方會依交班內容處理。昨日確切原因尚無法證實，我們不會先指責任何一位員工；會檢查出餐、裝袋與交付三個環節，確認哪裡缺少勾核。

顧客後續：今晚店家有先來電，餐點也在約定範圍內補送，內容正確。我把文章保留，並更新為已處理，避免其他人只看到前半段以為完全沒回應。希望店家往後在電話中把「補送」與「退款」的條件說完整，顧客才能選擇。

店家結語：已記下建議。這次因店家只先提出補送，讓您感覺沒有選擇，我們向您致歉。日後遇到餐點漏送，會先確認顧客是否仍需要餐點、可等待多久，再提出可執行的處理方式。謝謝您在不公開個資的情況下協助核對。

顧客補充：我也會在收到餐點時先核對袋數與品項，若現場發現不符便立即反映。這不是把責任推回顧客，而是雙方都能更快確認。照片與往返信件我先保留到事情完成，之後不再公開討論個別員工。
