# 關於詢問過敏原的那段通訊軟體私訊

以文：妳好，我是週六活動的參加者。看到群組說點心會有餅乾和鹹派，想請問成分。同行朋友對花生會過敏，不是單純不喜歡吃，所以我們想先確認能不能碰。

若晴：謝謝你先說。我是協助訂餐的人，但沒有製作食品，不能只看外觀回答。妳主要想確認花生本身，還是也要問花生油與製作時的接觸風險？

以文：都要。她吃到花生會有明顯反應，也會避免和花生製品共用器具的食物。其他堅果目前沒有同樣狀況，但我們仍想看完整成分，不希望妳替我們判斷安全。

若晴：了解。我先向店家問三件事：餅乾與鹹派各自的原料、是否使用花生油或含花生配料、製作和夾取時是否與花生產品共用器具。我會把店家原話轉給妳，由妳們自行評估。

以文：謝謝。若店家無法確認，也請直接說不確定，我們會自備點心，不會要求臨時重做。

若晴：好。我現在詢問，回覆可能要等店家確認廚房紀錄。

（四十分鐘後）

以文：不好意思，再請問有消息嗎？我們今晚要決定是否另外準備食物。

若晴：剛收到第一段回覆。鹹派的主要配料表沒有列花生，但店家還在查油品與器具；餅乾有多種口味，其中一款含花生，其他口味可能在同一工作區製作。這還不能當成安全確認，請再等我一下。

以文：收到。既然餅乾同區製作，我們先不吃餅乾。鹹派等完整回覆。這不是對店家不滿，只是她需要避開風險。

若晴：理解。我也會請活動現場把不同點心分盤、分夾子，但分開擺放不能消除製作時已發生的接觸，所以不會把它說成無過敏原。

以文：對，謝謝妳分得很清楚。可以再問包裝上的成分標示是否能拍照嗎？請不要只傳一張看不清楚的遠照。

若晴：可以。我會請店家拍完整標示與品名，個別手作品若沒有包裝標示，就請他們以文字列出已知原料和無法排除的部分。

（晚間）

若晴：店家回覆如下：鹹派配方未使用花生或花生油，但廚房也處理含花生食品，器具與工作檯無法保證完全分開。餅乾確定有含花生的口味，同一空間製作。成分照片已傳在下一則，請你們依實際需要判斷。

以文：看到了。依她平常的處理方式，這次兩樣都不吃，我們會自備密封點心。請問活動場地允許自帶嗎？

若晴：場地方同意因飲食需求自備。請把點心保留原包裝，不要和公用餐盤混放。現場若需要冰存，先告訴我；目前安排沒有共用冰箱空間。

以文：不需要冰。我會帶一包有完整標示的餅乾和自己的水。她也會隨身攜帶平常需要的用品，不會交由活動人員保管。

若晴：好。我在名單旁只註記「自備點心，不取用公用點心」，不寫她的醫療細節。報到時我會再口頭提醒負責分餐的人，避免好意把餅乾遞給她。

以文：可以。也請不要在大家面前特別宣布，她自己知道怎麼處理。若有人問，就說飲食需求不同即可。

若晴：明白。我再確認最後安排：店家資訊已提供，但因共用工作區無法排除接觸，你們決定不吃活動點心；自備常溫密封食品，現場分開放置；工作人員不代為判定或勸食。這樣有漏嗎？

以文：沒有。謝謝妳沒有只回「應該沒問題」。問清楚成分後，我們反而能輕鬆參加，不必到現場才臨時猜。

若晴：收到。週六見。若店家在活動前又補充不同資訊，我會原文轉告，但目前安排不因那則回覆自行改變。
