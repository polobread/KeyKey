# 簡短俐落地談帳號與資料移轉

【即時通訊客服】

使用者：請問舊遊戲主機故障，換新主機後，帳號和紀錄可以移轉嗎？

客服：您好。先確認舊主機是否還能開機，以及您是否記得帳號資料。

使用者：能開，但畫面會突然消失。送修的人說可能是主機，也可能是接頭。我換過液晶螢幕，狀況一樣。

客服：了解。請先不要反覆重新開機。帳號可在新主機登入，部分遊戲紀錄是否能帶過去，要看資料存放位置。

使用者：我要怎麼看存放位置？

客服：進入主機的記憶資料管理。如果看得到紀錄，通常代表資料仍在主機或記憶卡。請先告訴我畫面能維持多久。

使用者：不一定。有時十分鐘，有時一開就黑。液晶螢幕顯示沒有訊號。

客服：那先處理備份，不建議現在做完整移轉。完整移轉中途斷線，可能需要重來。您手邊有相容的記憶卡嗎？

使用者：有一張，但裡面已有其他遊戲紀錄。會被清掉嗎？

客服：我無法只憑描述確認卡片格式。請先查看剩餘空間，不要按初始化。若畫面穩定，可逐項複製重要紀錄。

使用者：帳號也要複製到卡裡？

客服：不用。帳號是在新主機重新登入，記憶卡主要用來搬可複製的遊戲紀錄。兩件事分開做。

使用者：可是維修店說修理費跟換新差不多，我才想直接換。若只買新機，舊機壞掉前要先解除帳號嗎？

客服：請稍等，我查一下您這個版本的處理方式。

【數分鐘後】

使用者：還在嗎？

客服：在，抱歉久等。若舊主機還能進入帳號管理，先依畫面選項解除使用資格較穩妥；若無法完成，需再由客服核對帳號。不要在公開訊息提供密碼。

使用者：所以順序是先解除、再複製、最後到新機登入？

客服：建議先複製重要紀錄，確認記憶卡讀得到，再解除舊主機，最後到新主機登入。避免先解除後，備份還沒完成就無法檢查內容。

使用者：懂。那下載過的內容要全部重買嗎？

客服：使用同一帳號登入後，可查看帳號的下載紀錄。能否再次下載依各內容狀態而定，我現在不能保證全部都有。

使用者：遊戲光碟不用移，存檔才要，對吧？

客服：對。光碟是遊戲本體，進度紀錄是另一份資料。請先備份您最在意的紀錄。

使用者：我怕操作到一半畫面又黑。可以把遊戲主機搬到電腦店，接他們的液晶螢幕處理嗎？

客服：可以請現場人員協助測試訊號，但帳號密碼建議由您親自輸入。若要交機維修，先詢問是否會清除資料，並請對方在維修單註明。

使用者：維修跟換新成本接近，你會建議哪個？

客服：我不能替您判斷划不划算。可比較保固、故障原因、維修後是否保留資料，以及新主機是否支援原有配件。若主要考量是資料，先完成備份，再決定修或換。

使用者：原本的控制器可以接新機嗎？

客服：需要核對型號。請輸入型號文字，不要只說外觀顏色。

使用者：型號貼紙磨掉了，只看得到前面幾碼。

客服：那我無法準確確認。您可以拍下插頭與主機連接處，帶到門市比對，不要硬插。

使用者：好。我現在先開機，把三個常玩的紀錄複製出來。如果第二個還沒複製就黑畫面呢？

客服：關閉電源，等設備狀況穩定後再試。不要連續強制開關。已成功複製的紀錄可先用資料管理畫面確認名稱和日期。

使用者：確認後就能移到新機？

客服：新主機到手後，先建立網路連線並登入原帳號，再插入記憶卡查看。請先用複製方式，不要立刻刪除卡上的備份。

使用者：收到。重點是帳號重新登入，存檔另外搬；舊機能撐多久不知道，所以先救重要資料。

客服：正確。若備份過程出現讀取錯誤，記下畫面文字，再回來詢問。密碼、完整帳號和機身序號都不要貼在公開區。

使用者：好，這樣很清楚。我先不急著決定維修或換新，備份完成再比較。
