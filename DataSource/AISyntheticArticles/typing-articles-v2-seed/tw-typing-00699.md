# 從提出請假到下一步

共享文件：下週門市與供應商到貨支援排班草案。

門市承辦註記：我需要在週三下午請假處理家務，原排定的到貨點收無法全程在場。先在文件提出請假，請勿直接刪除我的班次；需確認誰能接手數量核對、瑕疵記錄與簽收。

供應商窗口批註：週三是主要到貨日，司機路線已排定，若更改到貨時段會影響後面店家。我們可換現場窗口，但不便臨時改車次。請問上午先送是否可行？

門市承辦回覆：上午倉庫正在盤點，提早會和另一批貨重疊，不建議。我的請假是下午兩點後；若能在一點半前完成點收，我可以照原安排。只是卸貨時間不一定能掌握，不能把希望當成計畫。

店長批註：先拆開工作。到貨時間維持，點收由副店長接手；承辦上午完成品項清單並標出容易混淆的包裝。若有短少或破損，副店長拍照記錄，隔日由承辦續辦。這樣是否影響供應商流程？

供應商窗口：不影響送貨，但簽收者須知道哪些項目可註記待查。我可在前一日寄出裝箱明細。

副店長批註：我能代班，但原本週三下午要訓練新人。若我去倉庫，請另外安排一人陪新人熟悉收銀，不能直接把那件工作延後又不說。

店長：已看到。小林可陪新人前半段，後半段改為整理貨架，不安排單獨操作。請副店長確認。

副店長：可以。不過小林當天原排休息到三點，若提早到要調整他的班表。請先問本人。

門市承辦：抱歉，我原以為找人簽收就結束，沒想到牽動新人訓練與小林班次。若這樣太麻煩，我可否把請假改成三點開始？

店長：不用急著收回。提出請假後，本來就要評估工作如何銜接。你先說最晚何時必須離開，不要為了讓排班好看而壓縮自己的事情。

門市承辦：兩點必須離開，無法改晚。謝謝，我確認維持下午請假。

小林批註：剛看到通知。週三可提早半小時到，但不能再早，上午已有安排。我願意陪新人，請把要教的項目列出來。

副店長：收到。我會把訓練縮成當天必要的三項，其他移到週五。不是取消，只是調整順序。

供應商窗口追問：請問最後的簽收人是副店長嗎？我們需要在送貨單備註，下午前請回覆。

店長：是，由副店長點收並簽名；門市承辦上午準備清單。若車輛在兩點前提早抵達，仍由原承辦處理，但不要求他等到完成才離開。兩點後一律交接。

門市承辦：我會在共享文件附交接事項：訂購品項、裝箱明細連結、異常回報方式、供應商聯絡窗口。個人請假原因不放進共用文件，只註明不在時段。

供應商窗口：明白。裝箱明細週二下班前提供，若內容再有變動會在同一份文件標日期，不另寄沒有版本的附件。

副店長：我想確認，瑕疵品是現場拒收，還是先註記？

供應商窗口：依品項狀況由現場與司機核對，不能先做一概決定。重點是保留照片與送貨單註記，隔日再由原承辦聯絡。

店長結論：週三到貨時段不變。承辦下午請假，兩點完成交接；副店長接點收，小林陪新人，訓練未完成部分移至週五。供應商於週二提供裝箱明細。任何修改都在本文件留下日期與批註，不以口頭取代。

門市承辦：已讀並確認。週三中午我會再提醒，確保交接檔案已更新。若請假前有未決問題，我會列明負責人，不只寫「麻煩處理」。

副店長：確認接手。請假期間安心處理家務，非緊急不打電話；要你回來判斷的事項先記錄。

供應商窗口：不變，簽收人已註明。謝謝。
