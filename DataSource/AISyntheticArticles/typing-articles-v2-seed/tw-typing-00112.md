# 關於登山與單車活動的那段私人書信

【哥哥來信】

阿弟：

你說下月要和幾位同學從南部鄉鎮騎單車到山腳，再登山看日出，我本來想說年輕人去走走很好。只是近日午後常見雲雨，山路若濕，夜裡出發更難看清。我不是要你取消，只想問你們有沒有因天氣調整的辦法。

出發前請檢查車胎、煞車、車燈與鏈條。每人自備水、乾糧和雨具，不要全隊只靠一個人帶。你信上寫「到了山上再看」，這句太含糊。若到了才發現風雨大，是原路回去，還是留在山腳？最好先約好。

母親叫我提醒你別空腹騎車，又怕我說太多讓你覺得我們不信任你。你若已安排妥當，就把集合地點、同行人與返家時間回信告知。若天候不好，延後並不丟臉。

哥哥

【弟弟回信】

哥：

信收到。你說得對，我們原先只約凌晨在車站旁集合，沒有談取消條件。大家以為帶雨衣便能照走，現在想來，雨衣只能遮雨，不能替單車煞車。

我們重新商量：出發前一晚聽廣播與詢問山腳熟人；若持續下雨，登山取消。天色尚可但山區情形不明，就只騎到平地村落，吃早點後返回。途中才變天，全部人在約定路口集合，不讓前面的人自行上山。

不過我有一個問題。有人從外地搭車來，若臨時取消，怕他白跑。能否請他提前一晚住我家？母親會不會覺得麻煩？我不敢直接答應。

阿弟

【母親附箋】

同學住一晚可以，請先說有幾人，不要半夜帶一隊回來。晚飯可在家吃，早上我做飯糰，你們另帶幾顆橘子。若取消活動，也不要因不好意思就偷偷出發。家裡多煮一鍋飯，比山路上找人容易。

【哥哥第二封信】

你們的調整較清楚。我再提醒幾件小事，但不確定是否都必要，可請帶隊較有經驗的人判斷。每人身上留姓名與家中聯絡地址；攜帶簡單修車工具；鞋底磨平者不要上山。當年沒有隨身電話，隊伍一散便很難聯絡，所以休息點和折返處要先定。

你問外地同學住宿，母親已答應一人。若超過一人，再寫信或打電話回家確認。別把「應該沒問題」當作同意。

我並非熟悉那條山路，不會替你判定天候。能確認的是，雨後路況可能與平日不同。到現場若有不安，就選短程。安全提醒不是一句「自己小心」，而是遇到什麼情況就做什麼。

【弟弟活動前來信】

哥：

外地同學只有一人，星期六傍晚到。我們會先在家吃飯，早些休息。單車都已檢查，有一人的煞車需調整，他修好前不參加。集合處改到我家門前，免得黑夜在車站找人。

飲食分工也排好：母親準備飯糰，我帶水與糖，同學各自帶一份乾糧。早餐店是否營業不確定，所以不把它當唯一補給。若順利下山，再到鎮上吃麵，不先叫店家留桌。

天氣若變，父親會騎車到山腳熟人處問消息。我們以「不登山」作保守決定，不以「都準備了」作出發理由。這樣可以嗎？

【哥哥回覆】

可以。我最放心的是你們已說明取消後怎麼辦。若不登山，可在平地短騎；若連平地也下大雨，就留在家裡。聚會沒有因此失敗。

還有一句可能多嘴：回程疲倦時不要比快。有人想先走，就讓一位同伴跟著，不叫他獨自騎遠。看到此處大概會嫌我像父親。嫌也無妨，回來再笑我。

【活動後的信】

哥：

星期日清晨落雨，我們沒有上山，只沿平地騎了一小段便回家。外地同學起初很失望，說坐那麼久的車卻只吃飯糰。我問他要不要冒雨賭一次，他看了濕滑路面，自己搖頭。回家後大家又去市場吃兩碗麵，心情便好了。

母親說我們準備得像遠征，最後只繞村一圈。我回答，正因準備過，才知道何時不去。下回等天氣穩定再約。你那些提醒沒有白寫；只是飯糰帶太多，晚餐又吃了一回。
