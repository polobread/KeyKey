# 鄰居正在討論約定見面時間

阿賢：林太太，在嗎？我是隔壁阿賢。上次說要一起找水電師傅看頂樓漏水，師傅回話了，問我們星期六上午能不能都在家。妳看到再回，不急。

阿賢：補一下，他說大約九點到十點間來，沒辦法說得更準。我那天十一點要出門，所以想先跟妳確認時間。

阿賢：哈囉？妳今天是不是沒上線？

系統顯示對方已離線。

阿賢：我先留著。若星期六不方便，星期日下午也可以，但師傅要今晚以前知道。主要是漏水位置跨到妳家曬衣間，我不能自己替妳答應開門。

隔日下午，林太太：抱歉，我家這兩天電話線有問題，撥接一直斷，剛才才看到。星期六上午原本要帶孩子去看牙。我能不能十點半回來？

阿賢：妳終於出現了，我還以為訊息沒送到。十點半恐怕太晚，他最慢十點左右就會到下一家。那改星期日下午？

林太太：星期日下午幾點？我不是故意一直不回，白天在店裡也不能上網。如果時間還沒定，可以先打家裡電話留言。

阿賢：他只說下午，沒說幾點。我現在再打去問。妳星期日整個下午都在嗎？

林太太：兩點以後可以，一點以前不一定。還有，我先生說漏水未必在我們這邊，若只是看外牆，不一定要進屋吧？

阿賢：上次下雨時，水痕從兩戶中間下來。師傅說要先看排水口，再看牆面。也許不用進屋，但得有人在，免得臨時需要開門又找不到。我沒有認定是妳家的問題，只是一起確認。

林太太：好，我知道。我剛才那句不是在推責任，是怕孩子看牙又改期。你問到再告訴我。

阿賢：師傅電話沒人接。我先傳呼叫器號碼給他，晚點若回電再上線留言。

當晚九點，阿賢：師傅剛回覆，星期日下午三點左右。這個時間妳可以嗎？

阿賢：我十點要下線了，麻煩看見後確認。若沒回，我不敢直接替妳約。

阿賢：還在嗎？

隔日上午，林太太：三點可以。我昨晚哄孩子睡著，自己也睡了，抱歉。請確定是這個星期日，不是下星期日喔。

阿賢：對，就是這週。那我回覆師傅：星期日下午三點，兩戶都有人。妳若臨時要外出，能否提早留話？

林太太：可以。我也把家裡電話留給你母親了，但白天若沒人接，不代表取消。你可以再傳簡訊到我的按鍵手機，只是我打字很慢，可能只回「可」或「不可」。

阿賢：短短回就好。還有一件，師傅說雨停後不一定看得出水路，若星期日前都沒下雨，他可能先看排水口，等下次下雨再來。這不算放我們鴿子，是現場不好判斷。

林太太：了解。若只先看排水，也請他把可能的原因說給我們聽，不要做完才談費用。能不能請你先問勘查要不要收錢？

阿賢：可以，我也正想問。時間先約定，費用另外確認，不混在一起。今晚我打電話。

星期六晚間，阿賢：已問清楚，第一次來看不先修，會說明哪裡要處理，再由我們決定。師傅仍約三點。我會兩點五十分在樓梯口等。

林太太：收到。三點我在家，先生也會回來。若師傅提早到，請先敲門，不要直接上頂樓，曬衣間有東西要收。

阿賢：沒問題。

星期日下午二點四十分，林太太：我已回家。剛才路上塞了一下，本來怕趕不上。你那邊方便嗎？

阿賢：我也在。師傅方才來電，約晚十分鐘。這次終於三邊都確認了。等他到，我先請他說明，再一起上去。

林太太：好。謝謝你前幾天一直追問，也抱歉讓你等那麼久。以後有期限的事，你訊息後再打一次電話，比較不會卡在我沒上線。

阿賢：記住了。那我們三點十分樓梯口見。
