# 怎麼把加班費與排班爭議說清楚

【共享文件：出勤與排班核對表】

勞工批註：我先把爭議期間的資料集中。證據原本散在主管私訊、工作群組、紙本班表照片與打卡紀錄裡，單看任何一段都不完整。這份文件只整理可核對的日期、原排班、實際工作與訊息來源，不在尚未查清前自行計算法定結論。

欄位一，某月三日。原排班至傍晚，主管在群組要求完成盤點後再離開；打卡顯示較晚下班。主管私訊另寫「明天再補時間」。請雇主說明這句是調整班次、安排補休，或只是口頭安慰。

雇主批註：收到。公司班表顯示原定時間如您所列，但現場主管稱盤點屬交接，不認為全部時間均為加班。需再查當日工作內容。請不要先把整段標成已核准加班。

勞工回覆：我同意標為待確認，但「交接」仍是工作與否應依事實判斷，不能只靠名稱排除。我附上盤點表的最後修改時間與同事訊息，證明當時仍在清點。

欄位二，某月八日。紙本班表後來被手寫更改，照片有兩個版本。第一版是休假，第二版改為上班；通知出現在前一晚群組。本人已到班，打卡也有紀錄，但薪資明細看不出如何計算。

雇主批註：人資收到的只有第二版，因此按一般出勤處理。排班變更是否符合雙方約定，需由主管補充，不能由人資單方面回答。

勞工：這正是不同紀錄散落造成的問題。請保留兩版班表，不要用後版覆蓋前版。我的主張是臨時改班與實際出勤都應被說明，並非僅要求看最後一張表。

雇主：同意保留版本。請在檔名加日期與來源。

欄位三，某月十二日。主管口頭說不用打卡，請在家回覆顧客訊息；當日晚間有多段工作群組紀錄，但沒有登入與登出時間。勞工主張這是工作，雇主認為無法僅憑零碎回覆判定完整時數。

勞工批註：我不主張從第一則到最後一則全部連續工作。請先確認哪些訊息是主管交辦、哪些回覆已完成任務，再由雙方討論時間。可以承認證據不足，不應直接寫成未工作。

雇主：此表述可接受。公司會請主管提供當日交辦內容，並核對客服紀錄。尚未確認的時間標為待議。

——文件審閱會後——

勞工新增總結：已確認事項包括三日原排班與較晚打卡、八日兩版班表及實際到班、十二日晚間確有工作訊息。待確認事項包括各段工作時數、排班變更溝通與後續補償安排。薪資差額須依完整紀錄與適用規範核算，本文件不引用未核實條文或門檻。

雇主回覆：公司不同意將所有打卡差額直接視為爭議金額，但同意不能只以班表或主管一句話結案。後續由人資、現場主管與勞工逐日核對，核對結果另作書面紀錄。

勞工：請再確認，原始群組訊息、班表照片與打卡資料在處理完成前不刪除。我會提供匯出的完整對話，不只截取對自己有利的片段，也請公司保存前後文。

雇主：同意保全相關資料。涉及其他員工個資的部分會限制閱覽，但不因而省略與本案有關的時間與交辦內容。

勞工：另請將主管說法標成「主管陳述」，不要直接寫「事實」。同樣地，我的內容標為「勞工主張」，除非有客觀紀錄支持。這樣雙方才看得出證據和意見的差別。

雇主：已修正欄位名稱。公司預計先完成三個日期核對，再處理其他零星紀錄，避免一次混入整月爭議。實際處理時程另行確認，不在此先承諾未核定期限。

最終共同批註：本文件的目的為提出並整理出勤紀錄，不代表任何一方放棄主張。每一列保留原排班、變更訊息、實際出勤、工作內容與尚待確認事項。若雙方對計算仍有歧異，可攜完整資料尋求適當專業協助，不以單張截圖取代全部經過。
