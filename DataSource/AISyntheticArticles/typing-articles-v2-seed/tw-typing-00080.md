# 耐心說明地談確認對方是否方便

【南城書店留言簿】

三月六日，阿清留：

文雄，星期日下午原說好在書店碰面，再一起去探望老師。你還方便嗎？

我上午要替家裡送貨，午後才能來。

若兩點不成，三點也可。

看到請在簿上回一句，免得大家各自猜。

三月七日，文雄回：

兩點方便。

我會先到書店等。

老師家帶水果即可，不必另買貴重東西。

三月八日，秀月留：

我也可去。

但要在日落前回家，不能留太晚。

請問從書店走去，約要多久？

三月八日，阿清回：

慢慢走約半個時辰。

若你不方便走遠，可在書店等，我們回來再見。

不是一定要每個人都同行。

三月九日，文雄留：

事情有變。

德輝昨日跌傷，星期日不能出席。他本來答應向親戚借腳踏車，如今車子也沒有了。

我仍可去，但原先四人同行，現在只剩三人。是否照舊？

請阿清確認。

三月九日，阿清回：

先照舊。

沒有腳踏車，我們就步行，不必為趕路勉強去借。

秀月若要早回，我們可把集合改到一點半。妳方便提早嗎？

若不便，仍是兩點，探望時間縮短一些。

三月十日上午，秀月未回。

阿清再留：

秀月，昨日的話妳看見了嗎？

我不是催妳答應。

只要寫「一點半可以」、「兩點才行」，或「這次不去」，都好安排。

三月十日下午，書店主人代記：

秀月之弟來過。

他說秀月今日陪母親看病，未讀留言。

明日會再來。

三月十一日，秀月回：

抱歉，方才才看見。

一點半可以，但我不能步行太快。

若德輝不能來，我們是否先送一張問候卡給他？他雖不能出席，仍是原先約好的人。

三月十一日，文雄回：

可以。

我寫卡片，大家在書店簽名。

另問阿清：老師是否已知道我們要去？若沒有先說，突然到訪恐怕不便。

三月十一日晚，阿清留：

我已請家兄帶口信。

老師回話，星期日下午方便，一點半至三點之間都可。

我們一點半在書店集合，走慢些，兩點左右到。

秀月可在三點前先行回家。

三月十二日，德輝託人留言：

謝謝各位記得我。

腳傷不重，只是不宜遠走。

借車的事已向親戚說明，不會讓他空等。

請代我向老師問好。

三月十二日，文雄留：

水果由我買，費用見面再分。

有人對柑橘不適嗎？若無回覆，我就照原先說的買。

三月十三日，秀月回：

我沒有不適。

但不要買太多，三個人提著走也辛苦。

一小籃足夠。

三月十三日，阿清留：

同意。

最後確認：星期日下午一點半，南城書店門前。

文雄帶水果與卡片。

秀月同行，步行放慢，三點前可先回。

德輝不出席，不等他，也不去他家取腳踏車。

若下雨，大家仍先到書店，再決定是否改日，不各自出發。

三月十四日上午，文雄回：

時間方便。

我會早一刻到。

三月十四日中午，秀月回：

我也方便。

若母親臨時需要我，我會請弟弟到書店留話，不讓你們久等。

三月十四日晚，阿清補記：

原來只是一句「星期日可否同行」，因德輝不能來，集合、腳程和帶物都要重問。

問得仔細並非客套。

有人不能出席，就把安排縮小；有人只能早回，就把步調放慢。

大家明白說方便或不方便，事情反而容易。

三月十五日，事後記：

三人都按時到了。

我們慢慢走，沒有因少一人便取消，也沒有催秀月。

卡片已交老師轉給德輝看。

老師精神尚好，留我們喝了一壺茶。秀月先告辭時，大家都知道她原先的安排，沒有再挽留。

文雄將剩下的水果分給老師家人，提籃由我帶回。
