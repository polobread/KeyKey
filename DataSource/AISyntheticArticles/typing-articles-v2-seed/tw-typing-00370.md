# 耐心說明地談客戶追加需求

寄件者：門市企劃小組
收件者：包裝供應商
主旨：請協助確認活動包裝的追加內容

您好。客戶今日提出，希望原訂紙盒除了印製標誌，再增加內襯分隔、單盒貼紙及個別裝袋，並表示「這些應該都包含在原報價」。我們查閱先前往返信件，原確認範圍只有紙盒尺寸、印刷位置與交貨數量，未見三項追加內容。為避免直接回覆造成誤解，請貴方先說明哪些可做、哪些需另行估價，以及是否影響原排程。

供應商業務回覆：

收到。依我方報價單，內襯、貼紙與個別裝袋均未列入。技術上可以處理，但需確認材質、樣式及包裝方式後才能評估，現在無法沿用原金額承諾。另提醒，客戶所說的「內襯」可能只是墊紙，也可能是固定商品的裁切結構，兩者工作不同。請先取得圖示或用途。

門市企劃：

謝謝。我們原本把「簡單內襯」轉述為一般墊紙，剛再問客戶，才知道他要商品放入後不晃動。這已不是同一範圍。我們會把需求改寫為功能，不替客戶猜結構。請問可否先做一個方向供討論？

供應商設計：

可以提出可能作法，但若無商品尺寸與重量，就不能畫成可生產稿。請提供樣品或完整尺寸。若客戶希望先看示意，我方會明確標註「討論用，非最終打樣」。這樣可以開始，不代表納入原報價。

門市企劃兩小時後追問：

想確認是否已收到上一封附的商品尺寸？客戶下午要開會，我們至少需要一段可轉述的範圍說明。

供應商業務：

抱歉，附件未隨信寄到，我們只看到文字。請重新附檔。您可先向客戶說：「新增固定商品、貼紙與裝袋，均需另確認規格、費用與時程；原紙盒製作仍依既定範圍進行。」不要說我方已接受全部追加。

門市企劃：

附件已補寄。另有一點，客戶認為先前提過「打開即可送人」，所以個別裝袋理應包含。查會議紀錄，那句出現在期待效果，沒有形成具體工作項目。我們該如何回覆才不顯得推責？

供應商業務：

可先承認雙方理解不同，再回到可追蹤文件。建議措辭：「我們理解您希望收到即可使用；先前確認文件列有紙盒印製，未列個別裝袋。為達到您現在說明的效果，我們會另列裝袋方案供確認。」重點是說清楚，不需指責客戶從未說過。

門市企劃：

很好。換一種較直接的說法是：「期待曾提到，執行項目尚未確認。」我們會將這句放在內部紀錄，不用在客戶信裡咬文嚼字。

供應商設計：

已收到尺寸。內襯需先確認商品實物公差，現階段僅能做概念配置。貼紙還缺文字與貼附位置；裝袋則要知道單盒或多盒一袋。三項若一起變更，打樣內容與原排程都要重排，不能只在原檔加一層圖。

門市企劃寄給客戶的草稿：

謝謝補充需求。為使商品開盒後保持固定，需新增內襯設計；單盒貼紙與個別裝袋也需確認文字、位置及包裝單位。上述內容不在先前已確認的紙盒印製項目中，我們將請供應商另案提供規格、費用與可行時程。原案是否先行，或等待追加項目一併確認，請您擇一，以免雙方對交付內容有不同理解。

客戶回覆摘要：

客戶表示原以為均包含，但看過項目表後同意先取得追加估價；為避免耽誤，原紙盒暫不生產，待內襯概念確認後再決定。貼紙文字由客戶次日提供，裝袋方式仍待內部討論。

供應商業務結論信：

收到。依最新決定，我方先提供內襯討論圖與追加項目清單，不啟動正式生產。尚未收到的貼紙文字與裝袋方式標為待確認，不以假設代填。完成估價後，請門市、客戶與我方在同一份版本上回覆確認。

本次範圍澄清如下：已確認的是原紙盒規格；新增且待估的是固定式內襯、單盒貼紙與個別裝袋；尚待客戶決定的是包裝單位。這不是單純把三項「順便加上」，而是會改變設計、工序及排程的追加需求。各方確認後再承諾交期，避免今日的客氣變成日後的爭議。
