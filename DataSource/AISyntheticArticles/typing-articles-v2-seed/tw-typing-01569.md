# 帶著不滿地談優先順序衝突

寄件人：文琪
收件人：行銷部林先生、資訊部陳先生
主旨：請確認本週兩項需求的處理順序

兩位好：

我需要把目前的衝突寫清楚。週一上午，林先生在走道口頭交代，要把活動登記頁改成新欄位，並說週三前一定要完成。今天陳先生又表示，系統月底結帳錯誤必須先修，原訂給登記頁的測試人力要全部移走。兩件事都被說成「最優先」，但沒有任何書面決定，執行同仁只能反覆停工。

我對這種情況確實不滿。昨天已依口頭要求完成一半的欄位修改，現在若立刻轉去修結帳，前面的工作會停在不能測試的狀態；若繼續做活動頁，又可能影響月底作業。請兩位在今天中午前共同確認排序、決定人及期限。未收到一致回覆以前，我先完成手邊可獨立收尾的程式，不再接受另一個只有口頭的插單。

文琪

寄件人：林先生
主旨：回覆：請確認本週兩項需求的處理順序

文琪好：

活動週五公布，登記頁當然必須先完成。我週一已說得很清楚，且當時你沒有表示做不到。欄位變更並不複雜，不應因資訊部臨時提出問題就整項延後。請照原時間完成，結帳錯誤可由其他人處理。

林

寄件人：陳先生
主旨：回覆：請確認本週兩項需求的處理順序

各位好：

結帳問題不是今天才出現，我上週已在會議中提出。月底關帳有固定期限，錯誤不修會影響後續核對。資訊部目前沒有「其他人」可立即接手，文琪熟悉這段程式，因此我主張先修結帳，再回頭測登記頁。行銷活動可考慮沿用舊欄位。

陳

寄件人：文琪
主旨：需要具體決議，請勿分別指示

兩位的回信仍是兩個相反指令，無法作為排程。我補充實際工時：活動頁剩下欄位驗證與測試，若需求不再變動，約需一天；結帳錯誤尚待重現，無法承諾半天內修好。兩項工作若輪流切換，兩邊都會增加重新檢查時間。

林先生提到我週一沒有說做不到，當時我並不知道結帳工作會移到我這裡。陳先生提到上週會議已說明，但會議紀錄只寫「追蹤」，沒有指定我負責。這正是我要求書面排序的原因。請不要再各自到座位旁交代一句，之後又問我為何沒照另一句做。

我提出三個可選方案：一、先用半天重現結帳問題，若可迅速修正就完成，再做活動頁；二、活動頁沿用舊欄位，整週集中處理結帳；三、維持新欄位，由兩部門主管協調另一位同仁支援結帳測試。請選擇，並同意對外期限。

文琪

寄件人：部門主管許小姐
主旨：決議：結帳修正優先，活動頁縮減變更

各位好：

我已與兩位確認。決議採第二方案：本週先處理結帳錯誤，活動登記頁維持舊欄位，只修改活動文字與日期，不做資料結構變更。行銷部若已對外說明新欄位，請自行更新公告內容，不要求資訊同仁以加班補上。

文琪今天先完成目前程式的註記與備份，下午開始重現結帳問題。陳先生負責提供錯誤資料與驗收條件；林先生今天下班前提供沿用舊欄位的定稿文字。任何新增需求請回覆本郵件，由我確認是否影響排序。

許

寄件人：林先生

決議收到。我仍認為臨時取消新欄位會讓行銷端難以說明，但既然排序已確認，我會修改公告並在下班前交定稿。請告知下週是否能重新排入欄位變更，不要無限延期。

寄件人：陳先生

收到。我會在下午一點前把可重現的資料放到測試區，並寫明正確結果。修正完成後由我驗收，不會再口頭增加其他範圍。

寄件人：文琪
主旨：回覆：決議與後續排程

收到，現在已有可執行的順序。我會照決議處理：上午收好活動頁未完成部分，下午轉入結帳問題。請林先生注意，現有修改不會直接發布；下週是否續做，請在本週檢討時由主管排定。陳先生提供資料後，我會先回報是否成功重現，再估修正時間。

我也請求往後把臨時工作寫入同一郵件串，至少包含負責人、優先程度與期限。口頭提醒可以用來通知，不能取代衝突時的決定。這次來回已耗掉不少時間，我不希望下週又靠誰的聲音較大來排工作。
