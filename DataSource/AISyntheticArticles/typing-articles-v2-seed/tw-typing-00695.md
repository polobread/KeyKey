# 溫和安慰地談交通事故責任

公司內部紀錄：本文件依雙方來函、值班簿與現場人員口述整理，用於釐清事故經過。內容只區分目前可確認事項、各方主張與尚待查明部分，不先判定責任。

甲方說明：下午送貨途中，我駕車行經巷口，乙方機車突然由右側駛出。我已煞車，但仍擦撞。乙方當場情緒激動，一直說我車速太快。我理解他受驚，可我不能接受尚未查明就說全是我的錯。車上同行人員可證明我進巷前曾減速。

乙方說明：我不是突然衝出，是看到貨車還有一段距離才前行。碰撞後手腳發抖，講話可能大聲，但我主要是擔心傷勢與修理費用。甲方說我「硬闖」也讓我很難受。請公司不要只採用自己員工的說法。

承辦人備註：雙方都將感受和責任主張寫在同一段，容易彼此反駁而忽略事實。請分開補充：一、各自在何處首次看見對方；二、碰撞前採取何種動作；三、車輛接觸位置；四、事故後的處理。無法確定者可寫「記不清」，不必勉強補出精確距離。

甲方補件：我在巷口前看到乙方，隨即踩煞車並向左修正。確切距離無法回想。貨車右前側有擦痕，機車左側倒地。事故後我先下車詢問，再請同事打電話聯絡相關人員。我曾說「你怎麼這樣騎」，這句帶著責怪，我願意承認不妥。

乙方補件：我記得先放慢，再向前通過；是否完全停下，現在不敢確定。機車倒地後，我說「一定是你太快」，這是當時的感覺，沒有測量依據。我要保留提出損害資料的權利，但同意先把事故順序核清。

承辦人回覆：謝謝兩位把「我認為」和「可確認」分開。受驚或不滿都可以記載，但情緒本身不能代替現場資料。甲方主張曾減速，有同行人員口述；乙方主張已察看來車，尚需和其他紀錄一起核對。兩項目前都屬一方陳述，不寫成定論。

現場紀錄摘要：值班簿記有人員到場先後，未記車速。照片可辨識兩車停留位置與外觀損傷，但拍攝於事故後，不能還原碰撞前路徑。附近店家聽見聲響後才出門，沒有目睹碰撞。

乙方詢問：公司一直叫我補資料，是不是要拖延？我的機車不能正常使用，日常通勤已受影響。

承辦人答覆：理解通勤中斷的不便。請將修理估價、就醫等相關資料留存並交付副本；公司收件時會列明項目。要求補件是為確認主張，不表示拒絕處理，也不代表已承認責任。若擔心遺漏，可先列清單核對。

甲方詢問：既然對方承認沒有測量車速，是否可結案為對方責任？

承辦人答覆：不能。乙方收回無依據的車速斷言，只表示該句不能當作確定事實，並不因此證明另一方全無責任。事故責任仍須綜合現場紀錄及後續查證。請不要把對方願意修正說法解讀為認錯。

雙方會談紀要：甲方願就先前責怪語氣致歉，但不先承諾責任比例；乙方接受道歉，仍保留權利主張。兩人同意由公司彙整照片、值班簿和修理資料，各自校閱時間順序；有歧異處並列記錄。

乙方校閱意見：請把「乙方突然駛出」改為「甲方稱乙方由右側駛出」，因為那是甲方主張。另將我「未停車」改成「是否完全停下無法確定」。改後我同意紀要。

甲方校閱意見：同意上述修改，也請將「貨車速度過快」標示為乙方事故當下說法，而非查證結果。

承辦人結語：已依雙方意見更正，保留來函與修訂紀錄。若補充，請指明事實、資料來源與更正文字，讓主張回到可核對的內容。資料齊備後依程序續辦；尚待判定處不預作結論。
