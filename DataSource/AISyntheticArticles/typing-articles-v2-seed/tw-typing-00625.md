# 從交通票券開始的確認票券

【即時通訊紀錄，二〇〇六年】

阿良：你在嗎？旅行社剛傳真兩種交通票券，一種從成都出發，一種是上海市內用。我們要去成都寬窄巷子和上海外灘，你幫我看看是不是買一張全國票就好。

小芸：我在。先別買。那兩個地方在不同城市，票券用途也不一定相同。傳真上寫使用日期、車種和退換條件了嗎？

阿良：字很小。成都那張像是機場到市區接送，上海那張寫觀光巴士。旅行社的人電話裡說「都包交通」，我聽成一張票到處用。

小芸：把「都包」問清楚，是各自包含，還是同一張票包含。你不要只問能不能去景點，要問從哪裡上車、哪天有效、是否要先換票。

阿良：季節會影響嗎？我們原本冬天去，現在可能改成秋天。旅行社說票先開沒關係。

小芸：行程日期若還沒定，不要只靠「沒關係」。請他們在傳真或電子郵件寫明改期後票券是否仍可用。我們那時可能沒有隨時上網查資料，紙本一定要留清楚。

阿良：我打電話了，沒人接。你覺得先付訂金保留比較好嗎？

小芸：不知道條件前不要急。尤其成都和上海之間的長途交通是否包含，目前根本沒答案。若不含，就要另外安排，不是拿市內票券就能接起來。

阿良：可是報價單最下面寫「全程交通」。

小芸：那可能是整份旅遊行程的用語，不一定是票券名稱。你把上下兩行也打給我看。

阿良：「自由活動期間交通自理。全程交通依確認行程所列為準。」啊，那我剛好只看後四個字。

小芸：所以先確認行程表。去成都寬窄巷子那天，是旅行社安排車，還是我們自己從住宿處出發？去上海外灘那晚又是團體活動，還是自由活動？兩天性質不同，票也會不同。

阿良：你還在嗎？旅行社回電話了，我一邊講一邊記，怕漏掉。

【五分鐘後】

小芸：在。你先問，講完再傳，不要邊打字邊漏聽。

阿良：問完。成都寬窄巷子是自由活動，我們自行前往；上海外灘排在團體行程，遊覽車接送。成都那張其實是機場接送券，不是景點交通票。上海觀光巴士票是可選購，跟團體接送無關。

小芸：這就清楚多了。那我們現在只需要決定機場接送券要不要買，上海觀光巴士票若當天已有團體活動，可能先不買。

阿良：旅行社又說，秋天班次可能不同，要出發前再確認。他不肯現在寫死時間。

小芸：這樣合理，但請他寫明「時間另行通知」，還要說通知方式。若只口頭說，到時我們很難知道有沒有改。

阿良：他可以寄電子郵件，也會在出發前打電話。我請他把今日確認內容傳來。還要核對什麼？

小芸：核對票券名稱、使用城市、日期、是否記名、領取方式、未使用能否處理。不要問一個籠統的「都可以改嗎」，要逐張問。也別自行推定其他交通都包含。

阿良：收到旅行社郵件了。成都機場接送券日期待航班確認後登記；上海觀光巴士票未下單；團體去上海外灘的接送列在行程內。沒有寫成都寬窄巷子的市內交通。

小芸：那就回信補一句：「確認成都寬窄巷子為自由活動，市內往返自理。」請對方回覆。不是不相信人，是避免我們又各自記一半。

阿良：已寄。原來我們一直把地名、行程和票券混在同一句話裡，難怪越問越亂。

小芸：等回覆後，把傳真和郵件一起放進旅遊資料夾。到秋天確定日期時，再拿同一份資料核對，不要只憑今天的即時通訊紀錄。

阿良：旅行社回「確認無誤」。那我先訂成都接送，上海觀光巴士暫不買。長途段另外照行程表辦理。

小芸：好。這次每張票只回答自己的用途，不再讓「全程」兩字帶我們從成都一路坐到上海。
