# 關於旅行後提出評論的那段家庭留言

留給家人的便條：

我們自東部旅行回來，大家都問住處如何。若有人再詢問，請不要只答「照片都是假的」，這話太重，也不完全合實情。院子、房舍外形與照片相似，只是照片拍在晴日且取景避開後方工寮；我們抵達時連日陰雨，房內光線較暗，牆角亦有潮氣。應把看見的情況寫清楚，讓業者有回應機會。

我打算寄信評論三件事。其一，宣傳照片使人以為房前空地寬闊，實際可活動處較小；其二，寢具雖整齊，靠窗處有濕氣；其三，主人協助搬行李且煮了熱水，態度並不怠慢。好與不好都寫，較為公允。

阿春

弟弟回條：

我同意不要說全是虛假，但你寫「較小」仍不明白。比什麼小？我們本來以為孩子可跑動，到了才見一半空地放著農具。可寫成「照片未拍到農具放置處，因此可使用範圍與想像不同」。

潮氣也要說是哪一間，不可讓人以為整棟都濕。我的房間乾爽，你們靠山側那間才有水痕。主人當晚有換房，但換去的房較窄。這些都要記。

阿春再留：

你補得對。我還不確定業者是否早已說明房舍兼作農用。當時的介紹紙找不到，不能憑印象指控漏寫。請問你收在哪裡？

隔日再問：

介紹紙仍未找到。你若拿去夾在車票本裡，請回一句，不然我明日便要寄信了。

弟弟回覆：

剛從田裡回來才看到。紙張夾在棕色旅行簿最後一頁。上面只寫可賞山景，沒有說空地可供遊戲，也沒有保證全院空著。所以我們不能說對方違背承諾，只能說照片容易使人有較寬敞的印象。

阿春：

明白。我把評論改成以下文字：「此次住宿與照片所示房舍相同，但照片未呈現後方工寮及農具區域，我們原以為孩子可在整片空地活動，抵達後才知可用範圍有限。靠山側房間遇雨有潮氣，反映後主人協助換房；新房較窄，但寢具乾爽。建議往後在介紹中多放不同角度照片，並說明雨季房況。」

這樣是否太苛刻？

弟弟：

不算苛刻，但可補一句交通。當地道路較窄，業者曾在信中提醒我們不要天黑後才到，我們卻因火車誤點而晚抵。主人仍到路口引導。這部分若不寫，讀者會以為晚到的不便全由店家造成。

阿春：

好。我也想提早飯。份量夠，但孩子嫌菜冷。當日大家晚起，是我們錯過約定時刻，不宜怪廚房吧？

弟弟：

對。若寫可說「我們晚到飯廳，部分菜已冷」，別寫「端上冷菜」。動作不同，責任也不同。

給業者的信：

主人先生：承蒙旅途中照顧，返家後特將感想奉告。房舍與宣傳照片大致相符，惟取景未見工寮與農具區，使我們誤以為全片空地均可活動。建議往後補充側面景況。靠山房間雨後潮濕，幸蒙迅速調換；若能在客人到達前先查看，當更妥當。

我們也須說明，抵達及用早飯均晚於原先約定，相關不便不能歸責於貴處。夜間引路與熱水照料，我們十分感謝。此信不是要求賠償，只希望日後旅客能由照片與文字得到較完整的印象。若我們所述有誤，也盼來信指出。

業者回函摘要：

來信已收。靠山房間遇雨潮濕一事會再查看，照片也將考慮增列其他角度。農具為日常作業所需，往後會先告知可活動範圍。感謝並未隱去晚到與換房經過。雙方對現場感受仍可不同，但有具體位置與時間，較能改進。
