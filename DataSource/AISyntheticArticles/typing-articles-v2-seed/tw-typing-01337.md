# 寫下著作權使用的幾種方式

【共享文件：插畫使用範圍確認稿】

文件目的：使用者擬將三張插畫放入活動手冊與社群貼文。雙方先前只在通話中談過，沒有文字紀錄，因此擬具本稿，確認授權範圍與修改程序。

一、可確認事項

插畫可用於本次活動的紙本手冊、活動介紹頁及宣傳貼文。不包含日後重印、販售周邊、轉交合作單位另作廣告，或供第三人改作。

【使用者批註】

通話時有提到電子報，這裡沒寫。它算「宣傳貼文」還是要另列？

【創作者回覆】

請另外列。我同意本次活動寄送一次，不同意放進往後固定寄送的版型。請寫「本次活動通知電子報」。

二、尺寸與修改

使用者可因版面需要等比例縮放及裁切留白，不改變人物表情、顏色與畫面內容。若涉及加字、去背、重組或與其他圖像合成，應先將示意稿送交創作者確認。

【使用者批註】

手冊封面可能會壓上活動名稱，算加字嗎？文字在插畫旁邊，沒有蓋到人物。

【創作者回覆】

若文字與圖像保持明確間距，可視為編排，不算改圖。若疊在圖上，就先傳版面。這是我對本案的同意條件，不代表一般法律判斷。

三、署名

紙本手冊於圖像旁或版權頁標示創作者名稱；網頁、貼文與電子報於可閱讀處標示。若署名被裁切，應調整圖片或在本文補上。

【創作者批註】

請把通話中說的「有空間就放」改掉。我要的是能看見署名，不是有剩餘位置才放。

【使用者回覆】

同意，已修訂。也請確認署名用本名還是筆名，我不自行猜。

【創作者回覆】

使用筆名，拼法見我附上的相關資料。請勿從舊貼文複製，舊版本有一個字不同。

四、檔案保管與轉交

原始檔僅供本案承辦與排版人員處理，不得公開連結或交贊助單位留存。日後若要再用，另行詢問。

【使用者批註】

印刷廠需要檔案，能否轉交？

【創作者回覆】

可以，但限本批印製。可寫「為製作本次手冊所必要之交付」。

五、尚待確認

手冊追加印製、成果報告使用及合作單位轉貼，均尚未確認。使用者擬整理數量、管道與期間，再由雙方補充。未回覆不視為默許。

【創作者批註】

「轉貼原文」和「下載圖片後另發一篇」要分開。前者保留原貼文與署名，我可以同意；後者形成新的使用方式，要再問。

【使用者回覆】

了解。我會把合作單位的做法問清楚，不用一句「協助宣傳」全部包住。

六、爭議處理紀錄

若發現超出約定的使用，先保存刊登位置、日期、檔案版本及往來訊息，通知對方說明與停止擴散。是否涉及侵權、是否涉嫌故意利用，須依具體事實與專業意見判斷，本文件不先作法律定論。

【使用者批註】

原句寫「違者嚴查查辦」，語氣太像公文，也像已判定違法。我建議刪除。

【創作者回覆】

同意。我的意思是會嚴查實際流向，必要時再依相關規定處理，不是現在指控任何人涉案。改成目前這段較準確。

七、最終確認

使用範圍為紙本手冊、活動介紹頁、宣傳貼文及一次本次活動通知電子報；可以等比例縮放與裁切留白；署名使用附件所列筆名；疊字、重組、追加印製和新的發布方式須另行確認。

【創作者回覆】

以上符合我的理解。請將定稿日期與雙方確認訊息一併留存。

【使用者回覆】

確認。我會依這份內容辦理，若後續需求有變，重新提出，不拿先前電話裡模糊的「可以用」代替授權。
