# 關於餐廳訂位的那段呼叫器留言

呼叫器留言，星期三上午：

「阿敏，訂位人數有變，請速回電話。文忠。」

阿敏回電：

文忠，你只留「人數有變」，我不知道增加還是減少。餐廳要求今晚以前確認，我先不打去改，免得改錯。原本星期六晚餐是十二人，七點到，名義用活動小組。請你逐項告訴我：現在幾人、是否有兒童、時間有沒有變。

文忠：

剛收到兩人臨時不能參加，另外一位同學要帶妹妹，所以十二減二加一，仍是十一人。沒有兒童，時間不變。我怕再有人變動，想等明天下午才通知餐廳。

阿敏：

不能再等。餐廳說大桌要提前安排，從十二人改十一人也應先通知。可以告訴他們目前確定十一人，明天下午再作最後確認。若一直等到全員百分之百確定，桌位可能先給別人。

呼叫器留言，星期三中午：

「阿敏，請以十一人先訂，晚間再回。文忠。」

阿敏致電餐廳後回覆：

餐廳已記十一人，星期六七點，保留到六點五十分。若人數增減兩人以上，需明天下午五點前再說。座位是兩張相鄰桌，不保證全坐同一桌。我沒有替大家答應額外餐點，只保留座位。請你把這幾點通知參加者。

文忠：

收到。志明剛說可能加入，這樣又回十二人。但他只能六點半以前確定。我是不是先叫餐廳恢復十二人？

阿敏：

先不要把「可能」算成確定。他若加入，明天下午五點以前仍來得及。請他六點半以前不是明天，而是今天回覆，否則我們會錯過餐廳期限。你的呼叫器留言要寫清楚日期，只寫「下午」很容易各自理解。

文忠留給志明：

「星期六聚餐，現訂十一人。你若參加，請今晚上六時半前回我電話；逾時不列入訂位。文忠。」

志明回電：

我可以參加，是一人，不帶朋友。七點前會到。剛才看到留言時以為是明晚六點半，還好又問一次。請把我算入。

文忠致電阿敏：

志明確定，總數十二。沒有其他待確認的人。我現在請你改回十二，麻煩再問餐廳座位是否一樣。

阿敏致電餐廳後：

已改十二人，仍是兩張相鄰桌，時間不變。餐廳請我們不要在門口才臨時多帶人。若有人取消，明天下午五點前通知；之後若只少一人仍可入座，但請抵達時說明。這次訂位名稱改用你的姓氏，避免服務人員找不到「活動小組」。

呼叫器留言，星期四上午：

「文忠，餐廳訂位十二人已確認，請回電核對姓名與時間。阿敏。」

文忠回電：

核對：星期六晚上七點，十二人，訂位人姓陳，兩張相鄰桌。六點五十分以前至少一人先到。若今天下午五點前再有人取消，由我直接通知餐廳，也會告訴你，不讓兩個人重複改。

阿敏：

正確。還有，別在呼叫器只留餐廳電話，免得旁人誤認是要他們各自打去改位。統一由你聯絡，我只作備援。

星期五晚間，文忠留言：

「人數維持十二，無變更。明日六時四十分門口集合。」

阿敏回電：

收到。我會提早到。這幾天人數來回，不是誰故意麻煩，而是每次只說「有變」才讓人急。往後直接留「原十二、減二、加一、現十一」這類短句，呼叫器字少也能講明白。

聚餐後紀錄：

十二人均到場，餐廳依確認人數安排兩桌。文忠向大家說，下次先設一個回覆期限，確定者才計入；訂位後若變動，由單一聯絡人修改。短訊只作通知，細節用回電核對。這次雖改了兩回，至少最後的日期、時間、姓名與人數都沒有再靠猜。
