# 當地方活動碰上假日人潮影響安排

三月十二日，星期四。

今日收到文雄自淡水寄來的明信片，問我春假是否仍要到日月潭相會。他聽說假日旅客多，擔心臨時找不到投宿處，也怕船班擁擠。我原本以為只要搭火車到附近，再轉車即可，並沒有細問。如今想來，兩人各從不同地方出發，若只說「湖邊見」，恐怕從早等到晚也碰不到。

我寫回：「你在淡水出發以前，可否先到車站詢問班次？我這裡會向旅行過的同事打聽。若假日人潮太多，我們便改早一日動身，或把會面地點定在車站出口，不要各自憑想像走到湖邊。」寫到這裡有些不高興。這趟行程說了許久，每次問他，他總回「到了再說」。人多時怎能到了再說？

三月十六日。

文雄來信。他說淡水近來每逢休息日也有許多遊人，所以明白我的憂慮；但他仍未問到日月潭當地交通，只聽朋友說下車後「不遠」。這種回答等於沒有回答。步行一刻與轉車半日都可被人說成不遠。我在信紙旁重重寫了一句：「請問清楚要在哪一站換車。」寫完又覺得太像責備，便另添：「不是催你，只因我第一次去，想把路程安排妥當。」

同事淑惠去過日月潭。她提醒我，交通與船行會受天候和旅客多寡影響，舊遊記所記不可全信。她沒有替我保證班次，只說最好在途中提早詢問，並預留等候時間。她還說，若兩人預算有限，不必勉強住在景色最好的房間；先找乾淨、能歇腳的地方，早晨再到湖畔即可。

三月二十一日。

我又寫信給文雄：「投宿之事，你是否已託人詢問？價錢與空房若無法先定，也請告訴我，不要只回一個『大概可以』。我們可以改成當日往返，但末段交通必須留意。」這一次我沒有刪掉不滿。總不能凡事都由我問，他只帶一只皮箱便算準備完成。

三月二十六日。

等了五天，沒有回信。我開始懷疑他已改主意。下午去郵局仍沒消息，回家後把原定攜帶的衣物又收回櫃中。母親說，朋友之間不必為一次旅行鬧脾氣。我並非氣他不能同行，而是氣他不明說。若工作走不開，一句話就好；若仍要去，也應確認日期。

三月二十八日。

終於收到急信。文雄說先前寄出的信可能途中耽擱。他已請熟人代問住宿，假日前夕房間選擇少，價錢也比原先預想高；他不敢替我作主，所以遲遲沒有定。他提議把日月潭之行挪到平日，春假則先在淡水見面，由他帶我走老街和河岸。我讀到這裡，氣消了一半，又生出另一半：既然不知道怎麼決定，為何不早問我？

我回信說，淡水我也願意去，但不能把兩個地方當成隨意替換。日月潭需要較長路程，我已向人借了旅行袋，也請了假；若延期，須重新安排。請他回答三件事：哪一日能在淡水會面、到站後在哪裡等、日月潭改在何時再議。問題寫得明白，免得他又只說「隨時都行」。

四月二日。

文雄這回答得很快。他在信上畫出淡水車站附近簡圖，約我上午在出口旁的郵筒見，若彼此錯過，就到指定茶店留字條。他也承認，先前怕我嫌住宿貴，才一直不敢回覆。日月潭則等過了假日人潮，再由兩人各自確認交通與費用，不急著訂死日期。

我寫下最後安排：先赴淡水，輕裝往返；日月潭之旅保留，待資料較齊再定。此次最費心的不是遠路，而是話說得含糊。詢問活動不能只問「去不去」，還要問何時、何處、如何會合。假日人多，本來就會改變安排，提早說明不算掃興。若文雄下回又寫「到時再看」，我便把這幾頁日記寄給他看。
