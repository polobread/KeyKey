# 耐心說明地談分配家務

寄件人：素娟
主旨：這週借住期間的家務安排

麗華、志明：

謝謝你們讓我到城裡上課時借住。原先我們說我負責買晚餐和洗碗，志明倒垃圾，麗華洗衣。但這幾天連續下雨，衣服曬不乾，市場也提早收攤，原本分法變得不實際。我不希望因為自己是客人就什麼都不做，也不想大家每晚臨時猜誰有空。

建議先改一週：晚餐由最早回家的人買，費用記在廚房紙上；下大雨時不特地去市場，吃家中可存放的食物。洗衣減少次數，急用衣物優先。垃圾仍由志明處理，但若他晚班，由我在傍晚拿出去。你們覺得可以嗎？

素娟

寄件人：麗華
主旨：回覆：這週借住期間的家務安排

素娟：

謝謝你先提出。你不必因借住把所有空缺都補上。我這週下午在家，可以負責煮兩天，免得每天冒雨買飯。洗衣部分，公用毛巾和工作服先洗，其他衣服各自決定是否等天晴。室內不要掛得太密，會更潮。

志明最近下班時間不固定，垃圾不適合再固定由他一人。可改成誰晚飯後出門，誰順手帶；若沒有人出門，就等隔天，不為一小袋垃圾淋雨。

麗華

寄件人：志明
主旨：回覆：這週借住期間的家務安排

兩位好：

我可以繼續負責垃圾，但請不要因我晚回就一直等。晚上八點前我沒到，素娟若方便便拿；不方便就放陽台有蓋桶內，隔天我處理。我也能在早班日買菜，不過請前晚列清單，別只寫「隨便」，到市場才發現每個人的隨便不同。

至於洗碗，不必永遠由素娟做。煮飯的人不洗，另外兩人輪流，較公平。

志明

寄件人：素娟
主旨：整理後的雨天分工

我把大家意見整理如下：麗華本週煮兩晚，我煮一晚，其餘看下班時間決定買飯或吃存糧。志明早班日可依清單買菜。煮飯者不洗碗，另外兩人輪流。垃圾晚上八點作一次判斷，志明未回且我方便就處理，否則留到隔日。洗衣只做急用部分，各自衣物不混在一起。

還有一件小事：玄關一直堆著三把濕傘，容易滴水。是否指定浴室外的桶子放傘，由最後回家的人把地擦乾？這工作很小，但若沒說，通常是麗華默默擦。

素娟

寄件人：麗華

傘桶可以，地面誰弄濕誰先擦，不必指定最後回家的人。若是不知道哪一把滴水，就看到的人順手處理。我想避免把每件小事都排班，但也不要把「順手」當成我來做。

另外，我週四原本要煮飯，天氣若仍不好，公司可能提早下班，也可能反而延遲，不一定。週四下午我會再寄信確認，不先算我必定能煮。

寄件人：志明

明白。這封信留作共同安排，不代表誰一次沒做到就欠另一人。天氣和班次改變時，先說做不到，再由其他人決定接手或把事情延後。非必要的清掃可等週末，不用雨天把屋子整理得像迎賓。

三日後

寄件人：素娟
主旨：雨天分工小結

這幾天安排大致可行。昨天志明臨時晚班，垃圾留到今天，沒有造成問題；麗華週四回得晚，我們改煮麵，也沒有誰冒雨買飯。唯一混亂是洗衣，我把一件不急的衣服也放進去，讓晾衣空間不夠，這點是我判斷錯，已移到室內衣架。

雨停後，我們是否恢復原分工，想先問過再決定。有些新做法其實較好，例如煮飯者不洗碗、買菜先列清單，可以留下。

寄件人：麗華

同意保留這兩項。垃圾和洗衣則回到各自容易記的方式。謝謝你們在天氣打亂安排時先說明，不把臨時協助變成永久責任。朋友同住，耐心講清楚何時能做、何時需要幫忙，比計算誰多洗一只碗更有用。
