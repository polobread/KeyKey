# 從宵夜照片開始的即時吐槽

阿威：你傳的宵夜照片太過分了。我人在離島值班，只能配著冷茶看球賽，你那碗麵還冒煙。

俊傑：先說，我不是炫耀，是麵自己很上相。比賽看到一半肚子餓，隨手拍給你而已。

阿威：你這句跟「我只是路過甜點店」一樣可信。現在場上還沒得分，我的胃已經先輸了。

俊傑：你那邊沒有東西吃？

阿威：有餅乾，但包裝上畫的是豪華起司，打開只有三片薄得能透光。這不是宵夜，是食物寄來的明信片。

俊傑：先墊一下，別空腹撐到比賽結束。你明天還要早起吧？

阿威：本來要吐槽球賽，怎麼變成健康關懷專線？放心，我有正常吃晚餐。只是看到你的照片，胃突然想加班。

俊傑：好，那回球賽。剛才那球你覺得有機會嗎？

阿威：有，機會大概跟我從照片裡夾到麵一樣大。傳球慢半拍，對方早就站好了。

俊傑：你今天很酸。是不是值班又遇到麻煩？

阿威：沒有大事，只是大家接力把話題越講越遠。下午原本問一張報表，最後聊到辦公室盆栽誰澆水。現在原本看球，又聊到我的餅乾厚度。

俊傑：盆栽有解決嗎？

阿威：你看，話題又自己長腳跑了。解決了，隔壁同事說那盆是塑膠的，難怪澆了一個月都很堅強。

俊傑：等一下，這比球賽精彩。有人真的澆塑膠盆栽？

阿威：據本人辯稱，只是擦灰塵時順手倒一點水。我沒有查證，請勿當成公司正式公告。

俊傑：那盆栽目前戰績全勝，水、陽光、假日無人照顧都影響不了它。

阿威：球隊若有這種穩定度，我就不用半夜對著螢幕嘆氣。

過了十幾分鐘。

俊傑：怎麼沒回？不會真的只剩冷茶吧？

阿威：剛才有工作電話。我還在。比賽也還在，只是分數讓人想假裝網路斷線。

俊傑：如果累就別硬看。重播或賽後消息明天再看也行。

阿威：我知道。其實今天心情有點悶，才一直吐槽。這週本來以為能回本島，臨時又要留守。看到你吃宵夜、在家看球，突然有點羨慕。

俊傑：原來是這樣。你不必用餅乾和球隊把難過包起來。臨時不能回來確實會失望，尤其行李都可能收好了。

阿威：收了一半，連要帶回去的伴手禮都放桌上。現在它們每天看著我，像在問船票呢？

俊傑：那就先放好，等確定能回再出發。今晚我陪你看到這一節結束，不把話題硬轉成正能量。你想罵傳球就罵，想說值班也可以。

阿威：謝啦。我也不是需要解決方案，只是想有人聽。剛才嫌你麵太香，不是真的怪你。

俊傑：我知道。我也收回「隨手拍」那句，半夜傳熱食照片確實帶有攻擊性。下次先附警告：觀看可能引起飢餓。

阿威：最好還要附實物補償。等我回去，你請一碗。

俊傑：成交。現在先把餅乾吃掉，冷茶換溫水。比賽輸贏我們管不了，至少別讓你明天胃不舒服。

阿威：收到。場上剛追回一分，我宣布麵照帶來好運。話題從宵夜繞過球賽、盆栽、值班，又回到宵夜，完整一圈。

俊傑：這才叫即時吐槽。你若想睡就直接說，不必陪我撐完全場。

阿威：再看一下。今天不能回家很悶，但有人一起講廢話，房間沒那麼安靜了。等這段結束我就去睡，明早還要把真正的報表完成。

俊傑：好。明天報表若又一路談到盆栽，記得把大家拉回主題。私人難過不用在公司交代，工作交接只寫真正需要知道的部分。

阿威：明白。留守安排我會照程序確認，回程也等正式通知，不拿猜測折磨自己。至於今晚，球隊又把球傳丟了，我只允許自己嘆三口氣。

俊傑：已經第四口了。我替你記帳，回來用一碗熱麵抵銷。

阿威：成交。謝謝你沒叫我「想開一點」就結束，也謝謝那張很過分但確實有效的照片。現在去倒溫水，等這節打完收工。
