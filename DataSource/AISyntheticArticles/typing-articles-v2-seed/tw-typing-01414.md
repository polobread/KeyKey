# 一場圍繞轉乘路線的確認末班時間

【旅遊筆記：北部兩日行】

這趟全家出門，最難的不是找景點，是確認轉乘後的末班車。父親看報紙上的班次表，母親拿旅館寄來的交通說明，我則抄車站公告。三份資料寫法不同，有的列平日，有的把假日另放一欄，還有一張已經褪色。誰都說「大概趕得上」，沒有人敢說究竟是哪一班。

第一天早上，先在車站窗口問。我的問法原是：「晚上最晚幾點還有車？」站務人員反問要去哪裡、哪一天、在哪站轉。我才知道只問一個末班時間不夠。從市區回住宿處要先搭火車，再換公車；前段有車，不代表後段接得上。改成完整問法：「週六晚間從市區出發，到轉乘站後還要換往山邊的公車，最晚應搭哪一班前段車？」答案才有用。

父親：把時間寫在紙上，不要只靠記。

我：已寫。但窗口說公車班次要到另一處問，不能拿火車到站時間直接推。

母親：那就先問公車，再往前倒推。還要留走月台、找站牌的時間。

我們到公車站，服務人員翻查當日表，再提醒末班可能因路況變動，旅客仍應提早候車。我沒有在筆記裡留下具體鐘點，因為那是當年、當日查到的資料，不適合讓後來的人照抄。我只記方法：先確認日期，再問方向；把「最後發車」和「最後能接上」分開；得到答案後請對方複述站名，避免同音地名聽錯。

下午逛街時，弟弟一直說還早，想多看一家唱片行。父親拿出紙條：「我們不是怕錯過市區這班，是怕到轉乘站後沒車。」弟弟這才同意提早走。旅遊中一句短提醒，比一路催「快一點」有效。催快不知道為什麼，說明是哪一段會斷，大家才會配合。

到轉乘站後，我們發現候車處和旅館來信畫的位置不同。原來站牌因施工暫移，紙本說明沒有更新。母親去問售票處，我留在行李旁，父親到可看見兩邊入口的位置等。沒有人拖著箱子分頭亂跑。確認新站牌後，我們搭上較早一班車，沒有把行程押在末班。

【住宿心得】

旅館接待人員事前來信寫得很客氣，但「下車後步行不遠」對第一次到訪的人仍太模糊。我們抵達後向他反映，他拿出簡圖，補畫轉彎處和醒目店面，也承認舊信沒有提到站牌移動。這不是要責怪業者，而是提醒住宿說明應同時寫站名、方向和找不到時的電話。旅客也要在白天確認，不要深夜才拿著舊地址四處問。

第二天原想去更遠的步道，母親問：「回程末班查了嗎？」大家一時答不出。這次沒有再說到時候再問。我們在旅館櫃檯借電話，分別詢問兩段交通，並把每次對話記下。若只能趕上最後一班，就縮短行程；若中間沒有足夠轉乘時間，就換近一點的去處。最後選了市郊公園，少搭一段車，玩得反而從容。

【給下次同行家人的備忘】

一、末班時間要按日期與方向確認。二、轉乘行程看的是整條路線，不能只問其中一段。三、紙本時刻表、旅館來信和車站公告若不一致，以當日向運輸單位確認的內容為準。四、行李、老人與小孩都會增加步行時間，別把到站和上車算成同一刻。五、最好提早一班，不以追到末班為成就。

九〇年代前半已有電腦印出的表格，但更新未必立即送到每位旅客手上；電話能問，對方也需要知道你問哪一天、哪條線。這次行程教我們，確認不是重複問「真的嗎」，而是把站名、方向、日期和銜接逐項說清楚。少逛一家店，總比全家在陌生站口爭論誰記錯好。
