# 客氣克制地談飲料甜度冰量

雅婷：午休要一起訂飲料嗎？我準備統計，但每個人口味不同，先問清楚。妳今天想喝什麼？

佩君：可以，謝謝。紅茶拿鐵，少糖少冰。如果那家少糖還是很甜，就改微糖。

雅婷：我沒喝過，無法判斷他們家的少糖有多甜。妳要不要直接選微糖？

佩君：嗯……可以。不過我怕微糖喝起來完全沒味道。店家的甜度是不是正常、少糖、半糖、微糖、無糖？

雅婷：菜單寫正常、七分、半糖、三分、無糖。大家平常說的少糖，在這家可能是七分，也可能只是泛稱。我不替妳猜，妳選一個明確比例吧。

佩君：那三分糖、少冰。等一下，紅茶拿鐵如果少冰，會不會補很多茶，味道變淡？

雅婷：菜單沒寫補茶或補奶，我不能保證。可以幫妳備註「少冰，不加滿亦可」，但店家是否接受要看現場。

佩君：好，就這樣。妳自己呢？

雅婷：我想喝青茶無糖、去冰。但上次去冰放久變溫，我下午才喝，正在猶豫。

佩君：那點微冰？至少還有幾顆冰塊。妳不是最怕溫茶嗎？

雅婷：對，改微冰。我的「微冰」就是店家選項，不是請店員數三顆冰塊，免得備註太為難人。

佩君：哈哈，好。還有志豪剛說「跟上次一樣」，妳知道他上次喝什麼嗎？

雅婷：不知道。他每次都以為全世界共用他的飲料記憶。我剛問了，還沒回。

佩君：先別替他點。他若過截止時間才回，就讓他自己買，這樣比較公平。

雅婷：我會再提醒一次，不過口氣客氣點。這團不是軍令，只是外送要在十二點前送出。

雅婷：志豪，飲料十二點截止。請回品項、甜度、冰量；「照舊」無法辨認，麻煩直接寫一次。

志豪：剛在開會。烏龍鮮奶茶，半糖，正常冰。

雅婷：收到。你上次好像說不要太冰，這次確定正常冰嗎？

志豪：妳一問我又想起來了。改少冰，半糖不變。

佩君：這家的選項好像叫微冰，沒有少冰？

雅婷：菜單有正常冰、少冰、微冰、去冰，兩個都有。不要把少冰和微冰混在一起。

志豪：那就少冰。謝謝妳們把我的飲料當專案審查。

雅婷：因為喝錯的人最後也會開檢討會。先確認總表：佩君紅茶拿鐵，三分糖，少冰，備註不加滿亦可；志豪烏龍鮮奶茶，半糖，少冰；我青茶，無糖，微冰。

佩君：我的備註若店家不能做，就維持少冰，不必另外打電話來回問。

雅婷：了解。還有小敏託我點檸檬茶，只說不要太甜。我請她補明確甜度，她回「妳看著辦」。這種要怎麼處理？

志豪：叫她選，不然妳選完她若不喜歡，兩個人都尷尬。

佩君：可以傳菜單截圖，請她在三分和半糖裡挑一個。她可能只是不知道有哪些選項。

雅婷：已傳。小敏回三分糖、正常冰，還說謝謝提醒。果然不是故意丟問題，只是沒看到菜單。

佩君：款項怎麼給妳？

雅婷：飲料送到、確認沒有缺杯後再一起收。價格以訂單顯示為準，我先貼總額和個別金額，大家核對自己的就好。

志豪：我的杯子麻煩標名字，不然烏龍和紅茶顏色一樣，我又會拿錯。

雅婷：會請店家貼標籤，我也在總表寫品項。若店家只寫甜度冰量，拿之前再問，別先插吸管試味道。

佩君：最後再確認，我的是三分糖，不是「少糖」。今天總算學到，同一個口語到了不同店家可能對不上選項。

雅婷：對。訂單已送出，店家回覆備註可以接受，但飲料不加滿的程度由現場製作。預計時間只是系統估計，大家先照原本午休安排，不用在門口排隊等。

志豪：收到。我這次把半糖少冰記在手機，下回不再說照舊。

佩君：我也記三分少冰。若喝完覺得仍太甜，下次調無糖，不在今天臨時改單。辛苦統計了。

雅婷：不辛苦。大家願意把甜度和冰量說成店家看得懂的選項，就已經省掉一半來回確認。
