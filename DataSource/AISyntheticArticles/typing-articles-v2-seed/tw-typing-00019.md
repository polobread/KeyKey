# 遊戲隊友正在討論看球賽即時反應

隊長：各位晚安。今晚一起看球可以，但先提醒，群組裡還有人晚點才看重播。若要報比分，請在訊息開頭寫「即時戰況」，讓他能先跳過。謝謝配合。

阿榮：即時戰況：第一球就打得好遠！差一點，我的鹽酥雞差點跟著飛出去。

小孟：謹慎更正，那叫界外球。你的雞排目前安全，球隊的得分仍然是零。

老蔡：講到雞排，鎮口那家今天排了十幾個人。我懷疑全鄉的人都用同一場球賽當晚餐理由。

隊長：請先回到球賽。現在投手連續兩顆偏高，捕手上去談話。

阿榮：他們大概在討論要不要加辣。

小孟：依現場畫面判斷，沒有任何一位球員手持胡椒粉。這則即時吐槽雖有創意，與比賽無關。

老蔡：說到胡椒粉，我爸以前種胡椒……

隊長：停。話題已從投手丘走到農田，距離有點遠。請問剛才那球到底算好球嗎？轉播聲音太小，我沒聽清楚。

（群組安靜了三分鐘。）

隊長：有人看到嗎？我再問一次，剛才滿球數那一球，裁判判什麼？

阿榮：抱歉，剛去拿飲料。是壞球，打者保送。順便說，我家的冰箱門關不起來，有沒有人會修？

小孟：先答球賽：壞球，四壞保送。至於冰箱，建議另開一個話題，不然等一下有人以為保送是冷凍功能。

老蔡：冰箱門通常是東西塞太滿。我上次一盒魚丸卡住……

隊長：正式提醒一次：目前討論項目是球賽即時反應。家電維修與魚丸保存，請比賽後再談。並非禁止聊天，只是訊息跳太快，真正的戰況會被洗掉。

阿榮：收到，隊長語氣像在宣讀比賽章程。那我嚴謹報告：跑者盜壘成功，畫面沒有冰箱，也沒有魚丸。

小孟：確認。補充，捕手傳球稍偏，二壘手沒有接穩。請勿把失誤怪給雞排攤。

老蔡：本人接受勸導。接下來只談球。可是廣告出現海產餐廳，這算轉播主動離題，不是我。

隊長：廣告期間可以短暫離題，但恢復比賽就收回來。好，現在有人出局了嗎？

阿榮：還沒有。打者一直碰成界外，投手已經投很多球。這一棒很黏，比我機車座墊被飲料潑到還黏。

小孟：比喻准予通過，因為至少仍在描述打席。

老蔡：那我可以說投手表情像月底等薪水嗎？

隊長：可以，短一點就好。群組現在不是作文比賽。

阿榮：即時戰況：安打！二壘跑者繞過三壘，正在衝本壘——

小孟：安全回來。追平。

老蔡：我剛才大叫，隔壁以為停電。這個算生活回報還是球賽反應？

隊長：算，因果關係明確。請繼續。

小孟：建議後續用簡短格式：「局數、出局數、壘上情況」。吐槽放下一行。這樣晚加入的人不用從胡椒、農田、冰箱一路考古。

阿榮：同意。我示範：後段局數，一出局，一壘有人。吐槽：投手教練走得比我去繳帳單還慢。

老蔡：我也來：換投完成，壘上仍有人。吐槽：大家剛才講了半天，最穩定的竟然是隊長的勸導。

隊長：謝謝，但請不要把我變成下一個離題主題。比賽結束後再自由聊天。我會把重要戰況整理在一則訊息裡，留給看重播的人決定是否閱讀。現在最後一個半局，先專心。

阿榮：了解。若再離題，我自願把雞排分一塊出來。

小孟：此承諾與球賽無關，但具有高度執行價值，建議保留紀錄。

老蔡：附議。群組終於形成正式結論：戰況要清楚，笑話要適量，雞排要分享。

隊長：補充紀錄，比賽結果由轉播畫面確認，雞排分配則由當事人自行協商。請各位不要在明天上線打遊戲時，說今晚只討論了冰箱。重要的追平安打，我已經另外整理好了。
