# 怎麼把詢問末班車說清楚

明德兄：

下月本處派我們到南部鄰縣查核倉庫，我已收到你轉來的旅社地址。只是回程交通仍有一點不明，想請你代為確認。公文所附時刻表印得模糊，我看末班車像是傍晚六時，又像六時半；同事口述則說七時前尚有一班。三種說法不能相合，若照錯了，我們會困在轉運站。

煩請你詢問車站：星期六從倉庫附近那一站往市區的末班車，究竟幾時開出？我問的是經過該站的時間，不是車輛由總站出發的時辰。若需轉車，也請確認接續班次是否還趕得上。倘若末班時間不容易確認，我們寧可提早收工，不宜憑猜測冒險。

住宿方面，我原先訂了市區飯店，交通便利，但費用較高。倉庫附近有人介紹一間民宿，另有青年旅館可住；若末班車太早，或許就近住一晚較穩妥。請先不要替我付訂金，等車班查明再定。

祝工作順利

同事志宏敬上

志宏兄：

來信收到。我昨日趁午休到車站詢問，售票員翻閱簿冊後，只說平日與假日不同，星期六究竟採哪一表，要等調度室答覆。我再問「最後一班幾點經過倉庫站」，他仍不能立即確定，只抄下一支站內電話，叫我隔日再問。故目前尚無可靠答案，請勿把六時半當作定案。

我也向附近雜貨店打聽。店主說末班車有時提早經過，但這只是居民印象，不能作準。你要的問法很清楚，我已另外寫下日期、方向、上車處與下車處，明日會請調度員逐項核對。若只問「還有沒有車」，很容易把對向班次也算進去。

住宿我順路看過。飯店靠近市區車站，翌日轉乘方便；民宿離倉庫近，但晚飯得走一段路；青年旅館床位較簡單，適合省費用，未必適合攜帶公文與器材。至於露營地，雖有人提起，此行是公務，夜間保管文件不便，我不建議。等末班時刻確定後再比較住宿地點，較為妥當。

同事明德覆

明德兄：

謝謝你親自走一趟。兩日未見後續消息，我再寫信追問，並非催促，只因出發日漸近，須向主任回報。調度室可曾答覆？請特別確認所稱末班，是從總站發車，還是抵達我們上車處的時間。這兩句意思相近，實際卻可能差上一段路程。

若仍無法查明，我建議採保守方案：工作在下午提早結束，先搭前一班進市區，再住原訂飯店。這樣即使途中延誤，也不必趕最後一班。若你確認尚有足夠轉乘時間，我們才改住倉庫旁的民宿，次日再回。請回信時不要只寫「大約傍晚」，要把詢問對象與所依時刻表一併註明。

志宏再上

志宏兄：

今日已取得調度室回覆。他們說舊表仍貼在候車亭，難怪你我所見不同；星期六應依另一份班表，但遇道路受阻仍可能誤點。我不在信中另抄一個時刻，免得轉寄時又抄錯。我已請站方在班表上圈出我們要搭的那一班，隨信附上影本，並請售票員蓋章註記。你抵達後仍應當面再確認末班時間。

依目前安排，搭前一班最穩當。我贊成提早收工、進市區住宿。飯店雖較遠，卻省去隔日清晨兩次轉乘；民宿留作臨時備案。青年旅館與露營地此次都不採用。主任若問，可以說我們並非不知道末班幾點，而是站方資料曾有新舊之別，所以選擇保留餘裕。

出差回來後，我會把車站詢問經過、住宿整潔情形與轉乘是否順利寫成簡短旅後評論，留給往後同仁參考。評語只記親身所見，不把傳聞寫成事實。如此下次有人辦同一路線，也不必再從模糊的時刻開始查起。

明德敬覆
