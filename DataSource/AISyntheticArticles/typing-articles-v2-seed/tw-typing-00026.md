# 集合訊息與那次朋友約宵夜

標題：週五看完電影吃宵夜？

發文者：夜貓阿凱

電影散場大概十點。有人要去吃宵夜嗎？先問人數，我再打電話訂位。想吃熱炒或豆漿都行，別回「隨便」，隨便最難約。

推 小嘉：我＋一。熱炒。

推 志明：先算我，可能晚十分鐘。

推 阿萍：哪一區？我沒機車。

→ 夜貓阿凱：北部郊區，戲院附近。可以走路，或大家一起叫車。

推 老周：那家熱炒週五晚上很滿，上次等到快睡著。你先問有沒有位。

→ 夜貓阿凱：剛打了，占線。等等再撥。

推 小嘉：不然吃豆漿店，桌子轉得快。蛋餅兩份、鹹豆漿一碗，我已經想好了。

推 志明：你是約宵夜還是先點餐啦。

噓 小嘉：先想好才不會站在櫃台發呆。

→ 夜貓阿凱：熱炒店回了，熱門時段不留桌，只能現場排。老闆說十點多還是可能客滿。要不要改豆漿？短句回答：熱炒／豆漿。

推 阿萍：豆漿。沒座位我不想站門口吹風。

推 老周：豆漿一票。吃完還能搭末班車。

推 志明：熱炒。難得大家到齊，坐下來慢慢聊比較有意思。

推 小嘉：我改豆漿。不是變心，是怕等座位等到店家打烊。

→ 夜貓阿凱：三票豆漿，一票熱炒。還有誰？阿哲有看到嗎？

（二十分鐘後）

→ 夜貓阿凱：阿哲？你要來就回一下，我要抓人數。

推 老周：他宿舍網路可能又斷。傳簡訊比較快。

→ 夜貓阿凱：傳了，等他回。集合先定戲院一樓售票口右邊，不要只說門口，那裡有兩個門。

推 阿萍：我九點半才下課，直接到戲院可以嗎？電影票你們先買，我到了再拿。

→ 夜貓阿凱：可以。若趕不上開場就打我按鍵手機，不要只留板上，我進戲院看不到。

推 志明：等等，原本不是先看電影再吃？阿萍九點半到，會錯過大半吧。

推 阿萍：啊，我把時間看成九點半開演。抱歉。那我只參加宵夜，你們散場傳簡訊給我。

→ 夜貓阿凱：收到。一樣算吃飯人數，不算電影票。

推 阿哲：現在才連上。我去，豆漿可以。別為我等位子，我自己騎過去。

→ 夜貓阿凱：好，五個人吃，四個人看電影。決定豆漿店，不排熱炒。散場後走過去，先到的人占一桌，但如果客滿就外帶到旁邊空地聊。

推 小嘉：外帶要記得多拿筷子。上次五個人只有兩雙，大家像在玩接力。

推 志明：我的雞排可以用手，不搶筷子。

→ 夜貓阿凱：別鬧。點餐先不統一，我們到現場各點各的。阿萍如果先到，麻煩回板上說有沒有座位；沒辦法上網就傳簡訊給我。就照辦。

【週五晚間更新】

→ 夜貓阿凱：電影結束，人潮很多。阿萍說店內滿了，外面還有幾個位置。我們走過去，約十分鐘。阿哲別跑去原本那家熱炒。

推 阿哲：收到。我已經在豆漿店附近，看到排隊了。要先幫忙點嗎？

→ 夜貓阿凱：先不用，怕每個人臨時改。幫忙看一張能坐五人的桌，沒有就兩桌靠近也行。

推 阿萍：剛空出一桌，我先坐。店員問幾位，我說五位。你們快到再點，免得東西冷掉。

推 小嘉：快到了。我要蘿蔔糕一盤，剛才說的蛋餅改一份，鹹豆漿照舊。

推 志明：這就是你說的不要站在櫃台發呆？

推 小嘉：對，我在路上就改完了。

【隔日心得】

→ 夜貓阿凱：昨晚成功集合。雖然沒吃成熱炒，至少沒把半夜浪費在等桌。下次熱門時段若店家不接受訂位，就一開始準備兩個選項。有人晚到，也要分清楚是電影人數還是吃飯人數。照片先別一張張寄信，檔案太大；挑幾張壓小再傳。宵夜很好吃，笑話很冷，散會。
