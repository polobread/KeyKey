# 當延後辦理入住碰上店家尚未回覆

冠廷：民宿有回你嗎？我們的火車延誤，原本的入住時間趕不上了。

怡君：還沒。我十五分鐘前傳訊息，顯示已送出，沒有已讀。

冠廷：要不要再傳一次？

怡君：先不要連續洗訊息。我已寫訂房姓名、日期、預計晚到，請他們確認能否延後辦理入住。

冠廷：我們大概幾點到？

怡君：現在不能確定。火車尚未恢復行駛，轉車也可能受影響。我只寫「將晚於原約時間」，沒有亂報一個時刻。

冠廷：可是店家若提早休息怎麼辦？

怡君：這就是要確認的。我正在找訂房確認信，看有沒有晚到聯絡方式和入住說明。

冠廷：找到了嗎？

怡君：確認信只寫需要事先通知，沒有說可自行進入。我會打訂房頁列的電話，不從搜尋結果隨便找號碼。

冠廷：好。我們兩個不要同時打，免得店家接到兩組說法。

怡君：我打，沒接。已留簡短語音：「今日訂房旅客因交通延誤，會晚到，請回電確認入住方式。」

冠廷：收到。那現在要改住車站附近嗎？

怡君：先不急著另外訂。原訂房還沒確認能否取消，新訂也可能產生費用。等交通資訊和店家回覆，兩邊一起判斷。

冠廷：如果半小時都沒回呢？

怡君：再打一次，並透過原訂房管道留言。不是一直催，而是留下我們已通知晚到的紀錄。

冠廷：我先把訂單資料整理好。要不要傳身分證照片？

怡君：不要。店家沒要求，也不該在一般私訊先傳證件。只提供核對訂房需要的資料。

冠廷：火車廣播說即將恢復，我估到民宿可能接近晚上十一點。

怡君：先寫「若轉乘順利，可能接近十一點」，不要說一定十一點到。我現在補傳更新。

冠廷：店家還是沒讀。

怡君：我知道。請你先看轉乘後還有沒有大眾運輸；若沒有，我們要提早決定安全的移動方式。

冠廷：末段交通查到了，但當天狀況仍要現場確認。我不把班次貼死。

怡君：好。店家剛回：「收到晚到通知，正在確認值班人員，稍後提供方式。」至少不是失聯了。

冠廷：那我們等。這句還不算已同意十一點入住吧？

怡君：對，只代表收到。要等他說明誰接待、在哪裡辦理，不自行假設鑰匙放門口。

冠廷：又過二十分鐘，還沒下文。要追問嗎？

怡君：可以。我寫：「我們已恢復行程，預估接近十一點抵達。請問可否延後辦理入住？若不便，請告知替代處理。」

冠廷：清楚。也把聯絡電話給他，別只靠私訊。

怡君：已附末幾碼請他核對，完整電話沿用訂單資料。

店家轉覆：值班人員會等候，抵達前二十分鐘請電話聯絡。入口夜間會關閉，不要自行推門；入住資料到場核對。

冠廷：收到。那我們到轉乘站後再更新一次。

怡君：對。你負責行李，我負責聯絡。若時間又變，不用兩個人各傳一版。

冠廷：到轉乘站了，預估時間只差幾分鐘。要通知嗎？

怡君：照店家要求，抵達前二十分鐘打電話。我先傳「行程恢復，稍後致電」，避免對方以為又取消。

冠廷：已經接近了。

怡君：電話確認完成，值班人員知道我們晚到。店家請我們慢慢走，不用趕。入住規則沒有因晚到免除，仍要現場核對資料。

冠廷：好。這次重點記住：通知晚到只是第一步，收到店家明確回覆才算安排完成。

怡君：沒錯。抵達後我再回一則，結束這串紀錄。

怡君：已辦理入住，房型與訂單一致。謝謝你一路確認交通，今晚先休息。

冠廷：收到，也謝謝妳統一聯絡。明早退房時間我們看現場提供的說明，不沿用原先猜測。
