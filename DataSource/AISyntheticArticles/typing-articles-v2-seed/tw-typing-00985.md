# 帶著不滿地談維修後問題仍在

三月初五，顧客留言：前日將家中座鐘送來修理，店中說是機芯積塵，清理上油即可。昨日取回，當晚尚能行走，今晨卻又停在四點一刻。發條明明已上足，鐘擺也照掌櫃所教輕推，走不到半個時辰便慢下來。修理費已付，問題仍在，請勿只叫我再上一次發條。

三月初五，店家回覆：承蒙留言。座鐘在店內試走兩個時辰，當時並未停擺。鐘若放在傾斜桌面，或搬運時受震，鐘擺會偏向一側。請先察看木櫃是否平正，左右墊紙試聽聲音；滴答若一邊快、一邊慢，即需重新校正。若仍無改善，煩請再送來，我們願意複查。

三月初六，顧客留言：照所寫的方法做過了。桌面原本就平，墊紙後聲音稍齊，仍在一個時辰後停止。家父腿腳不便，要靠座鐘掌握服藥時刻，我並非為了幾分快慢挑剔。昨日既說修好，今日又要我從城南抱到店裡，實在讓人不滿。可否派學徒到家查看？

三月初六，店家回覆：前次只收清潔與上油費，並未更換零件。若發條盒或擒縱叉有暗傷，短時試走未必立即顯現。您說的停走情形，我們已記下。今日人手皆有約，明日上午可請學徒往城南查看；到府只檢查放置與鐘擺，不在家中拆開機芯。若須拆修，仍要帶回店內。

三月初六，顧客補記：明日上午家中有人。請學徒先到巷口米店詢問陳宅，不必再繞去舊門牌。還請帶上次收據存根查對，我不願同一問題再算一次工錢。若確為另一處損壞，也請先說價錢，不要修完才通知。

三月初七，學徒查後記錄：上午到陳宅，座鐘置於高櫃，櫃腳尚穩。輕推鐘擺，約一刻鐘後擺幅漸小；改變墊紙亦無效。顧客所述屬實，並非未上發條。外殼無新碰傷，搬運途中以棉布包妥，現帶回店中詳查。未經顧客同意，不另換零件。

三月初八，顧客留言：昨日已讓學徒帶走，請問查出原因沒有？家父一再問鐘何時回來，我只能借鄰居的小鬧鐘暫用。上次等候三日，取回仍舊停擺，這次請給明白答覆。能修便說何日完成，不能修也請早些退回，不要一直擱在後間。

三月初八，店家回覆：拆查後發現擒縱叉的固定處略鬆，機芯走熱後位置偏移，因此初試正常，久走才停。這是前次清理時未察覺的毛病，本店應負複查不周之責。固定與校正不另收工錢，今日午後起連續試走，若至明日上午無停擺，再送回府上。舊發條尚可使用，不必更換。

三月初九，顧客留言：既說是前次未查出的毛病，我接受不另收費的處理。不過「試走一晚」請確實做到，不要只看幾刻鐘就算完畢。我寧可晚一天取回，也不要第三次報修。送回前請把鐘面玻璃擦乾淨，上次留下幾個手印，雖不妨礙走時，看了總不舒服。

三月初十，店家回覆：座鐘自昨日下午至今日上午連續行走，整點報時與分針皆正常，已由兩人分別記錄。玻璃亦已清理。下午由原學徒送回，放妥後會在府上再看一刻鐘，並向家人說明上發條的方向與每次圈數。此次不收任何費用，收據背面加註返修原因。

三月初十，顧客補記：鐘已送回，至晚間尚未停。學徒這次說明清楚，也沒有急著離開。我要說的並非店家不能失手，而是出了問題，不應先猜顧客桌子不平或操作錯誤。若一開始就肯承認還需詳查，我也不會寫得這樣重。且再觀察兩日。

三月十二，顧客末記：座鐘兩日皆能正常行走，家父服藥也恢復照鐘面安排。此案可以結束。仍希望店家往後接到報修，先把顧客所述的停走時刻、持續多久與已試方法逐項記下；同一故障返修時，也應主動說明是否收費。耐心不是反覆叫人再試一次，而是把未解決之處查到明白。

三月十二，店家答覆：所言甚是。本店已另備修理簿，記下送修現象、試走時數、換件與收費，交件時由顧客查閱。往後若維修後問題仍在，憑原收據即先複查，不使顧客重述多遍。此次勞您往返並耽誤家中使用，謹致歉意，也謝謝您在問題真正排除後再來告知。
