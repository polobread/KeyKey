# 關於家人對選擇不認同的那段電子布告欄

【南方小站／心情板】

主題：想離開家裡的工廠去念夜校，家人都說我不知足

發表人：海風吹過

家在南部小鎮，父親開一間小加工廠，我畢業後便留下幫忙。做了兩年，我決定白天上工，晚上搭車去市區念夜校，學會計。不是嫌家裡，也不是要立刻離家。我想把帳務學完整，以後多一點選擇。

父親聽完很生氣。他說鄰居家的孩子找不到工作，我有現成的位置還往外跑；母親比較軟，卻一直勸：「我們都是為你好，別想那些不實際的。」她本來是在安慰，聽進我耳裡卻像說教，好像我一提出不同打算，就是不懂事。

我不希望大家罵家人。怎樣解釋選擇才不會變成頂嘴？

回覆人：舊鍵盤

你父親可能聽見的是「你不要家裡了」，你真正要說的是「我仍會負責，但想多學一項本事」。把上課日、交通、工作如何交接寫成一張紙，比只講理想有用。

回覆人：木棉花

家人若每次都用「為你好」壓過你的話，你也會累。可以說：「我知道你們擔心，但請先聽我講完。」

發表人：海風吹過

謝謝。我昨晚又談一次，開頭就失敗。母親說：「你辛苦一天還去上課，身體撐不住。」我回：「我自己的身體自己知道。」她立刻掉眼淚。後來父親把招生紙收走，叫我不要再提。

我不是要證明他們錯，只怕每年都說明年再想。

回覆人：舊鍵盤

那句話容易被聽成不需要家人。可以改成：「我知道你怕我太累，所以先試一學期；若工作受影響，我會重新安排。」

回覆人：阿姊借帳號

先問一件事：工廠晚上是否常臨時加班？若你沒有處理這點，父親反對不全是情緒。遇到趕貨怎麼辦？

發表人：海風吹過

通常月底較忙。我可以跟叔叔換班，但還沒談。我原先以為報名是自己的事，現在看來工作安排要先說明。

回覆人：阿姊借帳號

選擇是你的，影響到別人的班就要協調。這跟能不能念書是兩回事。

發表人：海風吹過

隔了兩天更新。我寫好每週哪幾晚去上課、趕不上車怎麼辦。也跟叔叔談過，他願意在固定兩晚接最後一班，我早上多做整理。

父親仍說：「你就是心野了。」我忍住反駁，只說：「我去念書，不等於否定你。家裡帳目常靠記憶，我才想學得更穩。」他沒有答應。

回覆人：木棉花

至少你已把意思講清楚。不必每次衝突都在當晚和好。但要留意報名期限，別無限期等待。

回覆人：舊鍵盤

對母親可以單獨說。道歉的是口氣，不是你的選擇，兩者別混在一起。

發表人：海風吹過

昨晚我跟母親說：「那天我把妳的擔心擋回去，對不起。我還是想念，但不是不要妳管。」她問是不是站上的人教我說的。我說是冷靜後才知道那句話傷人。她沒有支持，只把招生紙還我。

父親問，畢業後我是不是一定離開。我回答：「我不能保證一輩子留在這裡，也不能說讀完就走。我能答應這學期工作不丟著。」他嫌答案滑頭。我說，講做不到的保證才是真滑頭。

回覆人：阿姊借帳號

這回答很實在。你想為將來負責，不是把後果推回家裡。學費、交通由誰負擔，也要講明。

發表人：海風吹過

最後回報。我用存款付第一學期，不向家裡開口。父親沒贊成，但同意報名，旺季安排每月重談。

這不算皆大歡喜。父親還是不喜歡我的決定，我也仍委屈。不過我們終於在談「怎麼做」，不再只說「你不懂」。我的心得是：解釋選擇時，把責任、時間和可能改變的地方說清楚；也可坦白，安慰若一直否定你的感受，就不像安慰。家人的關心要聽，自己的話也該讓他們聽完。
