# 會議紀錄裡的回報進度

【跨部門專案會議紀錄】

主旨：倉儲改建專案延遲，請各部門分別回報已完成事項、卡點、責任人及修正版時程。

主席：原進度表只寫「等待資料」，看不出誰等誰。今天不重複說整體落後，要把能先做的工作拆出來。

工程組：場地測量已完成，配置圖做到七成，仍缺倉儲組的大型設備尺寸。尺寸未到以前，固定牆面可以先畫，設備周邊不能定稿。

倉儲組：兩台舊設備仍在運轉，原廠圖找不到。已派陳員實地量測，明日下午可交外徑和維修空間，重量資料仍要向供應商查。

採購組：材料報價有效時間將屆，但沒有最後圖面就不能確定數量。可先保留常用規格價格，不先下全部訂單。

財務組：專案預算尚有額度，不過追加施工必須分項。不能因趕工就把材料、人工和運送寫成一筆。

主席：因此目前有三個不同卡點：尺寸、重量及材料數量。不要再合稱「倉儲資料未齊」。

【決議一：資料責任】

倉儲組陳員負責設備外徑與維修空間，明日下午交工程組。供應商重量資料由採購組林員追詢，若三日內未獲回覆，先在圖面標未知，不用猜值。工程組收到外徑後先完成固定牆面與動線，承重部分等重量資料。

【決議二：採購處理】

採購組把不受圖面影響的基本材料和需依數量調整的材料分開。前者可依核准程序先議價；後者只保留報價，不先下單。財務組由王員逐項核對，不因報價將屆就省略用途。

【發言摘要】

工程組：若重量又晚到，完成圖日期仍會往後。

主席：提出條件式日期。

工程組：明日收到外徑，可於兩日內完成配置；重量在三日內到，可再用一日完成承重註記。若超過，驗圖日期須重排。

倉儲組：設備不能停太久，量測安排在換班空檔，不影響生產。

採購組：供應商也要求設備型號，請倉儲組把銘牌抄清楚。

倉儲組：銘牌磨損，本日下午拍照並把可辨識字樣交出，不自行補字。

財務組：若只先購基本材料，請在訂單註明適用範圍，以免後面又重複購買。

【修正版進度】

第一階段為固定牆面、通道與基本材料，責任人分別為工程張員、倉儲陳員和採購林員。第二階段為設備周邊、承重及數量材料，卡點為外徑和重量。油漆與完工檢查改排在前述兩階段後，不用原日期硬壓。

【會後追蹤】

陳員按時交付外徑，工程組已完成配置草圖。供應商回覆重量資料，但缺一台設備的型號對照，採購組尚在核對。基本材料報價已保留，未下數量材料訂單。財務組完成預算分類，沒有發現超額。

工程組在草圖審查時又發現維修通道與消防箱距離不足。此問題可由調整活動工作桌解決，不涉及固定牆面，因此張員先提出兩個配置，不把整張圖退回重畫。倉儲組須在兩案中選定平日操作較可行者，責任人仍為陳員。

採購組提醒，基本材料雖可先買，也需有存放位置。倉儲組安排北側空區並標示批次，避免與現有維修料混放。財務組只核准已列用途的數量，沒有把保留報價視為必須全數採購。

主席批示：可先進行配置圖內部審查與基本材料採購，承重定稿和完整施工日仍待型號對照。各部門不得再以彼此未完成為由停下可先做項目。專案已有新分工與部分排程，但最後驗圖和進場日期尚未確定，狀態列為部分解決。
