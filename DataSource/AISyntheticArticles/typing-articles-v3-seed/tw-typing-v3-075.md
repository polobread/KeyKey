# 工作交接缺少關鍵步驟時真正會打出的字

【工作便箋一｜主管致值班員】

明日清晨須將東部山區收購之茶葉裝車，原負責人阿榮臨時返鄉，現聯絡不上。他留下的交接紙只寫「按甲、乙、丙三批過秤、封箱、送站」，未寫秤重後由誰核對，也未說車站收貨單放在何處。你先查現有資料，不可因車已約好便自行填寫重量。

【工作便箋二｜值班員回覆】

已查倉庫。甲、乙兩批外袋有編號，丙批只有產地名，沒有件數。磅秤旁找到一本舊簿，但最後一頁停在上月，無法確定本批是否應記於同一本。桌內有空白收貨單，沒有車站印記，不知能否使用。

現先將三批分區放置，未封箱。若今晚沒有進一步指示，明晨恐怕來不及裝車。

【主管便箋】

請立即做下列事項：

一、甲、乙批依袋上編號逐件清點，不開袋。

二、丙批先由兩人共同點數，以粉筆暫記於倉庫黑板，紙本欄位不先填。

三、舊簿保留原狀，不在不確定頁面續寫。

四、向車站貨運處詢問收貨單格式，空白單未確認前不用。

五、尋找阿榮平日與農戶往來的副本，但不得翻閱與本批無關的私人信件。

【值班員追問】

甲、乙批清點完成，件數與袋上總數相符。丙批由我與阿成共同點數，數量已記黑板。車站回覆需使用有連號之託運單，桌內空白單不合。貨運處明早可補發，但要求填寫貨主與到站人。

交接紙沒有到站人姓名，只寫「老地方林店」。請問可否沿用上次資料？

【主管回覆】

不可。店名相近，且上次到站人未必仍受委託。先查訂貨信副本，如仍找不到，今夜暫停填單。明晨車到時請司機先等，不可把貨交給未確認收件人。

【倉庫員便箋】

在公用文件匣找到訂貨信一封，寫明「交林茂商行」，另有店主簽名，但沒有到站提貨人姓名。信內數量寫甲十袋、乙八袋、丙六袋，與現場點數相同。是否足以填貨主欄，仍請裁示。

【主管批示】

可將貨主寫林茂商行，但到站提貨人欄留待車站確認，不能用店主姓名代替提貨人。另請把訂貨信副本編號抄入交接紀錄，原件放回文件匣。

【值班員便箋】

尚有一處不明。阿榮紙上寫「過秤後扣皮重」，卻未記麻袋皮重標準。現有麻袋新舊不一，若一律扣同一數字，重量可能有差。請問是否先記毛重，待阿榮回來再算淨重？

【主管回覆】

是。逐袋記毛重，並將空袋樣本另秤，由兩人簽名。淨重暫不填，交接表明寫「皮重標準未確認」。若車站一定要求淨重，本批延後，不以猜測完成。

【翌日清晨紀錄】

車站貨運員送來連號託運單，確認商行可憑通知與印章提貨，不需事先寫個人姓名。甲、乙、丙三批毛重均已由兩人核對。空袋樣本重量差異明顯，證實不能套用單一皮重。

車輛已到，司機表示若上午不裝車便改載其他貨。主管指示，貨主、件數與交付方式雖已補齊，淨重仍有爭議，先不裝車。已向司機說明並請其自行決定是否等候，不以合作關係要求空等。

【主管致原負責人便箋，留待返班】

阿榮返班後請立即補充：各批皮重計算方式、是否有農戶秤重副本、淨重由誰簽認。你原留「扣皮重」三字不足以讓他人安全接手，亦使車次延誤。請說明事實，不必先追究責任。

【交接暫結】

目前已補齊項目：各批件數、毛重、貨主、託運單格式及提貨方式。尚未解決項目：皮重標準與最終淨重。貨物留在分區內，封條未貼，鑰匙交夜班主管保管。下一班人員不得重複過秤或自行換袋，避免紀錄再增一套。

本案不能為趕車而宣稱交接完成。原負責人聯絡不上時，可把確定部分做完，也要明確標出不能猜的步驟。待皮重來源確認後，再重約車輛並完成封箱。至此雖仍未出貨，但貨物、文件與未決事項已有明確狀態。
