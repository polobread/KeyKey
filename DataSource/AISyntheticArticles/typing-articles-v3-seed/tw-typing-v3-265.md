# 朋友談臨時更改集合時間

【工作聊天軟體｜週末看展】

雅婷：集合時間要改。

阿凱：又改？

雅婷：展館通知入場提前，我們得從十一點改成十點二十分。

小文：哪裡集合？

雅婷：原地點，車站東口。

志豪：我行事曆還寫十一點。

雅婷：我剛更新共同行事曆。

志豪：我只看到前一版。

小文：可能還沒同步。

阿凱：群組置頂也寫十一點。

雅婷：對，我漏改置頂。

阿凱：先別只說行事曆更新，大家會看不同地方。

雅婷：收到。

雅婷：新版：週六 10:20 車站東口集合，10:30 一起走，11:00 前到展館。

小文：我可以。

阿凱：我也可以。

志豪：我不一定。

雅婷：卡在哪裡？

志豪：我前一晚值班，原本算好十點半起床。

雅婷：抱歉，這個改動對你不是只差四十分鐘。

志豪：如果一定十點二十，我可能直接到展館。

小文：那不用到車站。

雅婷：可以。你最晚十一點到展館入口，我們在裡面等？

志豪：票在誰那？

雅婷：電子票都在我手機。

阿凱：那不能先進去。

雅婷：我可以把每張票分開傳給本人，但要先核對姓名。

志豪：請傳我的。

雅婷：好。

小文：我也想自己留一張，免得集合又有變。

雅婷：可以，大家都各自收票。

阿凱：可是聊天軟體會壓縮圖片嗎？

雅婷：我傳原始檔，不傳截圖。

志豪：我的行事曆剛同步，現在看到十點二十了。

小文：置頂呢？

雅婷：已改。

阿凱：舊訊息還在，會有人滑到前面只看到十一點。

雅婷：我在舊訊息下面回覆「已作廢」，不刪除，讓人知道為何改。

小文：誰還沒讀？

雅婷：佩珊。

志豪：她今天休假，工作軟體可能沒開。

雅婷：我可以用私人訊息通知，但不想一直追。

阿凱：這是週末朋友活動，用私人訊息合理。傳一封就好。

雅婷：已傳。

小文：展館通知有寫若遲到怎麼辦嗎？

雅婷：只說入場時段提前，遲到需依現場安排，沒有保證能進同一場。

志豪：那我不能睡到最後一刻。

阿凱：你直接去展館，十點五十分到比較安全。

志豪：可以，我設兩個鬧鐘。

雅婷：我不把你列入車站集合人數，免得十點半大家還等。

志豪：對，除非我主動說到了，否則你們準時出發。

小文：佩珊回了嗎？

雅婷：還沒。

阿凱：她原本要跟誰搭車？

小文：跟我。

小文：我再看一下我們約的時間，啊，我和她私訊裡還寫十點四十五。

雅婷：這就是第三個版本。

小文：我會直接改我們的私訊，不只轉傳群組。

雅婷：謝謝。

佩珊：剛看到。我一直以為十一點集合，十點二十也趕得上。

小文：我們改成十點在原公車站碰面，一起去車站。

佩珊：好。

雅婷：請每個人回覆自己的路線，我做最後一版名單。

阿凱：10:20 東口。

小文：10:20 東口，和佩珊一起。

佩珊：同上。

志豪：10:50 展館入口，不到車站。

雅婷：我 10:10 到東口，負責集合；10:30 準時離開。票已分別寄出。

阿凱：我的票收到。

小文：收到。

佩珊：收到。

志豪：我也收到。

雅婷：舊版十一點和小文私訊十點四十五都作廢，以這串回覆為準。

志豪：這次清楚了。可是下次不要同時改三個地方，只更新一個主版本。

雅婷：同意。今天因為公告臨時來，只能先把散出去的版本逐一標掉。

小文：週六見，不再改時間了吧？

雅婷：除非展館再通知，否則不改；若再有變動，我會直接標「第二次更改」，不默默改行事曆。
