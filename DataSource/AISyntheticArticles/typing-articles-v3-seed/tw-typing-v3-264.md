# 借用物品後找不到配件時真正會打出的字

小芸：相機還你了。

阿成：看到了。

阿成：USB 傳輸線呢？

小芸：在袋子裡吧。

阿成：沒有。

小芸：我有放。

阿成：只有相機、電池和充電器。

小芸：黑色短線呢？

阿成：沒看到。

小芸：你再翻小夾層。

阿成：翻了。

小芸：不可能，我昨晚收的。

阿成：所以妳覺得我弄丟？

小芸：我不是那個意思。

阿成：妳一開口就說有放。

小芸：因為我記得捲好放進去。

阿成：我記得借妳時根本沒放傳輸線，只給讀卡機。

小芸：有線。

阿成：有嗎？

小芸：你還說線接頭鬆，要小心。

阿成：那可能是充電器的線。

小芸：不是同一條？

阿成：不是。

小芸：等一下。

阿成：妳看借走那天的照片。

小芸：我在找。

阿成：桌上有拍全套。

小芸：照片只拍到袋子外面。

阿成：第二張呢？

小芸：有相機、電池、充電器、讀卡機，旁邊一條黑線。

小芸：袋子右側還有一個透明小袋，裡面像是備用記憶卡，但照片沒拍到小夾層。

阿成：備用卡我這裡有，透明袋也在。現在只核對線，不要一次把所有東西都變成疑案。

阿成：傳給我。

小芸：傳了。

阿成：那條看起來是充電器電源線，不是 USB。

小芸：照片糊掉了。

阿成：接頭比較粗。

小芸：可是我用過 USB 匯照片。

阿成：妳不是用讀卡機？

小芸：第一次用線，後來才用讀卡機。

小芸：第一次是相機直接接主機，電腦有跳出資料夾；第二次讀不到，我才改用讀卡機。

阿成：如果當時直接接得上，妳那邊確實曾有傳輸線。我把「沒有借」的說法收回。

阿成：那線從哪拿的？

小芸：你袋子裡。

阿成：我真的不記得。

小芸：先不要比誰記得對。

阿成：好。

小芸：我去看電腦旁邊。

阿成：也看妳的印表機線，兩條很像。

小芸：找到了兩條，但接頭不同。

阿成：相機那條是小梯形接頭。

小芸：其中一條是。

阿成：那就是吧。

小芸：不確定，線上沒有標籤。

阿成：拍接頭給我。

小芸：已傳。

阿成：這條是相機線。

小芸：所以真的在我家。

阿成：看來是。

小芸：我昨晚收袋子時怎麼沒放進去？

阿成：可能還接在電腦後面。

小芸：剛才就是從主機後面拔的。因為線繞到桌下，我以為是印表機的。

小芸：主機後面太暗，我又把兩條線用同一條束帶綁著。昨晚只拔了桌面看得到的充電器，漏掉下面這條。

阿成：那就解釋得通。

小芸：對不起，我剛才一直說有放。

阿成：我也一口咬定借妳時沒給，結果照片證明至少有一條。

小芸：今晚拿去給你？

阿成：不用特地跑。

小芸：可是我答應今天全部歸還，少一條線放到明天，還是應該讓你知道確定位置。

阿成：現在有照片和接頭可核對，我知道不是遺失，晚一天不影響。

小芸：你明天要用相機嗎？

阿成：要匯照片，但讀卡機也可以。

小芸：讀卡機在袋子裡？

阿成：在。

小芸：那我明天下班帶去。

阿成：好。用小紙貼「相機」再放，不然下次又跟印表機認親。

小芸：你少笑。

阿成：我也會把配件列在袋子內側，因為光靠兩個人的記憶差點吵起來。

小芸：照片也留著。

阿成：留。照片不夠清楚，但至少讓我們知道不是憑空多出一條線。

小芸：下次借之前我們把相機、電池、充電器、讀卡機和傳輸線排開各拍一張，不再只拍整個袋子。

小芸：明天帶小梯形接頭黑線一條，交給你後一起試。

阿成：可以。其他配件都齊，缺的就是它。
