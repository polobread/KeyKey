# 簡短俐落地處理請人代收包裹

阿哲：明天下午有包裹到，我人在外地。可以請你代收嗎？

雅雯：可以。幾點？送到哪裡？

阿哲：宅配只說下午，地址是我家。上次司機進不來，包裹又被帶走。

雅雯：我們這棟有門禁。我沒有你家的磁扣，司機也不能直接按我家門鈴就上樓。

阿哲：那我把管理室電話給他？

雅雯：這裡沒有全天管理員。先問宅配能不能到大門外打給我，我下樓拿。

阿哲：好。我已在配送備註寫「到大門請聯絡鄰居」。

雅雯：等一下，你有填我的電話嗎？

阿哲：還沒。我怕沒問就填不好。

雅雯：可以填，但只限這件。請寫清楚收件人還是你，我只是代收。

阿哲：收到。包裹是一個紙箱，不大，不用付款。

雅雯：有沒有冷藏？很重嗎？

阿哲：常溫，應該不重。裡面是書。

雅雯：那沒問題。司機到時我下樓，簽收後先放我家玄關。

阿哲：我晚上九點左右回來再拿，可以嗎？

雅雯：九點可以。不要太晚，我明早要早起。

阿哲：了解。我回來前先傳訊息，不直接敲門。

雅雯：好。還有，門禁怎麼說？你只寫大門，社區有前後兩個門。

阿哲：對，我忘了。請他到靠便利商店的前門，不要去停車場那側。

雅雯：把這句加進備註。若他只到後門，我走過去要一段路。

阿哲：已改：前門外等，靠便利商店，抵達前電話聯絡代收人。

雅雯：這樣清楚。

阿哲：如果他提早到，你不在怎麼辦？

雅雯：下午三點前我不在。請他不要把紙箱放門口，也不要請別戶代收，改約稍後送。

阿哲：我傳簡訊給宅配了。對方回覆會先電話確認。

雅雯：好。你也把配送單號留給我，萬一來電時司機只說姓氏，我可以核對。

阿哲：單號末四碼是七二八一。我只傳末四碼夠嗎？

雅雯：夠，我不需要完整訂單資料。

【隔日下午】

雅雯：剛接到電話。司機在後門，說備註沒更新。

阿哲：糟。他還在嗎？

雅雯：在。我請他開到前門，沒有給門禁密碼。

阿哲：謝謝。是我的修改太晚嗎？

雅雯：不確定，先把交接完成。等一下再問客服。

阿哲：好。箱子若破損先不要收。

雅雯：外箱完整，末四碼也對。我已簽收。

阿哲：收到，麻煩你拍一張箱子外觀，不用拍標籤。

雅雯：已拍。紙箱放在玄關乾燥處。

阿哲：我大約九點前到。回家後先傳訊息。

雅雯：可以。宅配剛才問是否能把我的電話留作你以後的固定代收，我拒絕了。若下次還需要，請再問一次。

阿哲：拒絕得對，我沒有授權固定使用。這次辛苦了。

雅雯：沒事。下次請一開始就確認前門、可收時段、聯絡電話和是否付款，省得司機繞路。

【晚間】

阿哲：我到家了。現在方便拿嗎？

雅雯：方便。我拿到門口，你在走廊等，不用進來。

阿哲：箱子收到了，外觀正常，裡面也無缺。謝謝你。

雅雯：交接完成。我把照片刪掉，末四碼也不留。晚安。

阿哲：晚安。下次若再請託，我會先把門禁和交接方式寫完整，不讓你臨時處理。

雅雯：好。鄰居互相幫忙可以，但每一件都先講清楚，彼此才不會因為客氣而多猜一步。
