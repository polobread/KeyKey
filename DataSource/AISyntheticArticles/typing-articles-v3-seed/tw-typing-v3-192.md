# 客氣克制地處理採購規格與報價不一致

【簽呈草稿】

主旨：本次採購器材之需求規格與供應商報價品項名稱相近，內容有別，擬請核示比對及訂購方式。

說明：使用單位原需求為可供會議室長時間使用之移動式設備，附件規格表列有必要配件、操作介面及保固服務。供應商送來的報價單採用同系列名稱，但型號尾碼不同，且將部分配件列為選購。報價總額較預估低，若僅看品名容易認為完全符合；實際逐欄比對後，電源附件、固定方式和到場設定均未明載。

採購承辦意見：如果直接依較低價格下訂，驗收時可能才發現缺件；如果把報價所列品項視為含全部需求，又沒有供應商書面答覆，後續也難以判明。建議先製作差異表，請使用單位確認哪些項目為必要，哪些可接受同等功能，再請供應商按同一表格回覆。

【使用單位批示】

報價型號的主機性能看來足供一般會議，但我們不能省略移動固定架。現場常需移至兩間教室使用，若只有桌上底座並不合用。另外，原規格寫「含必要連接線」，是指可直接接現有設備，不是只附原廠盒內線材。請採購協助釐清，惟不要先指定特定廠牌配件。

【供應商書面澄清】

本公司報價品項包含主機、標準底座和基本線材，未含移動固定架。到場設定亦未計入，原報價只有交貨及簡易功能測試。型號尾碼為通路包裝識別，主機本體相同；但配件組合確有不同，敝公司先前未在摘要欄說清楚，敬請見諒。

如貴單位確定需要固定架與現場設定，本公司可另列項目。至「必要連接線」應包括何種接頭，仍請提供現場設備照片或介面種類，否則無法保證全數相容。

【承辦續簽】

供應商已承認配件組合不同，故不能沿用原報價名稱逕認符合。使用單位補送的現場照片顯示兩間教室設備介面不一，若要求每一種可能接法均附線材，範圍仍不明確。擬將需求改寫為：主機一組、可移動固定架一座、指定兩類現場介面所需線材，以及交貨時完成基本連接測試。其他備用轉接物不列為必要品。

如果供應商願依修正版逐項報價，即請明列品牌、型號、數量和是否含安裝；除非每一欄均已回覆，不以「整套」二字代替。採購人員只核對文件，不替使用單位判斷實際操作是否合適；功能部分由使用單位於報價回來後再簽認。

【供應商第二次回覆】

敝公司依差異表重報，主機與固定架分列，兩類線材各列數量，到場設定改列服務項。另註明保固對象為主機，耗材及外接線材不在同一範圍。本次總額因新增項目調整，原報價作廢，不再作訂購依據。

【核定紀錄】

主管核示依第二次報價進行，並將差異表、使用單位簽認和供應商回覆併為採購附件。驗收時按表逐項核對，不再以相近品項名稱推定內容。承辦已把舊報價標註「僅供歷程參考」，避免又被誤作有效文件。規格、責任人與驗收依據均已明定，使用單位同意照修正版辦理。

下訂前，承辦再以電話逐項讀回。供應商確認移動固定架不是桌上底座的別稱，現場設定也不是一般送貨；使用單位則確認兩類介面即可，不再要求模糊的「全部相容」。三方在同一份差異表簽章後，採購才發出訂單。訂單品名後附型號和配件清單，總額與第二次報價相符，舊報價上的近似名稱未再沿用。
