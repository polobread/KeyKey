# 正式謹慎地處理疑似違規事項需要查辦

【調查紀錄，案件編號 D-271】

案由：離島居民反映港邊公地夜間堆放建材，疑有占用通道及轉售公料情事，請查明並擬具處理意見。

居民陳述：陳情人表示，近月曾見數批水泥袋與鐵材由小船卸下，暫放於候船棚後方。因為其中部分包裝印有工程名稱，所以居民懷疑係公家工程材料遭人移作私用。陳情人又稱有人以每批 300 元兜售，但未親見付款，只聽鄰人轉述。其要求機關嚴查，不可等船將材料載走後再說無物可查。

首次勘查：承辦人與村幹事到場，見水泥袋十一包、鐵條一束及覆蓋帆布一件。通道仍可通行，但堆置位置靠近候船棚。現場無人看管，包裝上確有某修繕工程簡稱，未見財產編號或領料單。承辦人拍照、丈量位置並製作清冊，未擅自搬動材料。

可確認事項：一、特定時間有上述材料堆於公地。二、部分水泥袋印有工程簡稱。三、現場未見交易，也無法由包裝判斷材料所有人。因此尚不能確認有人涉案，更不能將傳聞中的 300 元寫成實際售價。

待調查事項：材料是否為工程剩料、由何人運送、何故置於公地、是否妨礙公共使用，以及陳情人所述轉售消息來源。因本島船班與本島端承包人聯絡不易，資料取得可能不同日完成，不宜因此省略查核。

訪談一：附近漁民表示，材料由修繕工班暫放，等下一船運回。他沒有看過買賣。問及姓名，僅知領班綽號。訪談二：另一居民堅稱曾聽見有人喊價，卻不願說明是誰。承辦人告知，保密其個資與免除提出具體線索是兩件事；若無時間、地點和對話對象，該段只能列為待查陳述。

工程承辦單位回覆：該修繕案確有同品牌材料，帳面尚未完成退料。工地清冊記載剩餘水泥十包、鐵條一束，與現場十一包不完全相符。承包人稱多出一包為自購材料，因此不能只用數量差異認定侵占，也不能因其口頭解釋就視為已核對。

費用資料：陳情人所稱每批 300 元，未見收據、借據或買受人。承包人提出工程尾款清單，其中沒有材料出售項目。兩者均不足以單獨證明交易有或無；承辦人將該金額列為訪談線索，不登入已發生收入。

擬辦：一、請工程承辦單位提出領料、使用和退料相關資料，並由承包人說明自購材料憑據。二、通知材料管理人限期將物品移至適當處所，以免長期占用候船棚周邊；移置不代表案件結束，須記錄去向。三、針對疑似轉售部分，請陳情人補充可辨識的時間和對象，現階段不以傳聞逕認違規。

主管意見：擬辦方向可行。對居民回覆須寫明已查得材料與工程有關聯，但所有權和一包數量差異仍待查。不要寫「查無不法」，也不要承諾必定裁處。300 元一節未有交易憑據，只能列入訪查。

居民再次詢問：「材料都移走了，還查什麼？」承辦人答稱，移置去向、領料簿和船運紀錄仍可核對；但若居民另有目擊者，應提供可聯絡方式，由機關個別訪談，不要在村內張貼姓名指稱涉案。

【第二次勘查】

材料已移至承包人租用倉間，原通道恢復空曠。工程單位送來領料簿影本，十包水泥與鐵條可對應；多出一包只有商店手寫便條，日期模糊，尚待向店家核對。承包人否認出售，居民則認為移走就是湮滅證據，雙方說法仍有衝突。

【現況】

公地占用部分已停止，但材料權屬與轉售傳聞未明。案件 D-271 續列查辦，不因現場清空即結案，也不在證據不足時先認定承包人涉嫌特定犯行。
