# 會議紀錄裡的整理證據

工廠勞資會談紀錄

出席：廠方代表林主任、會計員陳先生、工人代表黃先生、裝配組工人三人、紀錄員一人。

案由：工人代表提出上月夜間延長工作之工資尚有短付，惟各組排班紀錄分存於工頭手冊、守衛簽到簿及車間壁上班表，應先整理證據，再議應付數額。

黃代表：我們不是來憑記憶喊數目。裝配組有六晚做到收工鐘後，工人各有記在自己的小冊，但廠方只認守衛簿。問題是有人從側門搬貨，沒有在正門簽退。如果只看一冊，當然對不上。

林主任：廠方願意查。可是如果把私人筆記一概當成正式出勤，會計也無法辦。請先分清可查的紀錄和個人所述。

工人阿源：那晚我留下修皮帶，工頭叫的。班表已經擦掉了。

黃代表：這正是卡點。排班記在黑板，隔週便重寫；守衛簿只管正門；工頭手冊又各自保管。除非把三處資料放在一起，否則誰都只看到一半。

陳會計：可先列四欄：日期、原定班次、實際工作、可供佐證者。若有領料單或機器停開時刻，也可附在後面。沒有資料的部分先註「待查」，不要硬填。

決議一：由黃代表收集工人私人小冊所記日期，只抄與本案涉及的時段，不抄無關事項。責任人為黃代表，於下次會談前交紀錄員彙整。

決議二：由林主任通知各組工頭攜來排班手冊，不得事後添改。若某頁已遺失，應由工頭口頭陳述何時遺失及平日記載方式，紀錄員另列待調查事項。

林主任：我再說明，這不是要追究哪位工頭藏簿。現在先查工時。若發現有人故意改記，再另案擬辦，不能混在一起嚇得大家不敢拿資料。

工人阿和：守衛簿能借來嗎？

林主任：原簿不出警衛室，可由紀錄員到場抄錄。

黃代表：要讓工人代表一同看，否則又會爭抄得對不對。

林主任：可以，一人陪同。

決議三：紀錄員與工人代表於警衛室會同查閱守衛簿，逐日抄錄入廠及離廠時刻。倘側門未記，則以領料單、修理單及同班人證詞補列來源；不能相互印證者，保留為當事人主張，不先算入確定時數。

陳會計：還有一件。工人說的是延長工作，廠方現有表上寫的是夜班津貼，兩個名稱不能混。相關規定應依當時廠內公告查明，我不在此處先說哪種算法一定適用。

黃代表：同意。工人要求的是把真正做過的時間算出來，再由雙方依可查規定核算，不是先猜總額。

查閱結果摘要：六個爭議夜晚中，四晚可由守衛簿、工頭手冊與領料單相互證明；一晚雖無正門簽退，但修理單載有故障排除時刻，並有工頭簽名；其餘一晚僅有兩名工人私人筆記，工頭稱記不清，未能列為確定紀錄。

林主任：前五晚我沒有異議。最後一晚如果沒有別的憑據，廠方不能當場承認。

阿源：我能找出當晚交給倉庫的零件袋，上面可能有收件日期。

黃代表：那一晚先留待查，不拖住其餘五晚。

決議四：會計員依已確定的五晚時數重新核算，於本期工資冊補列；計算表由廠方和工人代表各存一份。第六晚另附資料頁，不因前五晚已辦妥而刪除，也不在證據不足時先下結論。

執行情形：陳會計已完成五晚核算，黃代表核對人名與時刻後簽收，補付項目列入本期工資冊。第六晚的零件袋後經倉庫找得，日期與工人筆記相合，工頭亦辨認簽字，雙方遂同意補入計算表。全案所涉六晚均有可追查來源，散存紀錄已編成一冊，由會計室及工人代表各留副本。
