# 伴侶談朋友之間的誤會擴大

小芸：阿慧不回我。

志明：還是那句話？

小芸：對。

志明：誰轉給她的？

小芸：不知道。

志明：原句是什麼？

小芸：「她總是有事才找我。」

志明：這句單看很傷。

小芸：但前面在說社團器材。她每次只有借器材時才找我這個管理人。

志明：妳是在說聯絡流程，不是友情？

小芸：對。

志明：後面還有嗎？

小芸：「平常聊天都找別人，器材卻直接跳過登記。」

志明：這句也可能像在吃醋。

小芸：我知道。

志明：有舊對話嗎？

小芸：即時通訊紀錄還在，但轉出去的只有第一句。

志明：妳想把整段貼給她？

小芸：想。

志明：先問她要不要看，否則像拿證據壓她。

小芸：她現在認為我背後嫌她。

志明：先承認那句離開上下文確實會這樣聽。

小芸：可是我沒有那個意思。

志明：澄清意思和承認影響可以一起。

小芸：你幫我寫？

志明：我可以看，但最好是妳的話。

小芸：阿慧，那句話是在談社團借器材，不是在說妳只把我當工具。

志明：後面加道歉。

小芸：為別人亂轉也要我道歉？

志明：不是為轉傳，是為原句寫得容易傷人，以及妳剛才回她「不要只聽片面」。

小芸：那句也不行？

志明：聽起來像責怪她相信了。

小芸：我真的很急。

志明：我知道。

小芸：改成「我剛才說妳只聽片面，語氣不好，對不起」？

志明：可以。

小芸：要提轉傳的人嗎？

志明：先不要猜是誰。

小芸：可是有人故意截句。

志明：也可能有人只記住那句。除非有證據，否則別再開第二場誤會。

小芸：完整訊息：阿慧，那句是在談社團借器材和登記，不是在說妳只把我當工具。它單獨看真的很傷，我剛才又怪妳只聽片面，對不起。

志明：很好。

小芸：還要說我珍惜友情嗎？

志明：如果妳真的想說，可以短一點。

小芸：我不想用一句珍惜把事情蓋掉。

志明：那先不加。

小芸：傳了。

志明：有讀嗎？

小芸：已讀。

志明：等一下。

小芸：我想把舊對話截圖也傳去。

志明：她還沒要求。

小芸：如果不傳，她會覺得我編理由。

志明：如果直接傳，她也可能覺得妳逼她立刻接受。

小芸：那怎麼辦？

志明：可以補一句「若妳願意，我可以給完整前後文」，然後停。

小芸：這樣會不會又多一封？

志明：會。所以先等。

小芸：五分鐘了。

志明：五分鐘很短。

小芸：她平常秒回。

志明：她現在可能在想。

小芸：我也擔心社團其他人都看到。

志明：那是另一件事。先不要在群組公開澄清，免得更多人知道原句。

小芸：阿慧回「我現在不想看解釋」。

志明：尊重她。

小芸：我要回什麼？

志明：回「好，我先不再傳。妳願意談時再找我」。

小芸：會不會太冷？

志明：也可以加「我知道妳現在難受」。

小芸：我回了。

志明：嗯。

小芸：她又已讀，沒回。

志明：澄清和道歉已送到，但她是否接受還沒有答案。

小芸：我還是想找出誰轉的。

志明：可以之後問，但今晚不要把猜測丟給每個朋友。

小芸：好。我先把舊對話留著，不公開、不刪，也不再傳給她。

志明：我陪妳等，但不保證這件事明天就好。
