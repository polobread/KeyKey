# 交通事故責任尚待調查時真正會打出的字

【事故說明草稿】

主旨：請就事故照片與當事人陳述釐清可確認事實

本案發生於市區交叉路口。甲方機車與乙方自用車發生碰撞，雙方均已留下聯絡資料，現場亦有警員到場。甲方送來四張沖洗照片，乙方另附車損照片兩張。因兩人對號誌、行進方向及煞車先後說法不同，責任尚待調查，不宜在公文草稿內先寫成「乙方違規肇事」。

目前可由照片確認者如下：兩車停止位置、地面散落物大致範圍、甲方機車右側擦痕，以及乙方車輛前側損傷。照片沒有拍到碰撞瞬間，也看不出號誌顏色。因此，不能因為車輛停在某處，所以直接推定誰先進入路口。

甲方主張，自己依正常方向行駛，乙方突然轉向；乙方則稱，轉向前已減速，甲方速度過快。以上都是當事人陳述，尚非調查結論。甲方說「照片證明對方沒有煞車」，照片本身無法證明踏板操作；乙方說「對方一定闖燈」，現有資料也不能支持確定語氣。

擬請承辦人核對現場圖、筆錄與照片標示，再將草稿中的推測改為「甲方稱」「乙方表示」或「尚待查明」。事故涉及損害分擔，文字若先定責，容易讓後續查證失去界線。

【甲方書面意見】

我不同意把所有內容都寫成無法確認。我的機車倒在路口內，對方車頭又有撞痕，至少能說明碰撞方向。當時我看見綠燈才前進，不是事後編造。若公文只寫「甲方主張」，是否等於不採信我？

我承認照片沒有拍到燈號，但希望承辦人把我受傷、車輛位置及對方轉向的說法完整列入。請勿因責任未定，就把細節全部省略。

【乙方書面意見】

甲方草稿寫我「突然轉向」，這是他的看法。我已在現場說明轉向前有打方向燈，也有減速。因為機車從側後方接近，所以碰撞點才在車輛前側，並非我沒有注意。

我也不同意用車損位置直接判斷速度。照片可供調查，但不是完整經過。請將「乙方未禮讓」刪除，改列雙方說法，等相關資料查清再作判斷。

【承辦擬辦】

一、保留雙方書面陳述，不刪除受傷與車損事實，但在有爭議處清楚標明陳述來源。

二、照片依編號附卷。能確認的外觀與位置照實記載；號誌、車速、是否已減速及行車先後，不由照片逕行認定。

三、現場圖中的車輛位置須再與到場人員紀錄核對。若照片拍攝前車輛曾被移動，應另註明，否則位置可能被誤讀。

四、草稿刪除「必然」「顯然肇事」等確定字樣，改為中性敘述。此項只是修正文稿，不表示免除任何一方責任，也不表示機關已認定誰應負責。

【主管批示】

照擬辦方向修改。事故照片可以證明的範圍有限，當事人的感受與記憶仍應收入，但不可混作已確認紀錄。因調查尚未完成，所以本次回覆只釐清文件寫法，不作責任比例或法律結論。

請將修正版分送雙方閱覽。雙方如認為自己的原話被錯寫，可指出哪一段；若只是要求把推測改成確定事實，承辦人不得照改。至於事故責任，由後續調查依全部資料判斷。本件已明確決定文件如何區分事實與主張，責任本身仍不在此次草稿內先行認定。

修稿時並請保留原草稿，以便看出哪些字句因證據不足而調整。照片背面註明提出人與收件次序，不補寫未經核對的拍攝時刻。若雙方再送資料，另列附件，不直接覆蓋原有陳述。
