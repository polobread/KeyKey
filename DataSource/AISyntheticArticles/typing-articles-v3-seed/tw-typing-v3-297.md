# 急迫但清楚地處理臨時更改集合時間

提示01：整理伴侶集合時間臨時更改通知。

原時間：下午3點。

新時間：下午2點20分。

集合地點：車站東側出口。

原因：交通接駁提前。

限制：其中一人可能只看到前一版。

查詢01：如何寫出不會漏看的改期訊息。

短答01：第一行直接寫「時間已改」。

提示02：不要先寫一大段原因。

草稿01：時間改了，我們提早到。

追問01：提早到幾點不清楚。

草稿02：集合改為下午2點20分，地點仍是車站東側出口。

追問02：是否要寫原時間？

短答02：要，避免收件者把新訊息當補充。

草稿03：原訂下午3點取消，改為下午2點20分。

追問03：如果對方趕不到？

短答03：提供回覆選項，不把沉默當同意。

提示03：請回「收到」或直接說最早可到時間。

查詢02：伴侶未讀改期訊息怎麼辦。

短答04：改用雙方平常緊急聯絡方式，不連續洗版。

提示04：先傳一則完整訊息，再打一通電話。

追問04：電話沒接怎麼辦？

短答05：留簡短語音，重複新時間和地點。

訊息定稿：時間有變：原訂下午3點取消，改成下午2點20分，地點仍是車站東側出口。因接駁車提前，如果你趕不到，請回最早能到的時間，我們再決定是否分開前往。看到請回「收到」。不要只在舊行事曆上加註，否則手機若未同步，對方仍可能只看到前一版。

狀態01：訊息已送達，未讀。

操作01：撥打一通電話。

狀態02：未接。

操作02：留下語音，不增加新版本。

語音內容：集合改成2點20分，原本3點不再使用；位置不變。看到後請回覆。

追問05：是否通知同行朋友？

短答06：可以，但說明伴侶尚未確認，不請朋友代為施壓。

同行群組：我已通知新時間，某人尚未讀；大家先不要各傳一版。如果有人收到不同內容，以這則寫明原時間取消、新時間2點20分的版本為準。

狀態03：伴侶回覆只看到舊行事曆。

追問06：要責怪沒看訊息嗎？

短答07：先處理能否會合，責任之後再談。

伴侶回覆：我最早2點45分到。

查詢03：接駁車2點35分離開怎麼安排。

選項A：一人先搭接駁，另一人自行前往。

選項B：兩人都放棄接駁，改搭其他交通。

追問07：哪個選項已確認？

短答08：尚未，先比較到達時間和可行性。

伴侶決定：你先搭接駁，我自行前往目的地。

確認訊息：收到。你不必趕到車站，我2點20分到東側出口搭接駁；你依自己的路線前往，到達後傳訊息。這是雙方最後確認的安排，若路況再變，只更新各自到達狀態，不重開集合方案。

狀態04：雙方已回覆。

行事曆01：刪除下午3點舊事件。

行事曆02：新增2點20分集合與分開前往註記。

檢查01：沒有第二個集合地點。

檢查02：沒有把未讀當成同意。

結果：改期通知與替代安排均明確完成。
