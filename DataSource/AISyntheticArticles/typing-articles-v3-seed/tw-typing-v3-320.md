# 通訊軟體群組裡的核對物品

阿明：誰看到我的電鑽盒？

阿明：裡面的配件呢？

阿明：少一個充電座。

麗芳：你借我時沒有啊。

麗芳：我記得沒有。

小美：完美的鄰居法庭開庭。

阿明：我傳借出前照片。

麗芳：照片裡只有電鑽、兩顆電池和鑽頭盒，充電座沒有拍到。

阿明：因為充電座放下面，被盒蓋擋住。

麗芳：也可能本來就在你家。

小美：有交接當天的照片嗎？

麗芳：我拍過一張。

麗芳：傳了。

老吳：至少看得到袋子。

麗芳：對，你那天用塑膠袋另外裝了東西，但我以為是鑽頭。

麗芳：照片時間是下午四點多，背景看得到你家鐵門。我們至少能確定袋子在你家門口時還出現過，不是借用前就不見。

小美：所以袋子可能是充電座？

麗芳：可是我拿回家後只把盒子放工作間，沒看到袋子。

老吳：交接地點在哪？

阿明：我家門口。

麗芳：不對，是巷口。

阿明：先在我家門口講，後來妳騎車到巷口才拿走。

阿明：我記得妳先把盒子放後座，因為太重又停在巷口綁繩。袋子那時掛前面還是已放進去，我沒有看清楚。

小美：兩人的記憶開始更新。

老吳：袋子放哪裡？

麗芳：我掛在腳踏墊前面的掛鉤，電鑽盒放後座。

阿明：那到妳家時有拿下來嗎？

麗芳：我只記得先搬盒子。袋子真的想不起來。

麗芳：回家後我先接電話，接著把電鑽盒搬進工作間。因為下雨，我又把雨衣和購物袋一起塞到架子旁，東西可能就在那段時間分開。

小美：檢查機車置物箱？

阿明：也看看雨衣袋。

麗芳：為什麼會在那？

阿明：因為妳上次把我的延長線塞進雨衣袋，找了兩天。

麗芳：不要翻舊帳。

老吳：但可以翻雨衣。

麗芳：……我去看。

小美：全群等待開獎。

麗芳：找到一條電源線。

麗芳：線捲得很整齊，外面沒有塑膠袋。我平常不會這樣收，應該是從你借來時就綁好的。

阿明：是充電座的線嗎？

麗芳：照片傳了。

阿明：對，是那條線。但底座還是不見。

老吳：至少找到一半。

麗芳：雨衣袋只有線，沒有底座。袋子可能在騎回家途中鬆掉，也可能我把底座拿進屋後分開放。

老吳：先列兩條路徑。能在屋內查的先查；至於路上是否掉落，目前只有可能，別急著沿路問得全村都以為有人遺失危險物品。

阿明：先別說掉在路上。沒有證據，聽起來像要去沿街考古。

小美：鄉鎮尋寶活動取消。

麗芳：我傳工作間全景。桌下有一個黑色方塊，但被紙箱擋住。

阿明：原本底座是長方形，側邊有兩個插槽和一張褪色貼紙。若找到相似的，先拍正面和側面，不必每個黑盒子都搬來試插。

阿明：外型很像。

麗芳：我搬開看。

老吳：小心別壓到腳。

麗芳：不是，是舊收音機變壓器。

阿明：空歡喜。

小美：但線已確認是我的，不對，是阿明的。群組聊到我都入戲了。

麗芳：明天白天我再把工作間架子逐層找。今晚只確認電源線在我這裡，底座還沒找到。

麗芳：我也會翻門口的雨具櫃和當天用過的購物袋。找到後先拍照核對，不靠「看起來差不多」就接電測試。

阿明：好。電鑽盒和其他配件數量都對，先不要互相靠記憶定罪。

老吳：部分破案。

小美：嫌疑人仍是一個黑色底座。
