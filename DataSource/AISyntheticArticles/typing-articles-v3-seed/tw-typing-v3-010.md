# 從訂單明細開始的對話

顧客：您好，我的餐點少一份。

店家：請問訂單編號？

顧客：畫面末碼是7621。

店家：我查一下。

顧客：謝謝。

店家：請問少哪一份？

顧客：雞肉便當。

店家：飲料有收到嗎？

顧客：兩杯都有。

店家：配菜呢？

顧客：另一份便當完整。

店家：了解，會幫您處理。

顧客：請問怎麼處理？

店家：補送雞肉便當。

顧客：大約幾點？

店家：外送員回來就送。

顧客：他現在在哪？

店家：正在送另一區。

顧客：那「回來就送」可能是十分鐘，也可能一小時。我們不是催你瞬間出現，只要知道能不能等。

店家：了解，我先問他目前位置和預計返回時間。

顧客：這不算時間。

店家：目前外送較忙。

顧客：我們有人要搭車，不能一直等。若半小時內無法送，請直接退款。

店家：我問外送員。

顧客：好，請給我明確答覆。

店家：他說等等回覆。

顧客：你們可先看廚房是否還有雞肉便當嗎？如果餐點也要重做，時間應該一起算。

店家：廚房有備料，重做約十二分鐘。

顧客：那就不要等外送員回來才開始做，否則時間又往後延。

店家：已請廚房先製作。

顧客：又是等等。

店家：抱歉，我們正在聯絡。

顧客：訂位時我已寫六點半用餐，餐點六點二十送到，現在六點四十。請在六點五十前告訴我能否七點前送到。

店家：收到。

顧客：另外，這筆訂單不是蝦皮購物下單。我只是用蝦皮購物買了店家的餐券，再到你們的訂位頁預約。請不要叫我去找蝦皮購物物流。

店家：明白，是本店備餐漏放，與餐券平台配送無關。

顧客：對。

店家：外送員回覆了。

顧客：時間呢？

店家：六點五十五可到。

顧客：確定嗎？

店家：他已返回店內取餐，現在出發。路程約十分鐘。

顧客：請外送員到巷口再聯絡，門牌夜間不明顯。不要因為趕時間就放在別戶門口。

店家：已轉告，抵達後會先核對訂單末碼。

顧客：那請補送。

店家：好的。

顧客：不要加辣。

店家：原訂單是微辣。

顧客：訂單明細寫不辣，請再看一次。

店家：您說得對，是不辣。剛才看成另一筆。

顧客：這就是我一直請你們看完整訂單的原因。

店家：已在盒上註明不辣。

顧客：補送會另外收費嗎？

店家：不會，這是漏送補餐。

顧客：如果七點還沒到呢？

店家：我們也會在六點五十五查看一次，不讓您自己追問。

顧客：好。剛才我不滿的是沒有時間，不是要求你們違規趕路，請外送員正常騎車。

店家：明白，安全優先。

店家：請直接回覆本串，我們立即退款該份餐點，不要求您再等第二次補送。

顧客：可以。

店家：外送員已到巷口。

顧客：我請家人在門口等。

店家：穿灰色外套的先生嗎？

顧客：對。

店家：已交付。

顧客：家人拿到了，但我要先核對。

店家：請核對餐點和辣度。

顧客：雞肉便當一份、不辣，內容正確。

店家：飲料原訂兩杯都已收到，因此這次只補便當，沒有重複附飲料。

顧客：沒問題。我問清楚是怕你們之後盤點又以為多送。

店家：這次漏放與先前沒有給時間，真的抱歉。該份不另收費。

顧客：補送已收到。下次客服若說「會處理」，麻煩直接講是補送、退款，還有預計時間，否則客人無法安排。

店家：您的意見已轉給當班人員，今晚訂單已補齊。

顧客：好，這樣可以。
