# 正式謹慎地處理政策草案影響不同居民

【承辦人文章】本市正研擬市場周邊交通調整草案，內容包括縮短部分路段臨停時段、增設卸貨區，以及假日試辦行人優先區。草案尚未定案，請居民依實際使用情形提出意見。以下留言會區分個人主張、可確認現況與待調查事項，不把按讚數當成唯一依據。

居民甲：我支持。假日人多，車又一直鑽，帶小孩很危險。

居民乙：你走路當然支持，我們住戶車要停哪裡？

居民甲：我也住附近。

承辦人：請兩位說明使用時段和路段，避免以身分推測彼此需求。

攤商：卸貨才是問題。早上市場補貨，如果縮短臨停，貨車會排到外面。

居民丙：可是現在貨車直接擋騎樓。

攤商：我沒有說可以擋騎樓。

承辦人：草案擬設集中卸貨區，但容量是否足夠仍待現場計數。現階段只能確認早晨有卸貨需求，不能先說一處就能容納全部車輛。

居民乙：長期成本誰付？號誌、標線和人員都要錢。

承辦人：相關費用將另列試辦估算，尚未核定。草案貼文不會把暫估數字寫成確定支出。

家長：短期先把過街安全做好很重要，不能每次都等完整工程。

店家甲：行人多可能有生意，但如果送貨進不來，店也開不了。

居民甲：所以才要卸貨區。

店家甲：有區不等於有位置。

承辦人：這個差異已列入。將在平日清晨和假日上午分別觀察卸貨車次、停留時間及空間使用，不以單一時段推估全年。

居民丁：會不會試辦後就直接永久化？

承辦人：試辦結束前須整理觀察和意見，再由權責單位決定是否調整、停止或延續。本文不預告結果。

攤商：如果試辦期間生意掉了，誰能證明是交通造成？

承辦人：營業變化可能受多種因素影響，機關不會只憑一週感受下結論。攤商可提供來客方式、送貨困難和特定時段紀錄，作為評估資料。

居民丙：請嚴查違停，不然改再多都沒用。

承辦人：違規事項依相關規定辦理；本次意見蒐集重點仍是空間安排。查辦個案與政策設計會分開記錄。

居民乙：我要求保留住戶短暫上下車，不是反對行人安全。

家長：這樣講我能理解。

承辦人：已將需求改寫為「住戶接送及行動不便者上下車空間」，不再籠統記成反對限停。

店家甲：攤商也不是反對行人，是要有可工作的卸貨時段。

承辦人：一併修正。

居民戊：留言這麼多，最後真的會看嗎？

承辦人：會按議題彙整，但不公布留言者個資。相同意見會計數，也保留理由差異。涉及特定門牌與健康狀況者，請改由私密表單提供。

居民甲：那目前改了什麼？

承辦人：已決定在試辦前增加兩項現勘：清晨卸貨容量及傍晚住戶接送需求；並將原本整日限制改成分時段方案比較。這些是程序上的明確調整，不代表已選定最後方案。

攤商：請讓實際送貨司機一起看現場。

承辦人：已納入現勘名單，並會邀請居民、行人團體和攤商代表同場說明。個別代表不能代替全部居民，但可提供具體動線。

居民乙：我先接受分時段比較，仍反對直接取消住戶臨停。

家長：我支持試辦，也希望不要把卸貨逼進巷子。

承辦人：兩項意見均列入。草案將依新增現勘結果修訂後再公開，且清楚標示哪些是已確認需求、哪些仍有歧見。此次留言已形成可執行的調查項目和修稿方式，政策內容則仍待後續程序決定。
