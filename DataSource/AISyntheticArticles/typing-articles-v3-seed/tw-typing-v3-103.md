# 同學談線上遊戲隊友臨時消失

阿展：阿堯又不見了。

小晴：剛剛還在線上。

子維：排到一半耶。

阿展：真可靠，沒他我們更強。

小晴：你認真？

阿展：反話啦。

子維：文字看不出來。

小晴：我截給他看了。

阿展：為什麼要截？

小晴：我以為你真的不想再找他。上次他也臨時斷線，你在教室念了一整節，不像只是隨口抱怨。

阿展：上次是上次。今天我只是在吐槽。他沒說一聲就消失，我當然不爽，但沒有要把人踢掉。那句的意思是我們又得重排，不是他技術很差。

子維：群組名稱已經被改成「三缺一受害者」了。

阿展：誰改的？

子維：我。

阿展：你才在擴大喔。

小晴：先改回來吧。

子維：改了。

小晴：阿堯未讀。

阿展：又未讀。

小晴：你看，又來了。

阿展：我說「又」只是描述，不是要開除他。能不能不要每句都替我加結論？我如果真的不想組他，會直接講，不會在這裡繞。

子維：那你真正要講什麼？

阿展：他如果有事，傳「先離開」四個字就好。排隊前也說過能打一場，進去後突然沒人，其他人只能一起等。剛才那場還不能中途補人，大家都知道。

小晴：這樣就很清楚。你前面那句「沒他更強」看起來完全不是這意思。我截圖不是要挑事，是怕他晚點上線，看見群組改名更難受。

阿展：我承認反話失敗。請你別只把那句截給他，後面這段也補上。單看一句，他可能以為全班都在嫌他。

小晴：已補。

子維：要再排嗎？

阿展：先不要。萬一他手機沒電，等等又上來，我們可以問。但現在三個人硬排，只會再找陌生隊友。

小晴：你還是在生氣吧。

阿展：有一點。生氣和不想再跟他玩是兩回事。我氣的是突然消失造成三個人卡住，不是要翻他以前每次失誤。

子維：我可以當第四個。

小晴：你不是已經在嗎？

子維：我開另一個角色。

阿展：不要，等級差太多。

子維：嫌棄我？

阿展：對，這句是真的。

小晴：這次我看得懂。

阿展：笑吧。

小晴：阿堯狀態剛亮了一下。

子維：又暗了。

阿展：他到底怎樣？

小晴：可能網路不穩。東部今晚風很大，我家剛才也斷了一次，連通訊軟體都轉了很久才送出。先別假設他故意跑掉。

阿展：如果是斷線，那我前面講重了。可是一開始等人的時候，他至少能用手機回吧？除非家裡連手機訊號也不好。我不知道，所以才想問。

小晴：不一定。你先別再猜。

子維：我私訊他了，沒有回。

阿展：我也傳：「剛才那句是反話，不是叫你別來。臨時斷線沒關係，但我們等不到消息會困住。你有空時回一下狀況。」這樣可以？

小晴：可以。

子維：要不要先玩別的？

阿展：你們去。我沒心情。

小晴：這句又像在氣我們。

阿展：不是。真的只是沒心情。

子維：文字好難。

阿展：所以我才補清楚。

小晴：他還是沒回。

子維：那今晚呢？

阿展：不知道。先掛著。

小晴：我去洗澡，若他出現再叫我。

子維：我等十分鐘，也把房間留著。他若回來就不用重新找人。

阿展：嗯。
