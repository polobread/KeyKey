# 從錯誤紀錄開始的對話

阿傑：9月14日晚上8:20，資料程式又跳掉。

阿傑：畫面寫存檔失敗。

美玲：截圖有拍到右下角的網路狀態嗎？

阿傑：沒有，我只拍錯誤框。

美玲：下次把整個畫面一起拍，再另外抄錯誤文字。只截小框會失去當時的程式版本、時間和連線狀態。

阿傑：我已經重開了。

美玲：那截圖是重開前？

美玲：實際檔案還在嗎？

阿傑：在，而且又能存。

美玲：所以截圖和現在結果不同。請把操作順序一項一項傳，不要只傳最後畫面。

阿傑：先開8月報表。

阿傑：船務月報乙檔。

阿傑：改兩格數字，按存檔，就出錯。

美玲：有接磁碟片嗎？

阿傑：沒有，存硬碟。

阿傑：當時郵件也收不到。

阿傑：值班室另一台電腦好像也在轉圈，但我沒去問，因為急著把月報存下來。

美玲：先記成旁證，不寫成整個網路都斷。另一台是否同時失效，要問當時使用的人。

美玲：這很重要。

阿傑：可是檔案在本機，為什麼和網路有關？

美玲：程式啟動時會查共用資料夾的代碼表。先記錄，不要急著認定原因。

阿傑：現在要再做一次？

美玲：先備份副本。

阿傑：好了。

美玲：把系統時間記下。

阿傑：9月14日晚上8:37。

美玲：照原步驟改同兩格。

阿傑：存成功。

美玲：再試另一份檔。

阿傑：也成功。

美玲：錯誤無法穩定重現。請看紀錄檔最後幾行，有沒有和截圖相同文字。

阿傑：沒有存檔失敗，只有「代碼表連線逾時」。

阿傑：晚上8:19。

美玲：和你看到畫面相差一分鐘，可能是同一段操作，但不能只靠時間下結論。

阿傑：截圖檔案顯示8:20建立，這能當畫面出現時間嗎？

美玲：大致能證明你在那時存圖，但不保證錯誤正好於那一秒發生。紀錄寫「約8:20拍攝」比較妥當。

阿傑：我再拔掉網路線試？

美玲：可以，但先關閉原檔，用副本測，免得又傷到月報。

阿傑：已拔。

美玲：開程式。

阿傑：出現代碼表無法讀取。

美玲：還能進報表嗎？

阿傑：能。改數字後按存檔，又顯示存檔失敗，可是重開後內容其實有存進去。

美玲：再做一個不同數字的測試，避免只是開到前一次留下的內容。改完先抄數值，關閉後重開比對。

阿傑：已測。第二次也有存進去，錯誤框仍然出現。

美玲：那畫面文字不準。程式把代碼表連線錯誤顯示成存檔失敗，實際資料另有存檔結果。

阿傑：所以不是真的沒存？

美玲：這次測試有存，但仍要逐筆核對，不能保證每次都成功。

阿傑：接下來呢？

美玲：先恢復網路，重開程式，核對剛才兩格以及總計。今晚不要用錯誤畫面判斷是否重做。

阿傑：網路恢復。

美玲：數字一致嗎？

阿傑：一致，總計也對。

美玲：我把9月14日晚上8:19的紀錄、8:20截圖與8:37重測結果整理成一份，明早交程式維護人員。原因欄先寫「代碼表連線中斷時訊息誤導」，不寫成資料遺失。

阿傑：也附上9月13日下午4:10那次正常存檔紀錄嗎？同一份月報、同一台電腦，當時網路正常。

美玲：附上，可供比較。但它只能說明正常狀態下沒有出錯，不能單獨證明今天唯一原因就是網路。

阿傑：臨時做法？

美玲：看到錯誤先查網路與紀錄檔，再核對存檔內容；不要立刻覆寫原檔。步驟已用簡訊傳給值班同事。

阿傑：收到。報表保住了。

美玲：好，這次排查到這裡。
