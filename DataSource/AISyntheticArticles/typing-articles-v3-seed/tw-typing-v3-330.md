# 預約時間被業者臨時更動時真正會打出的字

訂位者：您好，我收到訊息說週六下午三點的剪髮預約要改時間，但提供的三個替代時段都不方便。

店家：設計師臨時請假，因此改成週六上午十一點、週日晚間或下週二。請問哪個可以？

訂位者：都不行。我週六上午有課，週日不在本地，下週二要上班。原預約已付訂金，請問還有其他方案？

店家：可以由另一位設計師在週六下午服務，但她的資歷與收費不同。

訂位者：如果改由其他設計師，需先說明是否增加費用，以及我原本預約的項目能否完整完成。

店家：項目可以完成，費用不增加。不過原設計師較熟悉您的髮況。

訂位者：我這次是重要場合前整理，因此才提前指定。如果店家臨時更動，我希望選擇取消並退訂金，不接受改成未指定服務。

訂位者：我不是質疑另一位設計師的能力，只是她沒有看過我先前留下的紀錄，臨時更換不符合原本預約目的。

店家：訂金原則上不退，但可以保留六個月。

訂位者：那是顧客自行取消的規則。本次是店家無法依原時段與指定人員提供服務，請不要標成我臨時取消。

店家：我先請主管確認。

〔等待六分鐘〕

店家主管：已查看預約訊息。原預約確實包含指定設計師與週六下午三點。因為替代時段都不方便，您可選週六同時段改由另一位設計師，或取消並退回訂金。

店家主管：本次不要求您提出其他時段不便的證明，選擇取消不會被記為無故未到。

訂位者：若取消，退款方式和時間如何？

店家主管：依原付款方式退回。實際入帳時間依付款端作業，我們不先承諾固定日，但今日會完成店內取消申請並提供編號。

訂位者：我再確認一次：不扣手續費，也不改成保留額度？

店家主管：正確。全額退原訂金，不留作下次折抵。

訂位者：那我選取消。我不希望影響另一位設計師，也不想在不熟悉的情況下勉強接受。

店家：可以理解。我現在取消原預約。

訂位者：請把原因寫店家更動，不要寫顧客行程不合。

店家：會寫「指定設計師臨時無法服務，替代時段未合」。

〔等待三分鐘〕

店家：取消完成，編號 BK-771。訂金退款已送出，預約時段也已釋出。

訂位者：我收到取消訊息，但內容只寫「預約已取消」，沒有退款金額。

店家主管：我另傳退款憑證摘要，會列原付款金額與退款狀態，不含完整支付資料。

訂位者：收到，金額正確。

店家主管：若付款端狀態數日後仍未更新，可直接以 BK-771 回覆這段對談，不必再提供完整卡號。

訂位者：好。請問週六原時段不會再打電話問我是否改由其他人吧？

店家：不會。原預約已取消，沒有候補或保留安排。

訂位者：了解。因為替代時段都不合，我接受取消與全額退訂金，這樣處理清楚。

店家主管：案件已依上述內容結束。後續若您另有需要，可自行建立新預約，不會沿用本次時段與指定人員。
