# 客氣克制地處理交通事故責任尚待調查

小林：我建立這個群組，只用來交換今天擦撞的照片和聯絡資料。責任由後續調查判斷，請先不要轉貼公開社群。

陳先生：照片很清楚，是你突然切進來。

小林：那是你的判斷。照片拍到碰撞後位置，沒有拍到我變換車道的過程。

陳先生：所以你否認？

小林：我否認的是把推測寫成確定結論。我會說明自己的行車方向，但不在群組先定責任。

目擊者阿芳：我只看到碰撞後兩台車停下，沒看到前幾秒。

陳先生：妳當時不是說他從旁邊過來？

阿芳：我說的是碰撞後他在你左側，不是我看到他切入。

小林：謝謝釐清。

陳先生：那行車紀錄器呢？

小林：我有檔案，會保留原始影片，先提供承辦人員，不在群組剪成十秒片段。

陳先生：為什麼不能傳？大家一起看比較快。

小林：影片可能拍到其他車牌和路人，也可能因截取起點造成誤解。你若有自己的原檔，也請保存。

陳先生：我只有事故照片。

阿芳：我有一張路口號誌照片，但拍攝時間是碰撞後，不能證明事發當下燈色。

陳先生：至少能看號誌正常。

小林：可以證明拍照時有亮，無法直接證明碰撞瞬間是哪個燈色。

陳先生：你每句都在推。

小林：我不是不負責。我已提供聯絡方式與保險資料，也會配合調查；只是不同意現在把「可能」改成「一定」。

阿芳：先把可確認的列出來吧。

小林：可確認：兩車在路口發生擦撞、右前與左側有損傷、事故後位置有照片、雙方當時都能自行下車。

陳先生：還有你在左邊。

小林：可寫事故後我的車位於左側。至於碰撞前如何到那裡，待影片和現場資料判斷。

陳先生：好，這樣寫。

阿芳：我的陳述也請寫「只見事故後」。🙏

小林：已補。

陳先生：我剛才在別群說你違規切入，要刪嗎？

小林：請刪除或更正為責任尚待調查。那是未確認主張，而且公開轉傳可能引來更多無關猜測。

陳先生：已刪。不是承認我錯，只是不先公布責任。

小林：了解。刪文和事故責任是兩件事。

阿芳：照片要傳哪裡？

小林：原檔先各自保存，另依承辦人員提供的方式交付。群組裡可放低解析度位置照，不放證件。

陳先生：修車估價可以先交換嗎？

小林：可以交換估價單，但金額與責任比例也不是同一件事。先各自向維修廠詢問，不要求對方當場承認全額。

陳先生：我明白。

阿芳：那我退出群組？

小林：可先留到承辦人員確認是否需要聯絡。若想退出，也把可聯絡方式私下交給雙方即可。

陳先生：我重新整理一句：我認為對方可能變換車道，但目前沒有完整影像，責任尚待調查。

小林：這樣能區分你的主張和可確認事實。

阿芳：我按個讚，不代表替哪邊作證。👍

陳先生：知道。群組先不再猜燈號和車速，有新資料再貼原件來源。

小林：同意。照片、影片與估價分開保存，後續依正式調查結果辦理。
