# 居民與承辦人談疑似違規事項需要查辦

【公文草稿】

主旨：有關居民陳情跨縣市載運不明廢料，疑似於河岸空地傾倒一案，查核情形與擬辦意見如說明，請核示。

說明：一、陳情人來函表示，曾見外縣市車輛於夜間進入河岸產業道路，翌日空地出現袋裝碎料。其認為主管機關先前只以電話詢問，未到場嚴查，並質疑「等雨沖走就查不到」。陳情人附紙本照片四張，另稱尚有錄影帶，惟未隨函提供。

二、本所人員第一次會勘時，現場確有袋裝物、磚塊和木材，未見車輛。袋面字跡磨損，僅能辨識部分貨號。附近居民說法不一：有人稱連續三晚聽見車聲，也有人只見白天工程車經過。這些內容均屬陳述，不能直接認定照片中的車輛就是傾倒者。

三、陳情人於電話中表示：「車從隔壁縣市來，又趁晚上卸貨，還不算涉嫌違規嗎？」承辦人答稱，夜間出入與跨縣市運送可列為調查線索，但物料來源、性質、所有人和放置用途尚無資料，現階段仍無法確認是否涉案。陳情人對此答覆表示不滿，要求不要再以「查不到」結案。

四、本所已函請土地使用人提供施工契約、進料單和清運憑據。使用人回覆，空地正進行農舍修繕，袋裝物為拆除後暫存材料，將由承包人載離；所附單據只列工程名稱，未列照片中貨號，也沒有車輛資料。因此能確認有修繕工程，尚不能確認所有袋裝物均由該工程產生。

五、另洽車籍所在地機關協查。該機關回覆，僅憑陳情照片無法辨識完整車號，且其轄內登記車輛不等於實際載運人。請本所如取得清楚車號、駕駛或貨物流向，再送相關資料。此一回覆未排除違規可能，也未證明陳情人所指車輛涉案。

擬辦：一、再次會同土地管理及相關權責單位勘查，分別記載物料外觀、數量、位置和地面狀況，不以「廢料」二字先作法律定性。二、請土地使用人補具承包人姓名、載運車輛和後續去向；若資料仍缺，於紀錄中明列未提出部分。三、請陳情人將所稱錄影帶交由本所登錄，勿逕寄唯一原帶，以免遺失；可到所說明拍攝日期和方向。

四、現場如有散落、阻塞或立即危險，先依權責採必要措施；是否涉及違反相關規定，則俟物料與行為人可辨後查辦。再次勘查前先通知陳情人與土地使用人，讓雙方各自指認位置，不安排雙方當場爭辯。不得因陳情語氣強烈便逕予裁處，也不得因一次會勘未見車輛就認定全無其事。

【主管批示草稿】

擬辦原則可行。回覆陳情人時請分開寫明：已確認空地有袋裝物和修繕工程；尚待調查的是物料來源、車輛與去向；機關目前決定是續查及要求補件，而非認定任何人違規。勿使用「查無不法」結語。

【第二次會勘追記】

土地使用人已將散落物集中覆蓋，產業道路恢復通行，此部分問題暫解。承包人交出一張手寫載運單，車號末碼可與陳情照片模糊影像相近，但不足以完整比對；物料成分亦未提出證明。陳情人到場仍要求立即查辦，並表示若再拖延將另行陳情。

【部分結論】

道路阻塞已改善，案件其餘爭點未明。公文先回覆可確認事實與續查範圍，不把手寫單據當成完整證據，也不將居民主張刪成一句「情緒性反映」。是否涉案，仍待相關資料到齊後判斷。
