# 調查紀錄裡的提出書面主張

【調查紀錄】

案由：租期屆滿後，房東主張自押金扣除牆面、浴室櫃和清潔費；房客主張部分痕跡入住前即存在，雙方對點交狀況說法不同。

一、房客書面主張

房客稱已按約搬離並交還鑰匙，房東於點交後才傳來整修總額，沒有逐項照片和單據。房客承認廚房爐台仍有油污，可就實際清潔費核對；但客廳牆面的小孔在入住照片已有，浴室櫃門也曾於租期初期以簡訊告知鬆動。因此，房客不同意將整面粉刷和櫃體更換全數列為其負擔。

房客提出入住相片、退租影片及通訊紀錄。相片可見牆面原有痕跡，但光線不足，不能辨明每個孔洞；退租影片可見櫃門仍能開關，亦不能證明內部鉸鏈沒有損壞。房客請求先返還無爭議押金，爭議部分另依資料判斷。

二、房東書面主張

房東稱點交時已口頭指出牆面孔洞、櫃門歪斜及廚房油污，房客因趕時間未在點交表簽名。房東提供師傅估價單與點交後照片，主張退租屋況比入住時差。然而估價單將補土、整面粉刷和櫃門調整列為一筆，未分原有老化與新增損傷，也未記損壞原因。

房東同意先返還部分押金，但認為應保留足以支付全部估價的金額，待工程完成再結算。房客則認為，若先保留全部，就等於在責任未明前由房客承擔不利益。

三、可確認紀錄

雙方均承認租期、押金交付、鑰匙已歸還，以及點交當日未完成雙方簽認表。廚房油污存在亦無爭議，但清潔範圍與實際費用仍須憑單據。入住照片可確認牆面已有若干痕跡，無法確認退租時每一處孔洞形成時間。通訊紀錄可確認房客曾反映櫃門鬆動，房東當時回覆「先觀察」，但退租時是否另有新增損壞仍待查。

四、待調查事項

牆面哪些孔洞為租期內新增、整面粉刷是否均為修復所必需、櫃門損壞與先前通報狀況的關聯，以及清潔費實際支付數額，均尚無一致資料。承辦人不以師傅估價直接作責任結論，也不因房客曾通報就推定後續任何損壞均與其無關。

五、擬辦意見

擬具爭議項目表，把雙方主張、照片可見內容和待補資料分欄。房東補送清潔付款證明與分項估價；房客提供入住相片原檔，避免只以截圖判讀。相關資料用於本案核對，不擴作公開指責。

承辦人另安排雙方共同觀看原檔，逐一標記拍攝位置，不接受任何一方在會後自行加註「新增」或「原有」後當成共同結論。對於無法由角度比對的牆面，紀錄明寫無從確認，不以照片張數多寡決定。

六、雙方協議

雙方同意無爭議押金先返還，該筆付款不表示房客放棄其餘主張，也不表示房東承認全部修繕應自行負擔。廚房清潔依實際單據扣除；牆面部分因無法辨明新增孔洞，房東撤回整面工程全額要求，改以雙方同意的小額局部補土費結算。浴室櫃則由房東自行修繕，不向房客扣款，惟雙方對損壞原因仍各自保留說法。

七、機關決定

依雙方簽認項目，押金餘額和扣除項目已明確列出，房東完成匯款，房客確認收受。此結果係就書面資料與協議處理金額，不作其他法律責任推論。點交爭議已有可追蹤的書面主張、證據限制和最終結算，案件辦理完畢。
