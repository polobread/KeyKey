# 公司與客戶談客戶追加原範圍外需求

【甲方來函】

本公司前委託貴廠製作木箱及內襯，用於離島器材運送。原契約約定於1963年4月18日前完成六十箱，總價依樣品和圖面核定。因收貨單位近日要求每箱另加防潮紙、編號銅牌及內容物清冊，並希望貴廠直接送至碼頭分批裝船，請一併辦理，交期仍照原定日期。

【乙方回函】

查原契約工作為製箱、內襯和送交甲方倉庫，未列防潮紙、銅牌、逐箱清冊及碼頭運送。新增事項可以估辦，但如維持原價與4月18日交期，實難承諾。防潮材料須另向本島供應商調貨，銅牌又需刻號；若內容物清冊由甲方逐箱提供，裝箱次序也要配合調整。

請甲方先確定哪些項目屬必要。倘全部增加，乙方將另列材料、人工及運費；如果預算不能增加，則請在原工作和新增項目之間選擇，不宜以「一併辦理」視為均已包含。

【雙方會商紀錄】

甲方代表：防潮是收貨單位臨時要求，不能沒有。銅牌可否改用油漆編號？

乙方代表：油漆編號可省刻牌時間，但耐久程度不同，須由甲方書面同意。內容清冊由誰寫？本廠只知道箱號，不知道每件器材名稱。

甲方代表：清冊資料由我們在4月12日上午10時前交。你們負責裝入透明袋，固定在箱內。

乙方代表：可以估價。送碼頭則涉及車輛和船期，除非指定裝船日，否則無法排車。

甲方代表：船公司暫排4月20日下午2時。原交貨日其實可改為送碼頭前一天。

乙方代表：這已不是維持原交期，而是改變交付地點與時間。請把4月19日送抵碼頭寫入補充條款，也要明定因船期臨時變更如何處理。

【補充條款草案】

一、原契約六十只木箱均增設防潮紙。乙方依樣品鋪設，材料費和人工另列，甲方核價後始採購。

二、箱號採油漆標示，不使用銅牌。甲方已知材質與原要求不同，仍同意以可辨識且不易脫落為準。

三、內容物清冊由甲方製作，於4月12日上午10時前交乙方。乙方負責依箱號裝袋固定，但不負責核對器材名稱正確性。若清冊逾時，乙方得順延此新增工作，不視為原製箱延誤。

四、交付地點改為指定碼頭，預定4月19日上午完成點交。運送費另計。船期如果變動，甲方應通知是否仍照原日送碼頭；除非雙方另有書面通知，乙方不自行把貨留到新船期。

五、原契約的箱體尺寸、數量和製作品質不變。新增費用只限防潮材料、清冊固定及碼頭運送，不因本補充條款重新計算已完成木工。

【甲方批覆】

同意油漆編號和清冊責任分工。防潮費及運送費依乙方報價核定，總額已由主管簽准。4月19日上午點交列為新交付時間，原4月18日倉庫交貨條文停止適用。

【執行回報】

甲方於4月12日上午9時40分交付清冊，乙方當日完成箱號核對。防潮紙如期到廠，六十箱於4月18日下午封裝完畢，翌日上午送達碼頭並由雙方按清冊點件。新增範圍、費用、責任和日期均依補充條款履行，未再以原價涵蓋追加工作。

碼頭點件時，甲方發現其中兩箱的油漆號碼不易辨識。乙方依補充條款當場補漆，並由甲方在清冊旁簽註完成，沒有把此事擴大解讀為六十箱均未履約。運送人員另交回收貨證明，載明箱數、到達時間和外觀狀況；船期後來延至隔日上午，但甲方依第四條通知乙方貨物仍留碼頭，保管責任由甲方接續。至此追加事項均有可查書面，原契約和補充工作也沒有再混為一筆。
