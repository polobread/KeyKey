# 同事談生病或照顧期間需要幫忙

標題：想問問，有沒有人方便幫一點忙

阿真：我這幾天感冒，家裡長輩又剛看完醫生。本來不想麻煩大家，可是就醫單和採買清單越寫越長。我先問問，不方便完全沒關係。

小林：你需要哪一種？

阿真：還在整理。

小何：先列出來吧。

阿真：明天下午要替長輩去診所拿檢查資料，我自己也要回診。還缺稀飯材料、衛生紙和幾樣日用品。但大家都有工作，我怕一開口就變成整包丟給別人。

美玲：不必整包。一人一件。

阿真：可是來回很花時間。

小林：我下班會經過診所。不過資料能不能由別人代領，要先問櫃台，不能直接去拿。

阿真：對，我也不確定。

小何：你先打電話問。若可以，我陪小林去；若不行，就改成我載你去回診。

阿真：這樣太麻煩了。

美玲：你每句都說麻煩，我們反而不知道怎麼幫。

阿真：抱歉。

美玲：不是怪你啦。我是說，可以把事情切小一點。像採買，我明晚本來就會去市場，你只列必要的東西和大約數量。

阿真：那……米一小包、蛋、青菜，以及衛生紙。重的東西先不要。

美玲：收到。

小林：診所電話問了嗎？

阿真：剛問。檢查資料須本人或有委託書的家屬領，我可以先寫委託書，但還要帶雙方證件資料。

小林：我不是家屬，不適合。

阿真：所以還是我去。

小何：那我載你。你什麼時候回診？

阿真：下午三點。

小何：我兩點半可離開公司，可是只能載你往返，無法陪等診。

阿真：這已經很夠了。

小何：那就只算接送。你不用因為我載一趟，又覺得欠我整個下午；我回公司還有自己的事，界線很清楚。

美玲：長輩那份資料怎麼辦？

阿真：我回診後再拿委託書去領。只是怕診所關門前趕不到。

小林：我可以先替你把委託書格式送去櫃台問，確定沒漏，再由你本人帶證件去領。這樣至少不會白跑。

阿真：可以嗎？

小林：可以。我中午就在附近辦事。

路人同事：記得不要在板上貼證件號碼。

阿真：好，我會私下交紙本。

美玲：採買還有沒有藥？

阿真：沒有，藥照醫囑拿，不請大家代買。清單就是剛才四樣。

小何：那分工很明白了。

阿真：我還是覺得過意不去。

小林：可以過意不去，但不要因此什麼都自己扛。我的部分只有順路問一張委託書，不會耽誤整晚。

美玲：我也只是多拿一袋。不過你若臨時又想到十樣，請先挑真正急的，別怕我們失望。

阿真：不加了。

小何：我明天兩點二十分在公司門口等。你若發燒更嚴重，先打電話改診，不要硬撐著照原安排走。

阿真：好。

隔日回報／小林：格式問過，委託書可用，櫃台說要帶的資料我已寫在紙上交給阿真。

美玲：東西買齊，晚點放警衛室。

小何：車子有空位，兩點二十分出發。

阿真：都收到了。我和長輩的就醫資料各放一個袋子，沒有混在一起。謝謝你們只接自己能接的部分，這樣我比較敢接受。

小林：先休息吧。

美玲：稀飯別煮焦。

阿真：這個我盡量。
