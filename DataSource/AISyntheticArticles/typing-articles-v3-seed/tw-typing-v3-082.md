# 進度表還沒說清楚

【簽呈草稿】

主旨：本社農產包裝改善案進度延遲，擬修正工作順序與完成日期，請核示。

說明：

一、本案原定由生產組試作新包裝、採購組確認紙材、運輸組檢查堆疊方式，於月底前完成。現因生產組等待紙材樣品，採購組等待運輸組提供耐壓要求，運輸組又等待生產組提出箱體尺寸，三方互相等待，進度表上仍只寫「進行中」，未能顯示實際卡點。

二、原進度表以部門為列、以日期為欄，但沒有標示每一項工作需要哪份前置資料。各組雖都有聯絡，內容多為詢問另一組何時完成，沒有把可先做與必須等待的部分分開。

三、若維持原表，主管只能看見三項同時延遲，無法判斷先處理哪一項。擬改以「輸入資料、負責人、交付對象、確認日期、未決事項」五欄記錄。

目前實況：

一、生產組已能提出兩種暫定箱體尺寸，不必等待正式紙材。尚未確認的是裝滿後重量與封口方式。

二、運輸組可依暫定尺寸，先測算車內堆疊及搬運通道；耐壓要求則需依路程與層數提出，不必等成品箱。

三、採購組已有三種紙材樣品，但未取得一致的耐壓條件，所以未送生產組測試。供應商報價仍在有效期間內，暫無須重新詢價。

擬辦：

一、生產組於本月十二日前將兩種暫定尺寸、預估裝載重量交運輸組。數字若為估計，須明寫，不得當作最終規格。

二、運輸組於十四日前提出兩種尺寸的堆疊層數與最低耐壓需求，並說明是否需加墊板。若兩案皆不可行，應寫出原因，不只回覆「請重新設計」。

三、採購組於取得耐壓需求後，從現有樣品中選出可測試者，十六日前送生產組。若沒有任何一款符合，再啟動補充詢價。

四、生產組於十九日前進行裝填、封口與搬運試驗，記錄破損、受潮與開箱情形。試驗不需等大量製作，先以少量樣品判斷。

五、三組於二十一日共同核對結果，提出一項建議規格及一項備案，送主管決定。

【會辦意見｜運輸組】

同意新順序。請生產組不要只提供外部尺寸，還需寫預估單箱重量與是否容易偏重。堆疊安全受重量分布影響，僅看長寬高不足。

【會辦意見｜生產組】

可補預估重量，但農產品含水量會變動，無法保證固定數字。建議以範圍表示，並在試驗時分別裝較輕與較重樣本。

【會辦意見｜採購組】

同意先用現有樣品。惟供應商所稱「耐壓紙材」各有不同規格，進度表應填實際測試資料，不可只抄商品名稱。若需新樣品，至少預留運送時間。

【承辦人修正】

依三組意見，進度表新增「數值性質」欄，區分預估、供應商資料與實測結果。另在每項日期後加一名確認人，避免負責人完成後無人接收。

【主管批示】

同意修正排程。原月底完成之目標改為二十三日提出核定規格，量產日期另案安排。各組不得為維持原日期省略搬運試驗。承辦人每日只更新一次共同進度表，電話討論後應補記結論。

【執行情形】

生產組按期交兩種尺寸與重量範圍；運輸組完成堆疊評估，排除其中一案；採購組挑選兩款紙材；生產組完成少量試驗。一款在較重裝載時底部變形，另一款保持完整，開箱亦無明顯受潮。

共同會議建議採用第二款紙材，並保留減少堆疊層數作為長途運輸備案。主管於二十三日核定，規格表交採購組取得正式報價。

【結案說明】

本案延遲已依新進度表處理。三組不再只寫「等待」，而能看出等待何物、誰提供、何時交付。正式量產尚需報價與採購程序，但規格決定已有清楚依據，原先互相等待的循環已解除。
