# 契約草稿還沒說清楚

採購契約核對會議紀錄

時間：民國五十三年六月十二日上午
地點：合作社辦公室
出席：合作社主任、採購員、豐年工場代表、會計員
案號：C-1842

一、會議原因

合作社擬向豐年工場採購抽水機配件，契約正文第三條寫「皮帶輪組」，附件清單卻寫「傳動輪一組」。兩個名稱是否指同一物件，雙方原先未明確約定。正文總價為12,600元，附件各項加總亦為12,600元，但若名稱指向不同零件，交貨時仍可能發生爭議，故在用印前開會核對條款。

二、雙方發言

採購員表示：「我方詢價時說的是裝在現有抽水機上的皮帶輪，須連同軸套與固定螺絲。附件由工場繕打，我收到後只核總價，沒有注意名稱改成傳動輪。」

工場代表回應：「本場帳冊一向把皮帶輪列為傳動輪，並非另售齒輪。不過附件只寫一組，確實沒有把軸套和螺絲逐件列出。若照字面交貨，雙方可能各有不同理解。」

主任詢問，原樣品是否仍在。採購員取出封存樣品，工場代表當場核對，確認樣品包含一只輪體、一只軸套及四枚固定螺絲。會計員指出，報價單編號Q-307也列相同總價，但品名仍為「傳動輪」，沒有附圖。

三、可確認紀錄與待釐清事項

可確認者為：雙方均曾看過封存樣品；總價前後一致；工場內部用語確實稱為傳動輪。待釐清者為：交貨品是否須完全符合樣品尺寸，以及備用螺絲是否包括在總價內。會議未認定任何一方故意改名，也不把用語差異寫成違約。

工場代表提出，輪體可依樣品製作，軸套也包含在內，但四枚固定螺絲原估價只含兩枚。採購員表示，現有機座需要四枚；若另加價，應在契約上列明，不能到交貨時才追加。

四、條款修正

經討論，正文與附件統一改稱「皮帶傳動輪組」，並在括號註明工場帳冊原稱「傳動輪」。內容寫明：輪體一只、軸套一只、固定螺絲四枚，尺寸以雙方在會議現場簽認的樣品為準。附件原來的「一組」刪除，改逐項列數量。

四枚螺絲不另加價。工場代表說，雖原估只列兩枚，但差額不大，願依總價12,600元交付完整一組。合作社同意維持付款方式，不因此延後第一期款。

交貨日期原文寫「七月上旬」，附件寫「七月十日前」。為避免範圍不同，統一改為七月十日前送到合作社倉庫。若船運受天候影響，工場應先以電話或書信通知，雙方再把實際情形記入往來簿；本次不預先約定無法查證的延誤原因。

五、擬辦與決議

採購員今日依本紀錄擬具修正版契約，正文和附件同時修改，不得只在附件旁手寫。會計員重新核對總價、數量及付款日期。工場代表於修正版每頁蓋章，合作社主任覆核後再行用印。

雙方確認，案號C-1842所稱「皮帶傳動輪組」就是今日桌上封存樣品的同式配件，不包含其他齒輪或馬達。原稿與修正版一併保存，原稿加註「未用印，不作交貨依據」，避免日後誤取。

六、散會前確認

主任逐項詢問：「名稱是否一致？」雙方答一致。「數量是否清楚？」工場代表答輪體、軸套各一，螺絲四枚。「價款是否仍為12,600元？」會計員答是。「交貨日期？」採購員答七月十日前。

工場代表補充，成品完成後會先與樣品並列檢查，再裝箱送出。雙方對修正文字均無異議，契約草稿不再使用兩個不同名稱。本紀錄繕寫兩份，合作社與工場各收一份。
