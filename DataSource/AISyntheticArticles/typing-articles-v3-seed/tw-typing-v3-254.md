# 通訊軟體群組裡的互相吐槽

【夜貓】明天星期一，請問行事曆有提供封鎖功能嗎？

【南風】長按刪除人生。

【小卷】我試過，只有刪除行程。

【夜貓】沒用，我老闆會再邀一次。

【山路】你們至少放了三天，我週六還在改簡報，根本沒有假日結束的問題。

【南風】這麼一說，好像更慘。

【小卷】不要比慘啦。

【山路】我不是比，是不爽。群裡每次都拿「明天不想上班」當笑話，可是有人是真的忙到睡不好。

【夜貓】抱歉，我原本只是想吐槽。其實我今晚看到明早兩場會，也有點喘不過氣。

【北窗】陌生人群組突然進入真心話時段。

【海鹽】我剛進群，不認識大家也能講嗎？我每到收假前就一直檢查鬧鐘和交通時間，明明都設好了還是怕遲到。朋友說我想太多，但那種緊張不是一句「放輕鬆」就會消失。

【小卷】可以講。這群又不是只收笑話。

【夜貓】我也會重看行事曆，看到半夜反而更睡不著。你若都準備好了，先把提醒關掉一小時吧，我也跟著關。

【小卷】可以啊，不然大家只丟梗圖，丟完還是各自盯著行事曆發呆。

【南風】我最氣的是主管週五下班前塞工作，然後說星期一一早要。週末沒叫你做，但答案自己長出來嗎？

【茶茶】這句有痛。

【夜貓】我現在有一封信停在草稿，想問明早會議能不能延到下午，卻怕被當成不積極。

【山路】有理由就問。你卡在哪裡？

【夜貓】報表要等另一組早上補數字，九點開會只會集體說「還沒收到」。

【小卷】那不是偷懶，是順序不對。

【北窗】建議你寫：「資料預計上午到齊，若改至下午，可直接核對完整版本。」把工作和原因放前面。

【夜貓】已送。手在抖😵

【南風】陌生網友隔空扶住。

【茶茶】我也來一個。我明天行事曆從八點半排到五點，中間只空半小時，誰能幫我判斷哪個會該先退？

【山路】看哪場沒有你的任務。

【茶茶】下午那場只是被副本邀請。

【小卷】先問主辦人是否只需會後看紀錄。不要默默消失。

【茶茶】問了。他回可以不用到。

【南風】群組今日績效一：救回半小時。

【夜貓】我的主管也回了，會議改下午兩點。不是世界末日，真意外。

【北窗】績效二：早上不再對空白報表開會。

【山路】好，我收回一半火氣。不是叫大家別開玩笑，只是有些人笑很大聲，是因為不敢說自己撐不住。

【海鹽】我把鬧鐘留著，但不再每五分鐘點開看。明天要帶的東西已放門口，現在去洗澡。這算今晚的處理嗎？

【山路】算，而且比繼續焦慮實用。

【北窗】各地陌生人同時被星期一嚇到，又各自救回一點時間，這群的功能突然很正經。

【夜貓】懂。我以後吐槽完也問一句，有沒有哪個行程真的能動。

【小卷】我的不能動，但我把午餐時間鎖住了。誰敢邀會，我就回便當照片🍱

【南風】這招值得寫進員工手冊。

【茶茶】我也把空出的半小時改成休息，不拿來塞另一件事。

【山路】很好。我的簡報今晚停在目前版本，剩下的明早先跟主管排優先順序，不再自己猜全部都急。

【北窗】所以大家還是不想上班？

【全群】對。

【夜貓】但至少明天少一場無效會議。

【南風】以及多一張便當威嚇圖。

【小卷】別逼我真的貼。

【茶茶】貼啦。

【海鹽】先不要，我剛恢復食慾。
