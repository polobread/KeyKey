# 親友離世後不知道怎麼開口時真正會打出的字

【母親來信，1994/3/7】

阿芳：

你舅舅走後，你一直沒回信。我知道你忙，也知道有人一開口就會哭，所以沒有催。可是外婆每天問那只舊手錶放在哪裡，家裡又有人說應該趕快分掉遺物。我不想在電話裡講，怕旁邊的人接著議論，只能寫給你。

大家來家裡都說「節哀順變」、「時間久了就好」。外婆聽完點頭，客人走後卻把椅子搬回舅舅原來的位置。我也不知道該勸她收，還是讓它放著。你若願意，請告訴我那只手錶是不是舅舅答應給你的。不是逼你決定，只是星期日要整理桌櫃，不能又讓眾人當著外婆面爭。

另外，舅舅床頭有幾封未寄出的信，大姨說都是廢紙。我沒有拆看，只用布包起來。那是他的字，不該趁大家忙亂時隨手燒掉。妳回來以前，我先放著；若妳知道收信人，再一起想要不要交還。

母親

【女兒回信，1994/3/9 夜間寫，翌日寄出】

媽：

我不是忙。我每次拿起筆，就只會寫「請保重」，看起來跟那些客人說的一樣遠。舅舅沒有把手錶送我。他去年 12/18 晚上修好錶帶後，讓我戴著試一天，隔日就還了。若有人說那是我的，請你更正。

先不要把東西分完，好嗎？我不是要全部留下。只是舅舅的工具盒裡有一支刻著外公名字的螺絲起子，外婆也許認得。我怕大家覺得舊、覺得沒用，就順手丟掉。星期日我趕不回去，但下個週末可以。

那些未寄的信也先別拆。就算信封沒封，也不等於家人都可以看。我回去後先認筆跡和名字；若完全看不出來，再請外婆決定。這件事不要在飯桌上突然問她。

還有，別再寫「你要堅強」。我看到那句就不知道怎麼回。你可以問我吃了沒，也可以告訴我外婆今天做了什麼。那些比較像你。

阿芳

【母親第二封信，1994/3/12】

阿芳：

好，手錶不寫你的名字。我已把工具盒和手錶放進上鎖的木櫃，鑰匙在我這裡。星期日只整理衣物與帳單，不分有紀念意義的東西。大姨雖不高興，說我又拖，但我回她：「等阿芳回來看過。」她沒有再爭，只是臉色不好。

外婆今天早上 6:40 起來，煮了兩碗粥，過一會兒才發現舅舅不會來吃。她沒哭，只叫我把另一碗收起來。我本來想說「人已經不在了」，話到嘴邊沒有說。後來陪她坐到粥涼。

下午她自己把舅舅的杯子洗了，又放回原處。我沒有收走。大姨問何時才能清空房間，我只答星期六阿芳回來後再談。她嘆氣，但也沒再碰木櫃。

妳有吃嗎？這不是叫妳堅強，我只是問。

母親

【女兒回信，1994/3/14】

媽：

我有吃。讀到兩碗粥時，我把信折起來很久，然後又打開。謝謝你沒有把外婆拉走，也沒有急著說她糊塗。

下週六我搭早班車回去，約上午 10:30 到。請不要叫大家特地等我，也不要把工具盒先擦得像新的。我想看舅舅原來怎麼放。手錶可以先問外婆要不要留在床邊；她若不答，就先不動，不必拿「總要決定」逼她。

我帶一冊舊相簿回去。不是要辦什麼紀念儀式，只是舅舅替我們拍的照片散在裡面。你若累，我自己翻；你若想坐旁邊，也不用一直說話。

信的事我也會看，但不在外婆面前逐封念。若其中有帳單，就交給妳處理；若是私人的，我們先保持原樣。至少這個週末不急著把每件東西定出歸屬。

阿芳

【母親便箋，夾在回信內】

車站我去接。外婆聽見你回來，只說「知道了」，又問能不能買她常吃的糕。工具盒未動，手錶也在。星期六先吃飯，再看東西；誰來催，我會請他改天。沒有更多漂亮話了。回來就好。
