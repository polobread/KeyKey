# 簡短俐落地處理專案延遲與重新排程

【工程組呈主管進度報告】

主旨：倉庫屋頂修繕延遲及工序重排

一、原排進度

木料到場後，由工務組丈量、採購組點收，再交現場班組施工。屋頂拆換與排水溝整修原擬同時開始，以免重搭工作架。

二、目前情形

採購組已收木料清單，實物尚未全數送達。工務組要等實物核對尺寸，才肯簽丈量表；現場班組又在等該表，不能先裁料。三組都說手上沒有可繼續的資料，工程因此停住。

排水溝所需磚料已到，可先清除舊溝。但若先拆到屋簷下方，日後搬運木料恐又阻礙通道。雨後地面濕滑，也不宜同時調入太多人。故本組未逕行施工，先報請改排。

三、擬改次序

先由現場班組清點已到木料，只記數量和明顯缺損，不代替工務丈量。採購組依送貨單追缺料。排水班先做遠離卸貨處的一段，靠近倉門部分暫留。待尺寸表簽回，再排屋架工作。

此法可使一部分人員復工，不能解決全部延遲。工務組仍需見到實物；採購組也尚未得供應方確切答覆。若今日只在進度表寫「等料」，明日仍無人知道先做哪段，故附上分工，請示。

工程員林某

【主管批示】

准先辦遠端排水溝及現有木料清點。清點表由現場領班負責，今日收工前交工程員；缺料追詢由採購組負責，不要再請工務組代問。丈量與核章仍歸工務組。

進度表應分成「可開工」「待實物」「待資料」三欄，不可把每項都寫成延期。能做者即做，需要等待者寫明在等誰。又如前項作業影響後項，須在旁註明，不要只畫箭頭。

屋架不得在尺寸未定時先裁。這一項不因趕工變更。排水溝靠近倉門部分也先保留，以免送料車無法進出。

【工程組第二次回報】

依批示辦理。現場領班已清點到場木料，數量可與部分送貨單相對；其中兩批只有品名，未註尺寸，已列待工務組丈量。排水班完成遠端舊溝清除，未動倉門周邊。

清點時另發現送貨單沿用舊稱，工務圖則用新編號。兩者可能指同一批材料，現場人員無權逕自改寫。工程組已將實物標記、送貨單名稱及圖面編號抄在對照紙上，交兩組各自核看。未簽回前，只能算相關資料待核，不能列為短缺，也不能當成已足數。

採購組回覆，供應方承認尚有一批未送，但沒有寫明何時到。工程員要求先以現有材料安排屋架一角，工務組不同意，理由是整體尺寸可能互相牽連。雙方仍在等同一批貨，尚不能排定屋架日期。

目前可確定者只有排水溝前段和材料清點。人員已重新分派：兩人續作排水、兩人整理舊料，其餘暫回原班工作，不在工地空等。進度表已重寫，未完成項目沒有填假定日期。

另請主管決定，若缺料先到而尺寸表仍未回，是否維持停工。採購組主張到貨即算解除卡點；工務組則說，材料齊備也不等於可裁切。工程組認為兩件事應分列，不宜用一個「完成」欄同時概括。否則上級看表會以為現場延誤已排除，實際仍無法動屋架。

【主管再批】

分派照准。供應方未具體答覆前，不再挪動屋架次序。採購組取得送料消息後直接交工程員與工務組各一份，免得兩邊又互等轉送。排水前段可續作，完成後即停，不得越過保留界線。

本次重排只解除部分人力閒置，材料與尺寸問題未解。進度表維持待資料狀態，不寫「已恢復正常」。

對照紙由工務組先核圖號，再交採購組核送貨名稱，次序照此辦理。任何一組若有異議，直接註在原紙，不另抄一份，以免又產生兩套內容。屋架開工仍須另行批示；今日不作日期承諾。
