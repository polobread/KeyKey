# 分手後歸還共同物品時真正會打出的字

【文章原發者】我和前任分手後，還有書、鑰匙、桌遊和一台共同買的小電扇放在彼此住處。對方一直把取物時間和「我們能不能再談」綁在一起。我只想把物品歸還完，不想每約一次就重談關係。請問怎麼寫才夠清楚？

朋友甲：先列清單。

原發者：我列了，對方又問電扇算誰的。

朋友乙：那是共同出錢？

原發者：對，各一半。

朋友甲：可以先處理無爭議物品，電扇另談。

原發者：他說除非見面，否則不把鑰匙還我。

朋友丙：這就不是回憶，是出入安全。鑰匙要優先。

原發者：我已經急著換鎖，但不想把事情鬧大。

朋友乙：你可以提出公開地點或請共同朋友代收，不必去他家。

原發者：我怕找朋友會讓他覺得我在告狀。

朋友甲：重點是你需要一個可完成的交接方式，不是說服他認同分手。

原發者：我寫「因為我們已經分手，所以請不要再談感情」，會不會太刺？

朋友丙：可以更直接寫界線：「這次聯絡只處理物品與鑰匙，我不討論復合。」

原發者：好。

朋友乙：時間也給選項，不要來回猜。

原發者：我能週六下午或週日早上。

朋友甲：地點選有人的地方。

原發者：便利商店門口。

朋友丙：清單要分「你的、他的、有爭議」。

原發者：我的書和備用鑰匙；他的外套與唱片；電扇有爭議。

朋友乙：桌遊呢？

原發者：是他送我的，但他現在說只是放我那裡。

朋友甲：又一項爭議。先不要在現場拉扯，把兩項封箱另標。

原發者：我怕他到了就不交鑰匙。

朋友丙：訊息先寫，鑰匙若未帶，其他交接也不必延長談話。你可自行換鎖，安全不用等他同意。

原發者：我已傳：「週六三點或週日十點，便利商店門口，請帶備用鑰匙。我會帶外套和唱片。這次只處理物品，不談復合。電扇與桌遊有爭議，先另放。」

朋友乙：很清楚。

原發者：他回「妳連五分鐘都不肯給？」

朋友甲：不要解釋五分鐘。重複可選時段。

原發者：我回週六或週日請選。

朋友丙：很好。

原發者：他選週六，但說要我自己去他家拿書。

朋友乙：你接受嗎？

原發者：不接受。

朋友甲：那就說只在約定地點交換。他若不帶書，後續再用郵寄，不進住處。

原發者：我說了。他現在不回。

朋友丙：至少你已把時間、地點、清單和界線寫清楚。

原發者：可是鑰匙還沒拿到，書也沒確定會帶。

朋友乙：所以事情還沒解決。週六可請朋友在附近，但不必由朋友出面吵。

原發者：我會請室友陪我到現場。今晚先不再傳。

朋友甲：好。

原發者：後續若他臨時改地點，我就不去。情緒的部分我不想再透過物品處理，但實際交接仍卡著。

朋友丙：也把週六交接清單存一份，現場只核對鑰匙、書、外套和唱片。電扇與桌遊既然有爭議，就不要為了趕快結束而臨時讓步。

原發者：我已把清單寄到自己的信箱，也告知室友只陪同安全，不替我和前任談感情。若鑰匙仍未帶，我會直接換鎖並再以書面處理，不延長見面。

朋友乙：這樣實際安排比較清楚，但關係是不是能結束，仍不是週六拿到幾樣東西就能替你決定。

原發者：對。我現在只確定不再用取物當見面理由，其他感受還沒有答案。
