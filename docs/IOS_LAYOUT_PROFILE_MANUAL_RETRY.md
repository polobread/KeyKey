# iOS 17 舊樣式選單當機對照紀錄

此處保留改為四組獨立外觀設定以前的操作紀錄。現行設定為「版面、鍵帽間隔、字體、刪除鍵位置」，長按「設」的版面選單已取消；下列舊版名稱及長按操作只用來對照當時的測試證據。新版設定入口見 [iOS README](../Source/Loaders/iOS-Keyboard/README.md)。

這份步驟對照 2026 年 11 月 4 日最後一輪自動測試當機前的操作。兩項都在 XCTest 查詢畫面元件及日誌回呼中中斷；以下是手動對照順序，尚未證實手動操作能必定重現。手動正常也能幫助區分一般操作與自動化查詢的差異。

## 測試準備

- Device Hub 裝置：**KeyKey Heart Sutra iOS 17 20261103**，實際機型為 iPhone 12，系統 iOS 17.0（21A328）。
- 使用琦琦 App 的「輸入欄位測試」頁，點第一個「一般文字／換行」欄位。每條流程從空白欄位開始。
- 使用琦琦鍵盤，設定「好打注音」與「標準」注音鍵位。
- 在 Device Hub 的 Device → Keyboard 確認 Simulate Hardware Keyboard 沒有勾選，使用滑鼠點螢幕按鍵。
- 手動試這份步驟時，直接開 App 操作，不啟動 XCTest。已安裝的 App 首頁也有「輸入欄位測試」入口。

## 流程一 九個與十個音節的組字和刪字

這條流程較短，可先試。切換樣式都使用**短按「設」進設定頁**，選樣式後按「完成」。

1. 裝置直式，在鍵盤設定選「好打注音」「標準」「左右分離」，按「完成」。
2. 依序按 **ㄋ → ㄧ → ˇ**，重複九次。欄位應有 **你你你你你你你你你**，上方有九個組字。先不要選字或按 Enter。
3. 第十次先**只按 ㄋ**，保留未完成的注音。
4. 短按「設」，選「滿版」，按「完成」；再短按「設」，選「左右分離」，按「完成」。未完成的 ㄋ 應保留，欄位仍是九個「你」。
5. 保留這個 ㄋ，依序將裝置轉成**一側橫式 → 直式 → 另一側橫式 → 直式**。每次等畫面穩定，檢查九個「你」與未完成注音仍保留。
6. 接著按 **ㄧ → ˇ**，完成第十個「你」。欄位應有十個「你」，上方仍只有九個可編輯組字。
7. 點上方組字列最左邊的「你」，從候選選單點選單字「你」。最後一輪自動測試選的是第一個候選「你」；欄位仍應有十個「你」。
8. **單點刪除鍵九次**，直到欄位剩一個「你」。這個字已經送入欄位，應保留；不要按第十次。
9. 按 **ㄏ → ㄠ → ˇ**，欄位應變成 **你好**。
10. 短按「設」，準備改回「滿版」。**最後一輪在準備點這個「設」、查找按鍵時當機，尚未成功開啟最後的設定頁。** 手動請確認是否能正常開啟。
11. 若可繼續，選「滿版」、按「完成」，再按 Enter，確認欄位仍保留「你好」。自動測試未完成這最後一段。

## 流程二 樣式與五種輸入擺法

這條流程從空白欄位開始，過程不輸入文字。切換樣式使用**長按「設」約一秒的快速選單**。

1. 裝置直式，設定「好打注音」「標準」。
2. 依序測以下五種輸入擺法：**注音 → 倉頡 → 簡易 → 英文 → 數字符號**。前三種從短按「設」後的輸入法設定切換。
3. 從簡易按左下的輸入模式切換鍵進英文，再按同一顆模式鍵進數字；可見標籤會隨目前模式改變。看到主鍵列有 **!** 和 **+** 即是此流程的數字符號擺法。不要用「符」開啟獨立符號面板。
4. 每種擺法都先長按「設」，選一次「滿版」作基準。接著依序長按「設」並選：**滿版 → 左右分離 → 滿版間隔 → 交叉排列 → 老花眼滿版 → 老花眼交叉**。因此每種擺法開頭會連續選「滿版」兩次，即使原本已選滿版也照做。
5. 每次等選單收起、鍵盤穩定，觀察高度是否相同、邊緣按鍵有無被裁切、欄位是否仍空白。
6. **最後一輪已走完直式前四種擺法，共 24 個樣式組合。到第五種數字符號、第二次從快速選單點「滿版」後，自動測試在查詢選單是否收起及「設」按鍵時當機。** 手動可特別觀察這個位置。
7. 若直式完成，再轉成一側橫式，依序重複五種擺法及上述樣式順序。原完整矩陣為兩方向 × 五擺法 × 六樣式，共 60 組合；最後一輪未進入橫式。
