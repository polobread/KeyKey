## 範圍與交付

- 主要修改 `Source/Loaders/Windows-TSF`，沿用 C++ TSF、WPF 設定程式與目前原生後端。
- 優先重用 macOS 的本地資源與共用引擎。不得重建或修改正式 `KeyKey.db`、模型、詞頻、訓練與驗證語料，也不新增網路服務。
- 保留舊設定、使用者詞庫與學習資料；新選項預設維持 Windows 目前行為。所有測試使用隔離 profile。
- 本次分支名稱為 `v1.3.2`；不因建立分支就全面更動五平台產品版號。完成後於 CHANGELOG 記錄 Windows 未發布功能；正式升版另按 AGENTS.md 的五平台清單辦理。
- 交付功能程式碼、必要行為回歸測試、Windows 操作文件與可追溯的驗證結果。不 push、不發布、不替換使用者已安裝的輸入法。
- 不包含注音文校正、OneKey、計算機、自訂 CIN 匯入、自訂音效及任意配色。

## 一 好打注音進階設定

### 使用者行為

在現有「注音」頁新增好打注音專屬區塊：

| 選項 | 設計 |
| --- | --- |
| 空白鍵開啟候選 | 對應 `ShowCandidateListWithSpace`，新 profile 保持 Windows 預設關閉；既有設定照讀 |
| 選字目標在游標前或後 | 對應 `CandidateCursorAtEndOfTargetBlock`，使用說明與例子避免把它誤解成選字後游標移動 |
| 選字按鍵 | 對應 `CandidateSelectionKeys`，留空沿用鍵盤配置自動候選鍵（許氏 asdfzxcv、倚天26 asdfjkl;、其餘 12345678），另提供數字按鈕與可編輯的 8 個不重複、可輸入 ASCII 按鍵；不接受空白、控制字元與重複鍵 |
| 組字區長度 | 對應 `ComposingTextBufferSize`，整數 10–20，與 macOS 設定範圍一致；預設保持 10 |

既有 Esc 清除整句的 user-choice 標記保留。無效值在套用前顯示具體錯誤；不得先部分儲存其他欄位再報錯。關閉未套用的設定不改變引擎。設定變更不得遺失正在組字的句子，需明確處理何時完成舊組字、何時啟用新值。

### 實作入口與驗收

- `SettingsModern/MainWindow.xaml`、`.xaml.cs`、`SettingsStore.cs`，需要時抽出可測的設定模型。
- 引擎既有讀取入口：`Source/ModulePackages/OVIMMandarin/OVIMSmartMandarin.cpp` 的 `loadConfig`；以 Windows adapter 修補為優先，避免更動其他平台預設。
- 驗證套用、重新開啟、下一次輸入生效、既有 profile 遷移與不合法設定。
- 使用非數字候選鍵實際選字，驗證頁面顯示與事件處理一致。
- 預設 10 音節重跑「請假要去哪裡玩呢去海邊因為那裡有比基尼」，檢查第 10、11、19 音節及全文不遺失、不重複。另驗證自訂長度的邊界與完整詞段擠出。

## 二 自訂詞讀音輔助

### 使用者行為

「自訂詞」頁新增「取得讀音」入口。輸入詞語後先依完整詞查詢本地正式詞庫，無完整詞才逐字查詢。顯示逐字讀音選單，允許破音字人工修正，並同步既有逗號分隔讀音欄位；保留熟悉原介面的使用者手動輸入方式。

- 有完整詞時優先提供詞庫已有的讀音組合，不把逐字第一讀音宣稱成語境正確。
- 缺字／無讀音時清楚標出需手動補充的位置，不能悄悄跳過該字或存入不完整讀音。
- 編輯既有詞語時保留已存讀音；只有使用者明確取得／選擇新讀音才覆蓋。
- Unicode 按 code point 處理，補充平面漢字不能當成兩個字。詞過長與大量破音字需設限，逐字提供候選，不展開無界笛卡兒積。
- 查詢只讀正式 DB；儲存仍走現有 user DB 驗證、rowid 與去重流程。

### 實作入口與驗收

- `UserDataStore.*` 或獨立 reading service、`SettingsModern/SettingsBackend.cpp`、`NativeBackend.cs` 及 WPF 控制項。
- 參考 macOS `OpenVanillaLoader.mm` 的 `userPhraseDBReadingsForPhrase` 與 `Utilities/PhraseEditor/OSX/PEController.m` 的 `editReading:`，不直接搬入 AppKit 程式。
- 明訂 native API 的緩衝區容量／長度與所有權，維持 x64/x86 P/Invoke 相容；查無資料與錯誤區分。
- 測試完整詞、破音字、查無字、補充平面字、長詞、保留手動修改、非連續 rowid、儲存後重新開啟及實際引擎選字。

## 三 符號與顏文字面板

### 使用者行為

工作列輸入法選單加入「符號表…」，開啟有分類與捲動／翻頁的面板。內容使用 `Source/Distributions/Takao/OnlineData/CannedMessages.plist` 的內建分類、`Buttons` 與 `Messages`，顏文字保留完整字串。初版不另搶占快捷鍵，不要求連線。

- 面板不搶走原文字宿主的輸入焦點。滑鼠選符號後送入原欄位並關閉面板；重新開啟可再次插入。
- 開啟面板本身不提交／清除組字；選擇時先透過既有模式切換的保字流程完成當前組字，再插入所選字串，順序只發生一次。
- Esc／關閉只關面板，不改文字；切換 App、焦點 context、輸入法或停用服務時關閉。不得把過期回呼送到另一個輸入框。
- 四種輸入法都可用；符號面板視為明確選取文字，保留資源原始全半形，避免套用全形模式破壞顏文字。
- 排版支援顯示器縮放、螢幕邊界、長顏文字及明暗外觀。提供可理解的分類／按鈕名稱與基本鍵盤關閉操作。

### 實作入口與驗收

- 新增 Windows 原生面板類別，與 `LangBarButton.*`、`TextService.*` 整合；不要從 TSF DLL 載入 WPF CLR。
- 經合法 TSF edit session 插入，使用現有 `ITfContext` 與明確生命週期檢查；不可用剪貼簿貼上或模擬鍵盤輸入。
- 從同一份 plist 產生／打包資源，選擇能讓受限 Search host 讀取的方式；內嵌資源可免除執行時額外讀取權限。解析失敗不得導致輸入服務崩潰。
- 測試分類解析及完整字串、一般輸入／未完成注音／已完成長句／候選開啟時插入、取消、連續點擊、焦點切換、服務結束、簡體開關與全形模式。
- 實際 TSF 文字宿主、Search、x86 宿主、高 DPI 與多螢幕屬獨立驗收，無法執行時記錄未驗證，不以單元測試代替。

## 四 簡體中文輸出

### 使用者行為

工作列選單加入可勾選的「簡體中文輸出」，設定頁提供同一開關。預設關閉，四種輸入法與關聯詞輸出一致套用。

- 與 macOS 一樣採輸出階段繁轉簡，組字／候選仍使用繁體詞庫；自訂詞與學習始終保存原繁體資料。
- 重用 `ModulePackages/OVOFHanConvert` 及其轉換表，維持現有逐字對照語意，不引入另一套模型或詞組轉換依賴。
- 切換開關時以舊狀態完成既有組字，新狀態用於後續輸入，避免同句半途改變或重複轉換；此行為在文件明示。
- 設定應在其他宿主、x64/x86 與受限 Search host 下一次操作同步；沿用現有 TSF 全域 compartment 設計的原則，避免無法讀取 Roaming 的 host 套用過期設定。
- 數字、英文、標點、emoji、無對應字保持原樣。符號面板字串如含漢字，經同一輸出策略處理；不寫入學習表。

### 實作入口與驗收

- `CMakeLists.txt` 納入既有轉換程式／必要表，保留授權標頭與打包 notices。
- `KeyKeyEngine.cpp`、輸出提交路徑、`FrontendSettings.*`、`LangBarButton.*`、設定頁與跨程序狀態同步。
- 特別盤點一般 commit、長句擠出、切換中英文／輸入法、失焦、關聯詞與符號直送路徑，確保全部只轉換一次；不能只在候選按 Enter 的路徑加入。
- 測試四種輸入法繁／簡輸出、關聯詞、長句擠出、選字後學習資料仍為繁體、重啟保留、跨程序／x86 同步及 AppContainer。使用隔離 GUID，不能污染使用者目前的全域選項。
