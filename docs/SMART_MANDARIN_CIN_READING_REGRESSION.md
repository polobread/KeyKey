# CIN 字音詞頻與 Guanyinma 固定 131 篇回歸

本次採詞組／人工讀音優先，僅單字回退使用 CIN 表中計算詞頻最高的可輸入讀音；同分沿用固定 reference 機率。before／after 共用凍結輸入，不能與舊選音規則的歷史數字直接相減。

這是完整來源重建與原 DB 的比較，包含已核准的「舊的」補償重算；不是只切換 CIN 表的隔離實驗。候選通過總動作至多增加 30 次的門檻，依使用者要求採用為 Guanyinma 分支的共用 DB，並同步 manifest、來源與 Android 快取識別。測試採 Guanyinma 核心，沒有驗證各平台 UI 或系統字型過濾。

## 「舊的」維持 1,715 的隔離比較

將已重建候選 DB 的「舊的」Unigram 從 2,029 降回 1,715，其他 Unigram、所有 Bigram、詞頻分母及凍結輸入均不變，再重播固定 131 篇。這是用來隔離此筆補償影響的診斷；不是將 1,715 放回來源後完整重跑 cooker。

| 項目 | 舊的 2,029 | 舊的 1,715 | 差異 |
| --- | ---: | ---: | ---: |
| 總動作 | 333,899 | 333,899 | 0 |
| 額外修正動作 | 10,510 | 10,510 | 0 |
| 與原 DB 的總動作差 | -98 | -98 | 0 |

131 篇全部 trace 相同，包含逐篇動作、修正字、候選順位與修正事件。「新的」仍維持 1,761。

| Unigram 路徑 | 分數 |
| --- | ---: |
| 舊的／2,029 | -4.047010448 |
| 舊的／1,715 | -4.120028371 |
| 就＋的 | -4.047179445 |

1,715 比「就＋的」的純 Unigram 路徑低 0.072848926，但現有句首「舊的」Bigram 是 -3.889684626；實際組句仍可能由 Bigram 勝出。實測「舊的」「舊的東西」「把舊的換掉」「這是舊的」在兩組都正確。

因此，2,029 是既有「完整詞必須剛好超過拆詞」檢查要求的最低整數，並非這次 131 篇測試證明必要的詞頻。直接把來源填回 1,715 仍會被該檢查中止；完整來源重建是否相同尚未驗證，不能由此隔離結果推定。

隔離實驗當時未變動正式 DB；本次採用的是「舊的」2,029 的完整來源重建 DB，未放寬 cooker 檢查。隔離結果與雜湊見 [1,715 診斷 JSON](../DataSource/CINReadingFrequency/jiude-1715-isolation-summary.json)，完整執行產物留在 JSON 的 artifacts 路徑。
