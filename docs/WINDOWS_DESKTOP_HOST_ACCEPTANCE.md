沿用既有使用者 profile，沒有清除學習。設定讀回為標準注音、UTF-8 字集、10 音節組字區、`12345678` 選字鍵、候選目標在游標後方、空白開候選關閉、Esc 清除整句關閉、繁轉簡關閉；中文啟動，初始為半形。關聯詞保留 `McBopomofo`，中文忽略 Caps Lock 的既有選項為關閉；Caps Lock 案例依這個實際值驗證，測試後切回關閉狀態。

## 證據與範圍

本機證據集中於 `Installer/local-builds/windows-desktop-acceptance-f2d4899/`，屬測試產物，不提交：

- `acceptance-results.json`：各檢查結果、輸入來源與未涵蓋項目。
- `environment.json`、`binary-evidence.json`、`pe-comparison.json`：測試初始設定、模組及建置識別比較；`environment.json` 的輸入來源描述是手打前的初始快照，最終狀態以驗收結果為準。
- `observations.json` 與對應 PNG：組字、候選、分段及使用者手打完成畫面。
- `notepad-automated-input.txt`、`word-automated-input.docx`、`word-committed-text.json`：真實宿主保存的自動送鍵文字及 Word 逐字核對資料。
- `physical-keyboard-input.txt`、`physical-keyboard-result.json`：使用者手打全文與核對結果。

本次只涵蓋上述 Windows x64 好打注音情境。傳統注音／倉頡／簡易在真實 App、x86 宿主、Windows Search／AppContainer、高 DPI／多螢幕、安裝／升級、真實 App 的 100 輪穩定性與手打中途邊界仍須另行驗證；macOS IMK 與 Linux／FreeBSD 原生宿主結果也不由本次推定。
