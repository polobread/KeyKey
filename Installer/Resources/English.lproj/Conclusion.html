The KeyKey files have been installed.

Save your work, log out of macOS, and log back in. This is required after a first installation, manual upgrade, or in-app update. A reboot is not required.

Upgrades: keep the existing KeyKey entry in Keyboard settings. After signing back in, select KeyKey from the Input menu; do not remove and re-add it.

First installation: after signing back in, add KeyKey under Traditional Chinese in System Settings → Keyboard → Text Input → Edit → “+”.

Try typing “台北” in TextEdit and verify the version in Preferences. See the macOS installation guide.

Know how this release types. Smart Phonetic is the default: type Bopomofo syllables and tones continuously to compose a sentence, then press Return to commit it. You can select Traditional Phonetic from the input menu if you prefer choosing one character at a time. Cangjie and Simplex remain available.

After selecting a character, you may see associated phrases. Select one or continue typing. Choose which collections contribute under Preferences → Phrases.

The old Yahoo software update and MobileMe iDisk sync services have been removed. User phrase databases from 1.1 are encrypted and cannot be read, so export them to a text file from 1.1 first and import them here.
