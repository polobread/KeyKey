Installation is complete.

If you are upgrading: the installer refreshes the current console user's input source and restores KeyKey if it was enabled. Check that you can select it and type in TextEdit, then verify the version in Preferences.

If this is a first installation: open System Settings → Keyboard → Text Input → Edit → “+”, choose Traditional Chinese, and add chichi77 KeyKey. Select it and try typing in TextEdit. If a first installation is still missing from the list, save your work before signing out and back in.

If KeyKey is missing or unusable after an upgrade: keep ABC enabled, remove KeyKey from Keyboard settings, add it again, and check typing. A logout hang after installation has been reported. Do not repeatedly log out or force power off to troubleshoot; report the package name and error message.

Privacy & Security → Device Control and Data Access is not where input sources are added. If the input method is missing or does not type, see the macOS installation and troubleshooting guide.

Know how this release types. Smart Phonetic is the default: type Bopomofo syllables and tones continuously to compose a sentence, then press Return to commit it. You can select Traditional Phonetic from the input menu if you prefer choosing one character at a time. Cangjie and Simplex remain available.

After selecting a character, you may see associated phrases. Select one or continue typing. Choose which collections contribute under Preferences → Phrases.

Software update and MobileMe iDisk sync are also gone; those services shut down in 2013 and 2012. User phrase databases from 1.1 are encrypted and cannot be read, so export them to a text file from 1.1 first and import them here.
