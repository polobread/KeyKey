Installation is complete.

If you are upgrading: the new version takes effect automatically; you do not need to log out.

If this is a first installation: log out and back in when convenient, then open System Settings → Keyboard → Input Sources, click “+”, and add chichi77 KeyKey under Traditional Chinese. The installer will not interrupt your current work.

Know how this release types. Smart phonetic input needs a language model cooked from the Sinica corpus, which was not part of the open-source release, so this release has no phrase input: you enter one character at a time. Typing 台北 means entering ㄊㄞˊ, picking 台 from the candidates, then entering ㄅㄟˇ and picking 北. Traditional Phonetic, Cangjie and Simplex all work, and all work this way.

Committing a character offers associated phrases, a second list of what usually follows it: 台 offers 灣, 北, 北市. It is a shortcut for the next character rather than phrase input, and each character is still committed by hand. Choose which collections contribute under Preferences → Phrases.

Software update and MobileMe iDisk sync are also gone; those services shut down in 2013 and 2012. User phrase databases from 1.1 are encrypted and cannot be read, so export them to a text file from 1.1 first and import them here.
