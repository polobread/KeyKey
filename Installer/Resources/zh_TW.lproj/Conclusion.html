琦琦輸入法的檔案已安裝。

請先儲存工作，登出 macOS 再重新登入。全新安裝、手動升級與程式內更新都需要此步驟，不必重新開機。

升級：保留鍵盤設定中原有的琦琦項目；重新登入後從輸入法選單選回琦琦，不必移除重加。

首次安裝：重新登入後，到「系統設定 → 鍵盤 → 文字輸入 → 編輯… → ＋」，從「繁體中文」加入琦琦。

選回琦琦後，到「文字編輯」試打「台北」，並在偏好設定核對版本。操作步驟見 macOS 圖文安裝與使用指南。

請先了解這一版的輸入方式。預設的「好打注音」可以連續輸入注音與聲調，依前後文組成整句；按 Return 確定文字。若偏好逐字選字，可以從輸入法選單切換到「傳統注音」。倉頡與簡易也仍可使用。

選字後若出現聯想詞，可以直接選擇或繼續輸入。可在「偏好設定 → 詞彙管理」勾選要啟用哪些詞庫。

舊 Yahoo 軟體更新與 MobileMe iDisk 同步已移除。舊版的自訂詞資料庫為加密格式，無法讀取，請先在 1.1 版匯出成文字檔再匯入。
