安裝完成。

如果你正在升級：新版會自動生效，不需要登出。

如果這是首次安裝：請在方便時登出再重新登入。接著打開「系統設定 → 鍵盤 → 文字輸入 → 編輯 → ＋」，選「繁體中文」並加入「琦琦輸入法」。從選單列的輸入法選單切換到琦琦輸入法，再到「文字編輯」試打注音。安裝程式不會立刻中斷目前的工作。

「隱私權與安全性 → 裝置控制和資料取用」不是加入輸入法的地方。若找不到琦琦輸入法，或選取後無法輸入，請依照 macOS 圖文安裝與使用指南檢查。

請先了解這一版的輸入方式。預設的「好打注音」可以連續輸入注音與聲調，依前後文組成整句；按 Return 確定文字。若偏好逐字選字，可以從輸入法選單切換到「傳統注音」。倉頡與簡易也仍可使用。

選字後若出現聯想詞，可以直接選擇或繼續輸入。可在「偏好設定 → 詞彙管理」勾選要啟用哪些詞庫。

另外已移除的還有：軟體更新與 MobileMe iDisk 同步（伺服器分別於 2013、2012 年停止服務）。舊版的自訂詞資料庫為加密格式，無法讀取，請先在 1.1 版匯出成文字檔再匯入。
