如果你正在升級：安裝程式會更新目前登入帳號的輸入來源，並恢復原本啟用的琦琦輸入法。請先確認可以切換、試打，並在偏好設定核對版本。

如果這是首次安裝：打開「系統設定 → 鍵盤 → 文字輸入 → 編輯 → ＋」，選「繁體中文」並加入「琦琦輸入法」。從選單列切換後，到「文字編輯」試打注音。若首次安裝仍找不到項目，儲存工作後再重新登入。

升級後若找不到或無法使用琦琦：先保留 ABC，並在上述鍵盤設定中移除琦琦後重新加入，再確認可以輸入。已有安裝後登出卡住的回報，請勿以反覆登出或強制關機來排除問題；請回報安裝檔名與錯誤訊息。

「隱私權與安全性 → 裝置控制和資料取用」不是加入輸入法的地方。若找不到琦琦輸入法，或選取後無法輸入，請依照 macOS 圖文安裝與使用指南檢查。

請先了解這一版的輸入方式。預設的「好打注音」可以連續輸入注音與聲調，依前後文組成整句；按 Return 確定文字。若偏好逐字選字，可以從輸入法選單切換到「傳統注音」。倉頡與簡易也仍可使用。

選字後若出現聯想詞，可以直接選擇或繼續輸入。可在「偏好設定 → 詞彙管理」勾選要啟用哪些詞庫。
